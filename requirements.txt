# Runtime dependencies for the build pipeline (scripts/*.py).
# Keep this list minimal — every package here runs in CI and locally on
# every build. Dev tooling (ruff, pytest) is pinned in CI workflows
# directly so it doesn't drift with the build deps.
#
# Pinned with `==`, matching requirements.lock exactly. The lock is what
# actually installs (uv pip compile --generate-hashes, then
# --require-hashes in CI), so a `>=x,<y` range here was never exercised —
# it only described a resolution that never happened. Exact pins also
# parse unambiguously: OpenSSF Scorecard's bundled osv-scanner cannot read
# a compound `>=x,<y` specifier, falls back to treating the version as
# unset, and so matches every advisory ever filed against the package.
# That reported four phantom CVEs (PyYAML <5.4/<5.1, markdown-it-py <2.2)
# against versions we have never used. Bump these together with the lock.
markdown-it-py==4.2.0
rjsmin==1.2.5
rcssmin==1.2.2
# Canonical taxonomy (_data/taxonomy.yml) drives build_tags + the per-tag
# landings, paged listings, RAG corpus, and the editorial check_taxonomy
# audit. PyYAML is the only YAML parser these generators need.
PyYAML==6.0.3
