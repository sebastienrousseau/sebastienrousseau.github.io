pain001

Uma biblioteca Python que automatiza a criação de arquivos de pagamento ISO 20022 pain.001 a partir de CSV ou SQLite. Projetada para a migração mundial de MT/MX para mensagens estruturadas em SWIFT, SEPA e nos principais arranjos.
