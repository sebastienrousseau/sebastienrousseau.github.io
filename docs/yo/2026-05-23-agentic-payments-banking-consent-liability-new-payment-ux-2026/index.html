Ìsanwó Alábòójútó nínú Báńkì: Àṣẹ Ìfọwọ́sí, Ojúṣe, UX Ìsanwó 2026

Ìsanwó alábòójútó ń yí UX ìsanwó padà láti ìṣòwò ti ènìyàn tẹ̀ sí ìṣiṣẹ́ AI tí a fún ní àṣẹ, tí ó ní ààlà, tí ó sì lè jẹ́ àyẹ̀wò — ó ń fipá mú àwọn báńkì láti tún àṣẹ ìfọwọ́sí, ìjẹ́rìí, ìmúdájú ìjà, àti ojúṣe ṣe.

Points clés

Ìsanwó Alábòójútó nínú Báńkì: Àṣẹ Ìfọwọ́sí, Ojúṣe, àti UX Ìsanwó Tuntun ní 2026

Ìsanwó alábòójútó ti kọjá láti inú àpilẹ̀kọ ìfihàn sí ẹ̀rí ọjà alààyè. Mastercard àti Rabobank parí ìsanwó kan tí AI agent bẹ̀rẹ̀ ní Netherlands, níbi tí agent kan ti ṣàdéédéé ìdánwò kọfí lórí Priceless.com láìwọ̀ àwọn alaye káàdì tààrà àti pẹ̀lú àṣẹ ìfọwọ́sí oníbàárà tí ó hàn gbangba tí a kọ sílẹ̀ ṣáájú ìṣiṣẹ́ (Association of Corporate Treasurers). Ọ̀rọ̀ ìṣẹ̀ètò fún àwọn báńkì báyìí ni ìgbékalẹ̀ àṣẹ ìfọwọ́sí: bí ilé-iṣẹ́ ìnáwó ṣe fi hàn pé ìsanwó ẹ̀rọ jẹ́ àfọwọ́sí ènìyàn tàbí ilé-iṣẹ́ tí ó wà lẹ́yìn rẹ̀ nítòótọ́.

Àkójọpọ̀ Olùṣàkóso / Àwọn Kókó Pàtàkì

  • Àwọn àmì ọjà àkọ́kọ́ ti wà láàyè. Mastercard àti Rabobank parí ìṣòwò AI agent ní Netherlands nípa lílo Mastercard Agent Pay, pẹ̀lú agent náà tí a dí lọ́wọ́ láti wọlé sí dátà káàdì tààrà (Association of Corporate Treasurers).
  • Àwọn protocol ìsanwó alábòójútó ń farahàn ṣáájú kí òfin tó dúró. Fenwick mọ̀ AP2, A2A, x402, MCP, àti MPP gẹ́gẹ́ bí ìsapá protocol tí ń kojú ìbáṣepọ̀ agent àti àṣẹ (Fenwick).
  • Àṣẹ ìfọwọ́sí ni ìṣòro báńkì pàtàkì. Àwọn àṣẹ cryptographic onírúurú AP2 ń gbìyànjú láti gba ìtọ́ni olùṣàmúlò àti ìfọwọ́sí ìkẹyìn gẹ́gẹ́ bí ẹ̀rí ète tí a lè ṣàyẹ̀wò (Fenwick).
  • Ojúṣe kò tíì ní ìdáhùn. Òfin ìsanwó tí ó wà ni a ṣe yí àwọn ìṣòwò tí ènìyàn pinnu kà, kì í ṣe àwọn ètò AI aládàáṣe tí ń ṣiṣẹ́ lábẹ́ àṣẹ tí a fi lélẹ̀ (Fenwick).
  • UK ti ń bá ìlànà mu. HM Treasury sọ pé yóò ṣàwárí bí ìlànà iṣẹ́-ìsanwó ṣe gbọ́dọ̀ bá ìsanwó AI agent mu (GOV.UK).
  • UX tuntun kì í ṣe checkout. Ó jẹ́ ìbáṣepọ̀ agent-sí-oníṣòwò, àṣẹ tí ó ní ààlà, àwọn iwèé-ẹ̀rí tókènì, kọ́kọ́rọ́ ìwọlé, opin ìnáwó, àti ẹ̀rí ìjà tí a ṣe ṣáájú kí owó tó rin.
  • Àwọn báńkì nílò ìpele ìdarí agent. Báńkì tí kò lè jẹ́rìí ìdánimọ̀ agent, ààlà àṣẹ, ìṣe àjèjì, àti orísun ìṣòwò kò gbọ́dọ̀ jẹ́ kí ìsanwó parí.

Kí Ló Dé Tí 2026 Fi Di Ọdún Tí Èyí Wá Di Ìṣẹ̀ètò #

Ilé-iṣẹ́ báńkì ti ṣe ìsanwó aládàáṣe fún ọ̀pọ̀lọpọ̀ ọdún, ṣùgbọ́n ìsanwó alábòójútó yàtọ̀ ní ìjẹ́pàtàkì. Autopay ń ṣe ìtọ́ni tí ó ti dúró; ètò ìsanwó alábòójútó lè yan oníṣòwò, àkókò, iye, ọ̀nà ìsanwó (rail), àti orísun owó nínú èrò tí olùṣàmúlò gbé kalẹ̀. Fenwick ṣàlàyé ìpín náà gẹ́gẹ́ bí àwọn ìṣòwò ìsanwó tí àwọn ètò AI ìbámu ń bẹ̀rẹ̀, ṣàkóso, tí wọ́n sì ń ṣe nípa àṣẹ tí a fi lélẹ̀ (Fenwick).

Àmì ìlànà UK ṣe pàtàkì nítorí pé ó gbé ìsanwó alábòójútó sí inú ìlànà ìsanwó pàtàkì dípò gbígbà á gẹ́gẹ́ bí ohun àjèjì AI. GOV.UK sọ pé ìjọba yóò ṣe ìjùmọ̀sọ̀rọ̀ lórí ṣíṣe ìfìnúfọ̀nú gbígba AI agent láti ṣe ìsanwó fún àwọn oníbàárà àti àwọn ilé-iṣẹ́ (GOV.UK).

Ipò Ìgbékalẹ̀ 2026 #

1. Ète Tí A Lè Jẹ́rìí Sí Di Kókó Ìsanwó #

Ìyípadà pàtàkì jẹ́ láti ìní iwèé-ẹ̀rí sí ẹ̀rí ète. Nọ́mbà káàdì, tókènì, iwèé-ẹ̀rí API, tàbí ààyè ìwọlé àkáǹtì kò fihàn pé oníbàárà ní ète ìsanwó pàtó yìí. Fenwick ṣe àkíyèsí pé AP2 ń lo àwọn àṣẹ cryptographic tí a fọwọ́ sí láti kọ àwọn ìtọ́ni tí ó ní ààlà ṣáájú àti ìfọwọ́sí ìkẹyìn, tí ń ṣẹ̀dá ọ̀nà àyẹ̀wò ète olùṣàmúlò (Fenwick).

2. Ìdánimọ̀ Agent Gbọ́dọ̀ Wà ní Ipele Báńkì #

Ìsanwó tí AI agent bẹ̀rẹ̀ nílò àwòṣe ìdánimọ̀ tí ó lágbára ju ìjókòó aṣàwákiri lọ. Báńkì gbọ́dọ̀ mọ̀ bóyá ìbéèrè náà wá láti ọ̀dọ̀ agent tí a fún ní àṣẹ, bóyá agent náà ń ṣiṣẹ́ nínú ààlà tí a fọwọ́ sí, àti bóyá a fọwọ́kan ọ̀wọ́ ìṣe.

3. Ojúṣe Nílò Ẹ̀rí Ṣáájú-Ìṣòwò #

Fenwick tẹnumọ́ àìdánilójú yí EFTA àti Regulation E, pẹ̀lú bóyá fífún AI agent ààyè àkáǹtì jẹ́ àṣẹ tòótọ́ àti ohun tó ń ṣẹlẹ̀ nígbà tí agent kọjá àwọn ìtọ́ni olùṣàmúlò (Fenwick). Ìdáhùn fún àwọn báńkì kì í ṣe láti dúró fún ilé ẹjọ́. Ó ní láti kó ẹ̀rí jọ ṣáájú ìpinnu owó.

4. Ìdarí Iwà Ẹ̀tàn Ń Yí Padà Láti Ìjẹ́rìí Olùṣàmúlò Sí Ìṣe Agent #

Apànìyàn kò nílò láti jí káàdì oníbàárà bí ó bá lè dí agent oníbàárà mu. Nítorí náà àwọn báńkì nílò ìdarí lórí prompt injection, ìṣe èké oníṣòwò, fífi àṣẹ irinṣẹ́ pọ̀, ìbáṣepọ̀ agent-sí-agent, àwọn àpẹẹrẹ ìnáwó àjèjì, àti àwọn àbá ìbàjẹ́.

5. UX Ìsanwó Di Ohun Tí A Fi Lélẹ̀ Tí A Sì Ń Ṣe Ìbáṣepọ̀ Lórí Rẹ̀ #

J.P. Morgan retí pé ìṣòwò alábòójútó yóò bẹ̀rẹ̀ pẹ̀lú àwọn ìpín tí kò léwu, tí ó ń ṣẹlẹ̀ lemọ́lemọ́, kí ó tó wọ inú àwọn ìrajà tó níye lórí gẹ́gẹ́ bíi tikẹ́ẹ̀tì àti ọkọ̀ (J.P. Morgan). Ọ̀nà yẹn ṣe pàtàkì: àwọn báńkì gbọ́dọ̀ bẹ̀rẹ̀ pẹ̀lú àwọn ìrírí tí ó ní ààlà, tí ó lè padà, tí kò gbówó lórí, kí wọ́n sì gbòòrò àṣẹ nìkan nígbà tí àwòṣe ẹ̀rí bá ṣiṣẹ́.

Kí Ni Èyí Túmọ̀ Sí Nípa Ìpín Báńkì #

Àwọn Báńkì Olùpín (Retail Banks) #

Àwọn báńkì olùpín gbọ́dọ̀ bẹ̀rẹ̀ pẹ̀lú àwọn ìrìnàjò ìsanwó alábòójútó tí kò léwu, opin ìnáwó tó lágbára, kọ́kọ́rọ́ ìwọlé (passkeys), àwọn iwèé-ẹ̀rí tókènì, àti àwọn ìlànà ìjà tó hàn gbangba. Èrò kì í ṣe ìdá-ara-ẹni tó pọ̀jù; ó jẹ́ ìdá-ara-ẹni tí ó ní ààlà tí àwọn oníbàárà lè gbẹ́kẹ̀lé.

Àwọn Báńkì Ilé-Iṣẹ́ (Corporate Banks) #

Báńkì ilé-iṣẹ́ nílò àwòṣe tí ó lágbára nítorí àwọn agent tí a fún ní àṣẹ lè bẹ̀rẹ̀ ìsanwó olùpèsè, ìyípadà FX, ìfilọ́lẹ̀ ìrìnàjò, tàbí àṣẹ àgbéwọlé. Ọ̀wọ́ ìfọwọ́sí, ìlànà ilé-ìṣúra, àti òpin àṣẹ gbọ́dọ̀ wà nínú ìṣòwò fúnra rẹ̀.

Àwọn Nẹ́tíwọ́ọ̀kì Ìsanwó #

Àwọn nẹ́tíwọ́ọ̀kì lè di ìpele ìgbẹ́kẹ̀lé fún ìṣòwò alábòójútó bí wọ́n bá pèsè ìṣe àmì-tókènì, ìjẹ́rìí àṣẹ, àwọn ẹ̀rí oníṣòwò, àti àwọn ìlànà ojúṣe tí àwọn báńkì lè gba pẹ̀lú àṣehẹ́pọ̀.

Àwọn Alábòójútó (Regulators) #

Àwọn alábòójútó gbọ́dọ̀ ṣàlàyé bí àwọn ìlànà àṣẹ ìfọwọ́sí, ìjẹ́rìí, ìsanwó aláìní àṣẹ, àti ìfìránṣẹ́ owó tí ó wà ṣe pẹ̀lú nígbà tí ẹ̀rọ bá yan àwọn alaye ìsanwó.

Ìparí #

Ìsanwó alábòójútó ni ìgbésẹ̀ àtẹ̀lé adásí ti ìsanwó tí a fi sínú àwọn ìpèsè, ṣùgbọ́n wọ́n nílò àwòṣe ìdarí tuntun. Báńkì gbọ́dọ̀ jẹ́rìí kì í ṣe ẹni tí oníbàárà jẹ́ nìkan, ṣùgbọ́n àṣẹ wo ni oníbàárà fi lélẹ̀, bóyá agent dúró nínú àṣẹ yẹn, àti bóyá ẹ̀rí ìṣòwò lè yè nínú ìjà kan. Ìgbékalẹ̀ tí ó borí kì í ṣe chatbot AI pẹ̀lú bọ́tìnì ìsanwó. Ó jẹ́ ètò àṣẹ ìfọwọ́sí, ìdánimọ̀, ìṣe àmì-tókènì, àti ojúṣe tí a wé yí ìṣiṣẹ́ aládàáṣe ká.

Àwọn Ìbéèrè Tí A Máa Ń Béèrè #

Kí ni ìsanwó alábòójútó?

Ìsanwó alábòójútó jẹ́ ìsanwó tí ètò AI ń bẹ̀rẹ̀, ṣàkóso, tàbí ṣe pẹ̀lú àṣẹ tí a fi lélẹ̀ láti ọ̀dọ̀ olùṣàmúlò dípò olùṣàmúlò tí ó ń tẹ̀ àwọn ìgbésẹ̀ kọ̀ọ̀kan.

Kí ló dé tí àṣẹ ìfọwọ́sí fi le?

Àṣẹ ìfọwọ́sí le nítorí pé ọ̀pọ̀lọpọ̀ òfin ìsanwó rò pé ìṣòwò pàtó kan ni ènìyàn fún ní àṣẹ. AI agent lè pinnu àwọn alaye ìṣòwò lẹ́yìn-ọ̀rọ̀ nínú ìtọ́ni gbòòrò, èyí tí ó ń ṣẹ̀dá àìdánilójú.

Ṣé ìṣe àmì-tókènì lè yanjú ewu ìsanwó alábòójútó?

Ìṣe àmì-tókènì ràn án lọ́wọ́ nítorí pé agent kò nílò iwèé-ẹ̀rí gangan, ṣùgbọ́n kò fihàn pé a fún agent ní àṣẹ láti ṣe ìṣòwò pàtó kan.

Níbo ni àwọn báńkì gbọ́dọ̀ bẹ̀rẹ̀?

Àwọn báńkì gbọ́dọ̀ bẹ̀rẹ̀ pẹ̀lú àwọn àpẹẹrẹ ìlò tí kò léwu, tí kò gbówó lórí, tí ó ní ààlà, níbi tí a lè dán àwọn àṣẹ, opin ìnáwó, ẹ̀rí ìjà, àti ìdarí oníbàárà wò lálàáfíà.
