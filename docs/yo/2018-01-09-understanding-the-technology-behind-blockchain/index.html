Àkopọ̀ / Àwọn Àmúlò Pàtàkì

  • Ìṣòro náà. Owó dígítálì béèrè fún yíyanjú ìṣòro ìnáwó ìlọ-méjì: ídènà kí ẹ̀ka kan náà má lò ìgbà méjì láìsí gbọ́ngàn ìsanwó tí a gbẹ́kẹ̀lé. Ìwé funfun Bitcoin 2008 yanjú èyí nípa rọ́pò àwọn agbànikànsí tí a gbẹ́kẹ̀lé pẹ̀lú ẹ̀rí àṣírí àti ìdíbò tí a pín káàkiri (Nakamoto, 2008).
  • Ìlànà data. Blockchain jẹ́ àtòjọ búlọ́ọ̀kù tí a sopọ̀ nínú èyí tí àkọsílẹ̀ búlọ́ọ̀kù kọ̀ọ̀kan ní SHA-256 hash ti àkọsílẹ̀ àǹfààní. Ẹ̀wọ̀n hash mú kí ìtàn jẹ́ fífikún nìkan: yíyí búlọ́ọ̀kù àtijọ́ kankan padà mú gbogbo hash tó tẹ̀lé ẹ̀ di aláìṣiṣẹ́, tí ó fipá mú olùkọlù láti tún gbogbo proof-of-work tó tẹ̀lé ẹ̀ ṣe.
  • Merkle trees. Àwọn ìdúnàádúrà inú búlọ́ọ̀kù kan ni a ṣe hash sí Merkle tree binary. Hash root, tí a tọ́jú nínú àkọsílẹ̀ búlọ́ọ̀kù, jẹ́ kí ìfọwọ́sí ìdúnàádúrà kọ̀ọ̀kan ní ọ̀nà iṣẹ́ laisi gbígbé búlọ́ọ̀kù kíkún sílẹ̀ — ìpilẹ̀ṣẹ̀ fún àwọn aláàánú SPV ìfẹ̀fẹ̀ ìwúwo.
  • Ìfaagungun Ethereum. Yellow Paper Ethereum (2014) ṣe àgbékalẹ̀ EVM — ẹ̀rọ stack tí ó mú kí ó dájú tí ó ń ṣiṣẹ́ lórí gbogbo ẹ̀ka kíkún. Smart contracts jẹ́ bytecode tí a gbé kalẹ̀ sí ẹ̀wọ̀n; wọ́n ṣiṣẹ́ kánna lórí gbogbo ẹ̀ka àti ìsanwó ní ọ̀nà atomic, rọ́pò àwọn agbànikànsí tí a gbẹ́kẹ̀lé pẹ̀lú kóòdù tí ó fipá mú ara rẹ̀ (Wood, 2014).
  • Pàtàkì ní ìṣe. Gbogbo ohun-ini tí a fún ní token, stablecoin, àti DeFi protocol tí a gbé kalẹ̀ láti 2017 máa ń ṣiṣẹ́ lórí àwọn ìpìlẹ̀ wọ̀nyí. Ìmọ̀ bí ẹ̀wọ̀n hash SHA-256 ṣe mú àìyípadà ṣẹ, bí Merkle tree ṣe jẹ́ kí ìfọwọ́sí tó níṣẹ ṣeéṣe, àti bí EVM ṣe ń ṣiṣẹ́ pẹ̀lú smart contracts ní ọ̀nà atomic jẹ́ ohun tí ó nílò ṣáájú ṣiṣẹ́ pẹ̀lú ètò Ethereum kankan.

Ìṣòro Tí Blockchain Yanjú #

Ṣáájú Bitcoin, àwọn ìsanwó dígítálì béèrè fún agbànikànsí tí a gbẹ́kẹ̀lé — bánkì, olùṣe ìsanwó, tàbí ilé gbọ́ngàn — láti dènà ìnáwó ìlọ-méjì. Tí Alice bá fi fáìlì dígítálì tí ó ṣàpèjúwe £10 ránṣẹ́ sí Bob, kò sí nǹkan nínú fáìlì náà tó dènà rẹ̀ láti fi ẹ̀dà kánna ránṣẹ́ sí Carol. Ojútùú nínú gbogbo ètò tó wà ni ìtọ́jú àkọsílẹ̀ àárín gbùngbùn: ìwé àkọsílẹ̀ bánkì sọ pé a ti lo owó náà, nítorí náà a kò lè lo ẹ̀lọ́ mìíràn mọ́.

Ìlọwọ́sí Bitcoin ni rọ́pò ìwé àkọsílẹ̀ tí a gbẹ́kẹ̀lé yẹn pẹ̀lú èyí tí a pín káàkiri nínú èyí tí àkọsílẹ̀ gbogbo ìdúnàádúrà ń tún ṣe káàkiri ẹgbẹẹgbẹ̀rún àwọn ẹ̀ka tí kò ní àjọṣepọ̀. Àìgbẹ́kẹ̀lé ara ọ̀kan tàwọn ẹ̀ka yí padà sí ààbò nípasẹ̀ ọ̀nà meji:

  1. Ìsopọ̀ àṣírí. Búlọ́ọ̀kù ìdúnàádúrà kọ̀ọ̀kan ní hash ti búlọ́ọ̀kù àǹfààní. Iṣẹ́ hash jẹ́ ìdèpọ̀ ìgbékèéṣe ìjú ọ̀nà kan: fún ìtẹ̀wọgbà kankan, iṣẹ́ ṣe àwọn ìtúpàtà tí ó ní gígùn tó ṣàbáwọlé, àti yíyí bit kan sí nínú ìtẹ̀wọgbà ṣe àwọn ìtúpàtà tó yatọ̀ pátápátá. Èyí túmọ̀ sí pé ìyípadà kankan sí búlọ́ọ̀kù ìtàn kan máa ń mú gbogbo búlọ́ọ̀kù tó ṣáájú rẹ̀ di aláìṣiṣẹ́.

  2. Ìdíbò proof-of-work. Fífikún búlọ́ọ̀kù tuntun béèrè fún ìwárí iye nonce tí hash búlọ́ọ̀kù rẹ̀ bá ṣubu ní ìsàlẹ̀ ìpẹ̀kun àfojúsun — tó gbowó ní ìṣirò láti rí, tó rọrùn láti fọwọ́sí. Èyí mú kí ìtúnjẹ ìtàn gbowó ní àmúlò sí ìjìnlẹ̀ búlọ́ọ̀kù tí a ń yí padà, nítorí pé olùkọlù gbọdọ̀ tún gbogbo proof-of-work láti búlọ́ọ̀kù yẹn sí ìparí ẹ̀wọ̀n.

Àpapọ̀ náà túmọ̀ sí pé ẹ̀wọ̀n tó gùn jù pẹ̀lú ìṣe àpapọ̀ proof-of-work jù lọ, ní ọ̀nà ìkọ́lé, ni ẹni tó ń tọ́jú nípasẹ̀ àwọn olùkópa ológun tí ń lo àwọn ohun-ìní gidi.

Àwọn Òpò Ìkọ́lé Àṣírí #

Ìmọ̀ ẹ̀rọ blockchain kópa àwọn primitive àṣírí mẹta tó ti wà ṣáájú sí ètò tuntun:

Àwọn Iṣẹ́ Hash SHA-256 #

SHA-256 (Secure Hash Algorithm 256-bit) jẹ́ ọmọ ẹgbẹ́ ìdílé SHA-2 tí NIST ṣe àmúlò. Ó gba ìtẹ̀wọgbà tí gígùn rẹ̀ yàtọ̀ àti ṣe ìtúpàtà bit 256. Àwọn àṣà pàtàkì fún lílo blockchain:

  • Ìgbékèéṣe. Ìtẹ̀wọgbà kan náà máa ń ṣe ìtúpàtà kan náà nígbà gbogbo.
  • Àtakò ìwòfà tẹ̀lé. Pẹ̀lú ìtúpàtà hash, kò ṣeéṣe ní ìṣirò láti tún kọ́ ìtẹ̀wọgbà náà.
  • Ipa avalanche. Yíyí bit kan sí ìtẹ̀wọgbà yí ìdajì àwọn bit ìtúpàtà padà níwọ̀n, tí ó mú kí àwárí brute-force di aláìṣiṣẹ́.
  • Àtakò ìkọlù. Kò ṣeéṣe ní ìṣirò láti rí àwọn ìtẹ̀wọgbà meji tó yatọ̀ tó máa ń ṣe hash kan náà.

Bitcoin lo SHA-256 ìgbà méjì (SHA-256d) fún ààbò àfikún lòdì sí àwọn ìkọlù fífarọpọ̀ gígùn. Ethereum lo Keccak-256, ìyatọ̀ finalist SHA-3.

Merkle Trees #

Merkle tree jẹ́ igi binary ti àwọn hash. Ẹ̀ka àwọn ewé kọ̀ọ̀kan jẹ́ hash ìdúnàádúrà. Ẹ̀ka inú kọ̀ọ̀kan jẹ́ hash ti àwọn ọmọ méjì rẹ̀. Gbòǹgàn — Merkle root — ṣàpèjúwe gbogbo ìdúnàádúrà nínú búlọ́ọ̀kù nínú iye byte 32 kan tí a tọ́jú nínú àkọsílẹ̀ búlọ́ọ̀kù.

Àbájáde ní ìṣe: láti fọwọ́sí pé ìdúnàádúrà kan pàtó wà nínú búlọ́ọ̀kù, o nílò log₂(n) hashes nìkan, kì í ṣe gbogbo n ìdúnàádúrà. Fún búlọ́ọ̀kù tí ó ní ìdúnàádúrà 2,000, ìfọwọ́sí béèrè fún hashes 11 dípò 2,000 — ìpilẹ̀ṣẹ̀ fún Simplified Payment Verification (SPV) nínú àwọn aláàánú ìfẹ̀fẹ̀ ìwúwo.

Àwọn Ìbuwọ́lù Dígítálì (ECDSA) #

Àṣẹ ìdúnàádúrà nínú Bitcoin àti Ethereum lo Elliptic Curve Digital Signature Algorithm (ECDSA) lórí ìgbékalẹ̀ secp256k1. Ìkọ̀ àdání fọwọ́sí ìdúnàádúrà; ẹ̀ka kankan lè fọwọ́sí ìbuwọ́lù nípasẹ̀ lílo ìkọ̀ gbangba tó báa mu láìmọ̀ ìkọ̀ àdání. Èyí ń ṣe ìdánilójú pé olùdáwọlé ìkọ̀ àdání nìkan ni ó lè fún ní àṣẹ ìnáwó láti àdírẹ́sì kan.

Àwọn àdírẹ́sì Ethereum jẹ́ 20 bytes ìkẹhìn ti Keccak-256 hash ti ìkọ̀ gbangba — ìpamọ́ tí ó mú kí àwọn àdírẹ́sì ṣe àkópọ̀ àti gbé ní irọlẹ lákòókò tí wọ́n ṣì sopọ̀ sí àwọn bata ìkọ̀ ní ọ̀nà àṣírí.

Bí Bitcoin Blockchain Ṣe Ń Ṣiṣẹ́ #

Búlọ́ọ̀kù Bitcoin ní ẹ̀ya ọgbọ́n mẹta:

Àkọsílẹ̀ búlọ́ọ̀kù — bytes 80 tí ó ní: ìtupẹ́lẹ́ ìlànà, hash ti àkọsílẹ̀ búlọ́ọ̀kù àǹfààní, Merkle root àwọn ìdúnàádúrà, àkókò Unix, àfojúsun ìṣòro lọwọlọwọ, àti nonce. Àwọn awakùsà ń tún nonce ṣe (àti nígbà mìíràn àkókò tàbí extra-nonce nínú ìdúnàádúrà coinbase) títí ti double-SHA-256 hash ti àkọsílẹ̀ bá ṣubu ní ìsàlẹ̀ àfojúsun ìṣòro.

Àtòjọ ìdúnàádúrà — ẹgbẹ́ àwọn ìdúnàádúrà tó tò nípasẹ̀ àkósoóna tí a fi sínú búlọ́ọ̀kù. Ìdúnàádúrà coinbase (àkọ́kọ́) yan ẹbùn búlọ́ọ̀kù àti àwọn ọ̀yà ìdúnàádúrà fún àdírẹ́sì awakùsà.

Ẹ̀wọ̀n — ìsopọ̀ àwọn àkọsílẹ̀. Àpapọ̀ proof-of-work nínú ẹ̀wọ̀n (àpapọ̀ gbogbo iṣẹ́ tí a ṣe láti ṣe búlọ́ọ̀kù kọ̀ọ̀kan) ṣe àpínlẹ̀ ìpín tí jẹ́ ẹ̀wọ̀n aṣàpẹẹrẹ. Àwọn ẹ̀ka máa ń tẹ̀ lé ẹ̀wọ̀n tí ó ní iṣẹ́ àpapọ̀ jù lọ nígbà gbogbo.

Àkókò búlọ́ọ̀kù dojúkọ iṣẹ́jú 10 fún Bitcoin. Ìṣòro ṣe àdáṣe ìgbà gbogbo búlọ́ọ̀kù 2,016 (ọsẹ meji nìkan) láti tọ́jú àfojúsun yẹn nígbà tí àpapọ̀ hash rate nẹ́tíwọ́ọ̀kì yí padà.

Ìpele Tí A Lè Ṣe Ètò Ti Ethereum #

Ethereum ṣe àfọwọ́sí ìlànà ìdúnàádúrà Bitcoin láti "gbígbé iye" sí "ṣiṣe kóòdù." Àwọn àfikún pàtàkì:

Ethereum Virtual Machine (EVM). Ẹ̀rọ foju tí ó da lórí stack pẹ̀lú ọ̀rọ̀ bit 256 tí ó ṣiṣẹ́ ní ìgbékèéṣe lórí gbogbo ẹ̀ka kíkún. Gbogbo opcode ní iye gas tó hàn gbangba. Ìṣirò ni a fipín sí ìpẹ̀kun gas búlọ́ọ̀kù, ídènà àwọn orùka aláìsinmi kí wọ́n má ṣe dènà nẹ́tíwọ́ọ̀kì. Gbogbo ẹ̀ka tó ṣiṣẹ́ pẹ̀lú bytecode kan náà lórí ipò kan náà gbọdọ̀ ṣe ìtúpàtà kan náà — ìdíbò yìí lórí ìmúṣẹ ni ohun tí ó mú smart contracts di aláìnígbẹ́kẹ̀lé.

Àwọn àkáǹtì. Ethereum ní irú àkáǹtì méjì: Externally Owned Accounts (EOA) tí àwọn ìkọ̀ àdání ń ṣàkóso, àti Contract Accounts tí kóòdù rẹ̀ wà lórí-ẹ̀wọ̀n. Ìdúnàádúrà tí a fi ránṣẹ́ sí àdírẹ́sì àdéhùn máa ń dáré ìmúṣẹ bytecode àdéhùn.

Ipò. Ipò àgbáyé Ethereum jẹ́ ìdèpọ̀ àwọn àdírẹ́sì sí àwọn ipò àkáǹtì (nonce, ìdọ̀gbà, ìpamọ́, hash kóòdù). Gbòǹgàn ipò — Merkle Patricia trie ti gbogbo àwọn ipò àkáǹtì — wà nínú àkọsílẹ̀ búlọ́ọ̀kù kọ̀ọ̀kan, tí ó jẹ́ kí ẹ̀rí iṣẹ́ ti ipò àkáǹtì kankan ní gígùn búlọ́ọ̀kù kankan ṣeéṣe.

Gas. Àwọn aláàánú san gas (ní ETH) fún gbogbo ìṣe EVM. Gas ṣe àwọn iṣẹ́ méjì: ó san àwọn awakùsà/olùfòyèwò fún ìṣirò, àti ó fi ọwọ́ di àwọn ohun-ìní tí ìdúnàádúrà ọ̀kan kankan lè lò, ídènà àwọn ìkọlù hana-ìpèsè nípasẹ̀ àwọn ìṣe gbowó.

Kíkọ Smart Contracts ní Solidity #

Solidity jẹ́ èdè tí irú rẹ̀ dáadáa, tí ó dojúkọ àdéhùn tí ó ń kọ sí EVM bytecode. Àdéhùn token tí ó kéré jù ṣàpèjúwe àwọn èrò ìpilẹ̀ṣẹ̀:

pragma solidity ^0.8.0;

contract MyToken {
    string public name;
    string public symbol;
    uint8 public decimals;
    uint256 public totalSupply;
    mapping(address => uint256) public balanceOf;

    event Transfer(address indexed from, address indexed to, uint256 value);

    constructor(
        string memory _name,
        string memory _symbol,
        uint8 _decimals,
        uint256 _totalSupply
    ) {
        name = _name;
        symbol = _symbol;
        decimals = _decimals;
        totalSupply = _totalSupply;
        balanceOf[msg.sender] = _totalSupply;
    }

    function transfer(address _to, uint256 _value) external returns (bool) {
        require(balanceOf[msg.sender] >= _value, "Insufficient balance");
        balanceOf[msg.sender] -= _value;
        balanceOf[_to] += _value;
        emit Transfer(msg.sender, _to, _value);
        return true;
    }
}

Àwọn àkíyèsí pàtàkì: mapping(address => uint256) jẹ́ ètò ìpamọ́ EVM, kì í ṣe ètò data inú iranti — kíkà àti kíkọ ní iye gas. require ṣàtúnṣe gbogbo ìdúnàádúrà nígbà tí kùnà, tí ó padà gas tí a kò lò. event Transfer ṣe ìgbéjáde ìrékọjá tí àwọn atọ́ka ìta-ẹ̀wọ̀n lo láti tọ́pátẹ̀ àwọn gbígbé láìka ipò kíkún padà. constructor ṣiṣẹ́ ọ̀kan nígbà gbígbe kalẹ̀; àwọn ìpèpe lẹ́hìn náà ń lọ sí àwọn iṣẹ́ tí a sọ orúkọ.

ERC-20 standard ṣe àtúnṣe atọ́kùn àjọṣepọ̀ fún fungible tokens — transfer, transferFrom, approve, allowance, balanceOf, totalSupply — tí ó jẹ́ kí token tó ń tẹ̀ lé ERC-20 kankan ṣiṣẹ́ pẹ̀lú pàájáwọ̀ tàbí àpamọ́wọ́ tó mọ̀ ERC-20 kankan láìsí ìdàpọ̀ àkànṣe.

Láti Ìwé Àkọsílẹ̀ sí Àkópọ̀ Ìṣúná #

Àwọn primitive blockchain tí a ṣàpèjúwe níbí — àwọn ẹ̀wọ̀n hash, Merkle trees, EVM, àti ERC-20 — di ìpìlẹ̀ fún ẹgbẹ́ àwọn ohun elo ìṣúná tí ó gbọrọ laàárín 2018 àti 2026:

Ìṣúná Tí Kò Ní Àárín Gbùngbùn (DeFi). Àwọn ìlànà yálà (Compound, Aave), àwọn olùṣe ọjà aṣátúnṣe (Uniswap), àti àwọn olùkóhun èrè gbogbo ń ṣiṣẹ́ bí EVM smart contracts. Wọ́n ń rọ́pò àwọn iṣẹ́ ìtẹ̀jẹ, ìtọ́jú, àti ìsanwó àwọn agbànikànsí ìṣúná ìbílẹ̀ pẹ̀lú kóòdù tí ó ṣiṣẹ́ ara rẹ̀ àti àwọn adágún omi ìṣúná lórí-ẹ̀wọ̀n.

Àwọn Ohun-Ìní Tí A Fún Ní Token. Àwọn bánkì àárín gbùngbùn àti bánkì ìṣòwò ń ṣe àdánwò àwọn àpamọ́ tí a fún ní token, àwọn àwọ̀n owó tí a fún ní token, àti àwọn orísun owó ọjà ówó tí a fún ní token lórí àwọn ìyatọ̀ tí a fún ní àṣẹ ti àwọn ẹ̀wọ̀n tó bá EVM mu. Àwọn ẹ̀rọ ìpìlẹ̀ — àwọn yíyípadà ipò tí a tọ́jú pẹ̀lú hash, ìsanwó atomic, àwọn ìlànà gbígbé tí a lè ṣe ètò — jẹ́ àwọn ọmọ taara ti àpẹrẹ Ethereum 2014.

Àwọn Owó Dígítálì Bánkì Àárín Gbùngbùn. Ìwádìí CBDC ìpínpín Bank of England, ètò euro dígítálì ECB, àti Project Agorá gbogbo ń ṣàwárí àwọn àpẹrẹ DLT tí a ní láti tàbí tó bá àwọn àpẹrẹ ìpilẹ̀ṣẹ̀ nínú Bitcoin àti Ethereum mu. Àwọn ìlànà ìdíbò àti àwọn ìlànà ẹ̀wọ̀n hash ṣì máa ń ní ìjọṣe kódà nígbà tí ìlànà àṣẹ àti ìjọba yatọ̀ pátápátá sí àwọn blockchain gbangba.

Ìrìn-àjò láti ìwé funfun Bitcoin 2008 sí ìṣúná tí a fún ní token 2026 bo àwọn ọdún mẹ́wàá méjì, ṣùgbọ́n ó ń ṣiṣẹ́ lórí ìdíle ìmọ̀ ẹ̀rọ tó mọ̀kọ̀. Ìmọ̀ bí ẹ̀wọ̀n hash SHA-256 ṣe mú àìyípadà ṣẹ, bí Merkle tree ṣe jẹ́ kí ìfọwọ́sí tó níṣẹ ṣeéṣe, àti bí EVM ṣe ń ṣiṣẹ́ pẹ̀lú smart contracts ní ọ̀nà atomic jẹ́ ohun tí ó nílò ṣáájú ìṣàwárí ẹ̀tọ́ kankan nípa ohun tí blockchain lè ṣe àti tí kò lè ṣe nínú àwọn ìpèsè ìṣúná tí a ṣàkóso.

Àwọn Ìbéèrè Tí A Máa Ń Béèrè #

Kíni iyatọ̀ laàárín blockchain àti àkójọ data tí a pín káàkiri?

Àkójọ data tí a pín káàkiri ìbílẹ̀ ń tún ṣe data káàkiri àwọn ẹ̀ka fún wíwà àti ìṣe, ṣùgbọ́n àgbàkọ gbẹ́kẹ̀lé jẹ́ àárín gbùngbùn — olùṣàkóso lè yí àwọn àkọsílẹ̀ padà. Blockchain mú ìyípadà ìjẹ̀ní di gbowó ní ìṣirò nípasẹ̀ ẹ̀wọ̀n hash àti ìdíbò: yíyí àkọsílẹ̀ ìtàn kankan padà béèrè fún ṣíṣe gbogbo proof-of-work tàbí proof-of-stake tó tẹ̀lé ẹ̀ lẹ́ẹ̀kan sí, àti ìdaradara nẹ́tíwọ́ọ̀kì láti gba ìpín tó yí padà. Àṣà tó yàtọ̀ ni ẹ̀rí ìyípadà ìjẹ̀ní tí àṣírí àti ìpìlẹ̀ àwọn àwúwà ń fipá mú dípò nípasẹ̀ àwọn ìṣàkóso ẹ̀wọ̀n wíwọ.

Ẹ̀dà wo ni Ethereum lo Keccak-256 dípò SHA-256?

Ethereum gbà Keccak-256 (finalist SHA-3 ṣáájú àwọn àdáṣe ìdàrúdọ̀ NIST) ní apá kan nítorí pé àwọn olùṣe àpẹrẹ rẹ̀ fẹ́ òmìnira láti ìdíle SHA-2 tí Bitcoin ti ń gbára lé. Keccak tún ní àwọn àṣà algebra tó yatọ̀ tí ó mú kí ó di ìfáni-mọ̀ fún àwọn ìṣe EVM kan. Ipa ìṣe fún àwọn olùpilẹ̀ṣẹ̀ ni pé ìpamọ́ àdírẹ́sì Ethereum àti hashing iho ìpamọ́ lo Keccak-256, kì í ṣe SHA-256d bí i nínú Bitcoin.

Kíni "gas" ń dènà nínú EVM?

Gas ń dènà irú ìkọlù méjì. Àkọ́kọ́, ó ń dènà hana-ìpèsè nípasẹ̀ àwọn ìṣe gbowó ní ìṣirò: gbogbo opcode ní iye gas, nítorí olùkọlù kò lè fipá mú nẹ́tíwọ́ọ̀kì láti ṣiṣẹ́ pẹ̀lú àwọn orùka aláìsinmi láìsí ọ̀yà. Keji, ìpẹ̀kun gas búlọ́ọ̀kù fi ọwọ́ di ìṣirò àpapọ̀ fún búlọ́ọ̀kù kọ̀ọ̀kan, ní ìdánilójú pé àkókò ìfọwọ́sí búlọ́ọ̀kù ṣì ní ìdánílójú àti asọtẹ́lẹ̀ fún àwọn ẹ̀ka kíkún. Láìsí gas, ìpèpe àdéhùn ọ̀kan kankan lè dènà nẹ́tíwọ́ọ̀kì nípa ṣiṣe ìṣirò tí kò ní ìpẹ̀kun.

Bí proof-of-stake ṣe yí àlàyé ààbò padà ní àkàkọ̀ pẹ̀lú proof-of-work?

Nínú proof-of-work, wàláà ń pèsè ààbò nípasẹ̀ ìnáwó agbára: ìkọlù ẹ̀wọ̀n béèrè fún ìṣàkóso jù 50% ti hash rate nẹ́tíwọ́ọ̀kì, èyí tí ó túmọ̀ sí ìṣàkóso jù 50% ti ohun ẹ̀rọ àti agbára rẹ̀. Nínú proof-of-stake (tí Ethereum ń lò láti Merge ní 2022), wàláà ń pèsè ààbò nípasẹ̀ ipò ẹ̀tọ́ ọrọ̀-ajé: àwọn olùfòyèwò ti ETH wọlé gẹ́gẹ́ bí ìgbẹ̀kẹ̀lé, tí a máa ń gé tí wọ́n bá fọwọ́sí àwọn búlọ́ọ̀kù tó ṣekọ̀ọ̀. Ìkọlù 51% béèrè fún ìfipò jù 50% ti gbogbo ETH tí a gbé sí — iye owo àpamọ́ dípò iye owo ohun ẹ̀rọ àti agbára. Àlàyé ààbò yatọ̀ ṣùgbọ́n ó dọ́gba ní ìṣirò ní àwọn ọ̀rọ̀ ọrọ̀-ajé labẹ̀ ìrònú pé àwọn olùfòyèwò tó ní ọgbọ́n fẹ́ ọ̀yà ìsanwó jù ìparun àpamọ́.
