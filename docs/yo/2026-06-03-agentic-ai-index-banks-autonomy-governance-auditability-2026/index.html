Atọ́ka Agentic AI fún Àwọn Bánkì ní 2026: Dídiwọ̀n Ìṣọmọ̀dáṣe, Ìṣàkóso, Agbára Àyẹ̀wò, àti Ipa Ìṣòwò

Agentic AI nínú bánkì jẹ́ ìṣòro onímọ̀ ẹ̀rọ tí a wọ̀ ní aṣọ ìṣòro AI. Àwòrán LLM ṣe pàṣípààrọ̀; àwọn service account tí OAuth ti ní ààlà, semantic router tí a lè sọ àsọtẹ́lẹ̀, àwọn ẹnu-ọ̀nà Open Policy Agent, audit log WORM, àti kill switch tí a ti dán wò kò ṣe pàṣípààrọ̀.

TL;DR. Àwòrán onípàtàkì atọ́ka fún dídiwọ̀n ìmúrasílẹ̀ agentic AI nínú àwọn bánkì, tí ó bo ìṣọmọ̀dáṣe, ìṣàkóso, agbára àyẹ̀wò, ìgbẹ́kẹ̀lé, àwọn ìṣàkóso, àti ìjẹ́pàtàkì ìṣòwò.

Points clés

  • Kí Ni 2026 Ṣe Ọdún Tí Atọ́ka Yìí Ṣe Pàtàkì. Iyípadà láti chat sí àwọn bounded workflow ni ohun kan ṣoṣo tí ó ṣe pàtàkì nínú agentic AI fún àwọn bánkì lọ́dún yìí.
  • Àwọn Àmì Lóòótọ́ Láti Ṣàyẹ̀wò. Ṣe ìpín àwọn agent nípa ohun tí a ti gba láàyè wọn láti ṣe, kìí ṣe nípa bí àwòrán tí ó wà ní ìpìlẹ̀ ti gbọ́n tó.
  • Ìṣèpín Ìṣọmọ̀dáṣe. Ṣe ìpín àwọn agent nípa ohun tí a ti gba láàyè wọn láti ṣe, kìí ṣe nípa bí àwòrán tí ó wà ní ìpìlẹ̀ ti gbọ́n tó.
  • Agent Control Plane. Control plane jẹ́ ẹ̀ka onímọ̀ ẹ̀rọ láàárín LLM àti ètò iṣẹ́ rẹ.

Agentic AI nínú bánkì ti di ìṣòro onímọ̀ ẹ̀rọ báyìí tí a wọ̀ ní aṣọ ìṣòro AI. Àwòrán LLM ṣe pàṣípààrọ̀; control plane kò ṣe. Ìpèníjà fún 2026 kìí ṣe ìgbà tí àwọn bánkì gba láti lò ó — Cambridge CCAF ti gbé tí dé 52% — ó jẹ́ bóyá àwọn ọ̀nà adáṣe tí bánkì rẹ ń ṣiṣẹ́ lónìí lè la àyẹ̀wò SR 11-7 jákèjádò ìgbà mẹ́ta tó ń bọ̀. Ọ̀pọ̀ kò lè.

Àkótán Aláṣẹ / Àwọn Àkíyèsí Pàtàkì

  • Dáwọ́ pípè wọ́n ní chatbot dúró. Ẹ̀ka iṣẹ́ jẹ́ bounded workflow pẹ̀lú àwọn àṣẹ tool-call tí ó le. Iṣẹ́ náà ń ṣẹlẹ̀ nínú workflow, kìí ṣe nínú LLM.
  • OSWorld ní 66.3% jẹ́ àjà ìgbẹ́kẹ̀lé. Ìwọ̀n tí ó súnmọ́ jùlọ ti Stanford HAI sí lílo irinṣẹ́ ilé-iṣẹ́ ṣì ń ṣàṣìṣe ní iṣẹ́-ṣíṣe kan nínú mẹ́ta. Èyí jẹ́ nọ́ńbà tí ó ń dá ìjáfáfá human-in-the-loop tí ó lágbára láre; kò dá láre kí ó ṣiṣẹ́ láìfẹ̀ẹ́sí lórí ohunkóhun tí ó kàn owó àwọn ará-òde.
  • Ṣe ìpín nípa àwọn àṣẹ, kìí ṣe nípa ọgbọ́n. Ìṣèpín Ìṣọmọ̀dáṣe ń lọ láti Ipele 0 (ìyẹnu CSA clause ISDA tí a lè kà nìkan) sí Ipele 4 (ìṣèto ìtúnṣe ìsanwó onírinṣẹ́-púpọ̀ pẹ̀lú àwọn àyẹ̀wò ìfipámáyà). Ipele 5 — ìṣèto ara-ẹni láìsí àyẹ̀wò — kò gbọdọ̀ wà nínú iṣẹ́ bánkì ní 2026.
  • Agent Control Plane ní àwọn ẹ̀ka márùn-ún tí a kọ́, kìí ṣe ìwé ìlànà. Àwọn service account tí OAuth ti ní ààlà, semantic routing tí a lè sọ àsọtẹ́lẹ̀, ẹnu-ọ̀nà Open Policy Agent, audit log WORM, àti kill switch tí a ti dán wò. Ohunkóhun tí ó bá kù jẹ́ àwárí.
  • SR 11-7 àti PRA SS1/23 ti ń ṣiṣẹ́ tẹ́lẹ̀. Fed ti sọ ní ọ̀pọ̀ ìgbà pé gbogbo ètò ìpinnu láti àfikún-sí-ìjáde wà nínú àkójọ. Àwọn bánkì tí ó ń jiyàn pé LLM kìí ṣe àwòrán ti pàdánù ìjiyàn òfin kí wọ́n tó kọ́kọ́ jiyàn.

Kí Ni 2026 Ṣe Ọdún Tí Atọ́ka Yìí Ṣe Pàtàkì #

Iyípadà láti chat sí àwọn bounded workflow ni ohun kan ṣoṣo tí ó ṣe pàtàkì nínú agentic AI fún àwọn bánkì lọ́dún yìí. Chatbot tí ó ń kọ ímeèlì ará-òde jẹ́ ohun tí a lè ṣàyẹ̀wò. Agent tí ó ń pe POST /accounts/{id}/freeze lórí pèpéle káàdì rẹ tí ó wà nínú iṣẹ́ jẹ́ ẹ̀rí tí a lè ṣàyẹ̀wò. Iṣẹ́ ti dé ìpèníjà náà: ìwádìí Cambridge CCAF 2026 ròyìn 52% lílò agentic tí ó ń ṣiṣẹ́ àti 23% ní ìbálẹ̀ ìfẹ̀ẹ́sí tàbí ìyípadà (Cambridge CCAF ⧉). Bèbè "ìdánwò àdásí" kọjá ní ìgbà kan ní pẹ̀ ọdún 2025.

Àwọn ohun méjì yí padà pẹ̀lú lílò.

Kíní, àwọn alábojútó dáwọ́ pípe LLM gẹ́gẹ́ bí ohun tuntun dúró. Federal Reserve ti ṣàlàyé pé SR 11-7 ⧉ wà fún ìpinnu tí ó dá lórí LLM láìbìkítà bóyá a kà LLM gẹ́gẹ́ bí àwòrán ní ti inú. SS1/23 ⧉ ti PRA fẹ̀ tó láti ká wọn. Ìṣèpín ewu giga ti òfin AI ti EU ká ọ̀pọ̀ lílò LLM iṣẹ́-ìnáwó. Kò sí ìjiyàn "a ò mọ̀ bóyá èyí ká" mọ́.

Èkejì, òtítọ́ ìwọ̀n ti dé. Atọ́ka AI 2026 ti Stanford HAI ròyìn OSWorld — ìwọ̀n tí ó súnmọ́ jùlọ sí lílo irinṣẹ́ ilé-iṣẹ́ tòótọ́ — ní ìpé 66.3% (Stanford HAI ⧉). Iṣẹ́-ṣíṣe kan nínú mẹ́ta ṣì ń ṣàṣìṣe. Nọ́ńbà yẹn ń gbé àjà onímọ̀-ẹ̀rọ kalẹ̀ lórí ìṣọmọ̀dáṣe ní 2026. Ó gbẹ̀ tó láti dá àwọn ìjáfáfá Ipele-3 onílàálà láàárín ìbójútó HITL láre; kò gbẹ̀ tó láti dá ìṣiṣẹ́ láìfẹ̀ẹ́sí láre lórí API kankan tí ó kàn àkáǹtì àwọn ará-òde.

Atọ́ka Agentic AI fún àwọn bánkì gbọdọ̀ ṣe fún ìpinnu tí ó dá lórí LLM ohun tí àwòrán Basel ṣe fún capital: yí àwọn ọ̀rọ̀ "a ní ìṣàkóso" padà sí ẹ̀rí tí a lè wọ̀n, tí a sì lè ṣàyẹ̀wò fún workflow kọ̀ọ̀kan.

Ìṣèpín Ìṣọmọ̀dáṣe #

Ṣe ìpín àwọn agent nípa ohun tí a ti gba láàyè wọn láti ṣe, kìí ṣe nípa bí àwòrán tí ó wà ní ìpìlẹ̀ ti gbọ́n tó. GPT-5 / Claude 4 / Gemini 3 kan kan náà lè jókòó ní ipele kọ̀ọ̀kan; wrapper ni ohun tí ó yàtọ̀.

  • Ipele 0 — Wíwo. Ìwọlé read-only sí àwọn log, trace, tàbí ìṣòwò. Agent náà fi àwọn àpẹẹrẹ tàbí àkàwé hàn; kò sí kíkọ ní ibikíbi. Àpẹẹrẹ: wíwá àyípadà nínú ìwọ̀n ìkọ̀ pacs.008 nípa corridor àti pípè ẹgbẹ́ iṣẹ́.
  • Ipele 1 — Ìpèsè read-only. Ó kà láti ọ̀dọ̀ àwọn ètò iṣẹ́; ó tú ìjáde tí a kọ́ ránṣẹ́ fún ènìyàn láti lò. Àpẹẹrẹ: yíyọ àwọn ìyàtọ̀ CSA clause láti ISDA Master Agreement àjọṣe àti ṣíṣàmì àwọn ohun tí ó yàtọ̀ kúrò ní àpẹẹrẹ àjọ̀dà bánkì. Agent kò kọ padà sí ibi tí a tọ́jú àdéhùn.
  • Ipele 2 — Àkọ́sílẹ̀ fún ìfìpamọ́ ènìyàn. Ó dá àkọsílẹ̀ tí ènìyàn yẹ̀wò tí ó sì fi ránṣẹ́. Àpẹẹrẹ: kíkọ Ìròyìn Iṣẹ́ tí ó Ní Ifura láti ìkìlọ̀ ètò àyàmúlò pẹ̀lú gbàsílẹ̀ KYC pẹ̀lú trace ìṣòwò; oṣiṣẹ́ BSA kà á, ṣàtúnṣe tí ó bá yẹ, ó sì fi ránṣẹ́. Ètò gbàsílẹ̀ kàn rí ẹ̀dà tí ènìyàn fọwọ́sí nìkan.
  • Ipele 3 — Bounded execution. Ó pe API iṣẹ́ pẹ̀lú àwọn ààlà tí ó le, tí a lè sọ àsọtẹ́lẹ̀ tí wrapper ń fipá mu. Àpẹẹrẹ: pípe API card-freeze pẹ̀lú max-amount-at-risk: 5000 USD tí ìlànà allow-list fipá mu; agent kò lè dí káàdì kan tí ó so mọ́ owó tí ó ga ju ààlà náà láìsí ìgbéga Ipele-2. Ààlà náà gbé inú policy-as-code, kìí ṣe nínú prompt — àwọn prompt kìí ṣe ààlà àbò.
  • Ipele 4 — Ìṣèto onírinṣẹ́-púpọ̀ pẹ̀lú àwọn àyẹ̀wò tí a fipá mu. Ó ń ṣiṣẹ́ ọ̀nà kọjá ètò; gbogbo ìyípadà ipo tí a kọ síta; àwọn àyẹ̀wò nílò ìfọwọ́sí ènìyàn kí tool-call tí ó ń bọ̀ tó ṣiṣẹ́. Àpẹẹrẹ: workflow ìtúnṣe ìsanwó — yọ pacs.008 tí ó ṣàṣìṣe láti dead-letter queue → wá olùgbà tí ó tọ́ nípa SWIFT KYC Registry → dá ìfìránṣẹ́ tí a tunṣe → kọ sí outbound queue → ènìyàn fọwọ́sí ìfìránṣẹ́ tí a tún ránṣẹ́. Tí ìgbésẹ̀ kankan bá ṣàṣìṣe schema validator, workflow dúró tí ó sì dá ìṣẹ̀lẹ̀ àdásí.
  • Ipele 5 — Ìṣèto ara-ẹni. Agent ètò àti ṣe láìsí ìfọwọ́sí àyẹ̀wò. Kò sí workflow bánkì iṣẹ́ tí ó gbọdọ̀ wà ní Ipele 5 ní 2026. Èyí kìí ṣe gbólóhùn ìbálẹ̀; ó jẹ́ gbólóhùn ìgbẹ́kẹ̀lé. OSWorld ní 66.3% ń bàra-ẹ̀ pọ̀ kọjá àwọn API call tí a so mọ́ ara wọn. Tool-call mẹ́ta ní 66% kọ̀ọ̀kan jẹ́ 29% ìṣẹ́gun láti ìbẹ̀rẹ̀ sí òpin. Márùn-ún jẹ́ 13%. Má ṣe.

Agent Control Plane #

Control plane jẹ́ ẹ̀ka onímọ̀ ẹ̀rọ láàárín LLM àti ètò iṣẹ́ rẹ. Àwọn ẹ̀ka márùn-ún, gbogbo wọn ní runtime, kò sí ọ̀kan tí a kọ sínú ìwé ìlànà.

1. Ìdánimọ̀ àti Àwọn Àṣẹ #

Agent kọ̀ọ̀kan dọ́gba sí service account kan ṣoṣo. Account yẹn ní àwọn token OAuth client_credentials tí ó ní ààlà sí API surface tí ó kéré jùlọ tí ó nílò. Token agent card-freeze lè pe POST /accounts/{id}/freeze pẹ̀lú amount-at-risk: 0..5000 usd. Kò lè pe GET /accounts/{id}/balance fún àwọn ará-òde mìíràn. Kò lè pe ohunkóhun nínú custody, treasury, tàbí trading. Àwọn àṣírí service account ń yí padà ní ọ̀sẹ̀-ọ̀sẹ̀; àwọn credential tí ó pẹ́ ni àṣìṣe control-plane tí ó wọ́pọ̀ jùlọ nínú àwọn ìjáfáfá iṣẹ́.

2. Àwọn Guardrails Tí A Lè Sọ Àsọtẹ́lẹ̀ Lórí Tool-Call #

Gbogbo LLM tool-call kọjá nípa semantic router tí a lè sọ àsọtẹ́lẹ̀ (NeMo Guardrails, LangChain Guardrails, tàbí irú rẹ̀) kí ìpè náà tó dé API iṣẹ́. Router ń ṣe ìpín ìpinnu náà lórí allow-list tí ó ní ààlà; àwọn ìpè ní òde àkójọ ni a kọ̀ tí a sì kọ síta. Lẹ́yìn náà, olùdánwò JSON-schema ń ṣàyẹ̀wò payload — àwọn ààyè tí a nílò wà, ìwọ̀n dọ́là wà nínú ààlà, àwọn ISO country code wúlò, BIC olùgbà wà lórí àkójọ àjọṣe tí bánkì ti fọwọ́sí. Olùdánwò gbọdọ̀ jẹ́ aládàá: pacs.008 pẹ̀lú amount: 0 jẹ́ àṣìṣe àwòrán, kìí ṣe ìṣòwò tó tọ́. Bẹ́ẹ̀ ni wire kan sí orílẹ̀-èdè tí olùdásílẹ̀ ìbáni-nínú-fún kò ti fọwọ́sí tẹ́lẹ̀ fún ẹ̀ka ará-òde tí ó ń bẹ̀rẹ̀.

3. Policy-as-Code #

Open Policy Agent (tàbí irú rẹ̀) jókòó láàárín olùdánwò àti API. Àwọn ìlànà ní fọ́mù ní Git; àwọn ìpinnu ìkọ̀ ní a kọ síta; ẹ̀rọ ìlànà kan náà tí ó ń dí àwọn ìpè microservice-sí-microservice nínú pèpéle tí ó wà tẹ́lẹ̀ ń dí àwọn agent tool-call. Pípé àwọn agent gẹ́gẹ́ bí ẹ̀ka pàtàkì pẹ̀lú ẹnu-ọ̀nà tí a kọ́ ni ọ̀nà tí àwọn bánkì fi ń parí pẹ̀lú àwọn shadow control plane tí kò sí ẹnikẹ́ni lórí ẹgbẹ́ pèpéle yóò lóye ní oṣù mẹ́fà lẹ́yìn.

4. Audit Logging #

Ìpamọ́ WORM tí kò ṣe yípadà — S3 Object Lock, ìṣekúkúrú Azure Blob, tàbí àkáǹtì ledger. Àpèjáde kọ̀ọ̀kan ń gba: àkókò, ID agent, ID service account, hash system-prompt, ìpìlẹ̀ tí a kó, olùpèsè LLM pẹ̀lú àwòrán pẹ̀lú àdàkọ, ìjáde LLM láìmáakọ́, tool-call tí a túmọ̀, ìpinnu OPA, èsì API, ipa tí ó ń tẹ̀le, àti UID olùfọwọ́sí níbi tí ó bá yẹ. A fi àmì àṣírí sí àwọn gbàsílẹ̀ nígbà tí a bá kọ. Log yìí ni ohun tí àwọn olùyẹ̀wò SR 11-7 àti SS1/23 yóò béèrè. Tí ìwọ kò bá lè pèsè trace pípé fún ìpinnu kankan, kò sí agent tí a ṣàkóso ewu àwòrán lọ́dọ̀ rẹ.

5. Kill Switch #

API ìfìpáyà pupa tí ń kọ̀ gbogbo àpèjáde agent tí ó wà ní fífò nínú ẹ̀ka àṣẹ kan ní kéré ju ìṣẹ́jú-aaya 60. A dán wò ní gbogbo ìgbà mẹ́ta pẹ̀lú ìdánwò tabletop. Kill switch nìkan ni ohun tí ń mú ọ padà bọ̀ láti ìjáde àwòrán olùtà tí ó padà sẹ́yìn ní ìdákẹ́jẹ́ẹ́, vector prompt-injection tí ìwọ kò sí àbára, tàbí ìṣẹ̀lẹ̀ àyípadà tí ó ti ìwọ̀n false-positive kọjá ààlà iṣẹ́ rẹ. Àwọn kill switch tí a kò dán wò kò ṣiṣẹ́; pèse fún àkókò ìdánwò.

Ìṣàkóso Ewu Àwòrán #

Àwọn bánkì tí ó ń jiyàn pé "LLM kìí ṣe àwòrán lábẹ́ SR 11-7" ti pàdánù tẹ́lẹ̀. Federal Reserve ti ṣàlàyé léraléra pé gbogbo ètò àfikún-sí-ìjáde tí a ń lò ní workflow ìpinnu wà nínú àkójọ. SS1/23 PRA fẹ̀ jù bẹ́ẹ̀ lọ. Ìdúró tí ó tọ́: kà gbogbo agent iṣẹ́ gẹ́gẹ́ bí àwòrán SR 11-7 / SS1/23 láti ọjọ́ kìn-ín-ní. Owó láti tún kọ àpẹrẹ agent tí a ti tú síta gẹ́gẹ́ bí àwòrán jẹ́ ní ọ̀pọ̀ ìgbà ìwọ̀n owó láti ṣe àpẹrẹ rẹ̀ gẹ́gẹ́ bí ọ̀kan láti ìbẹ̀rẹ̀.

Àwọn ọ̀nà ìgbèjà mẹ́ta, tí a lò sí àwọn agent:

  • Ọ̀nà àkọ́kọ́ (oníwọ̀n àwòrán). Ó ṣàkọsílẹ̀ ìlò tí a pinnu fún agent, ìpilẹ̀ṣẹ̀ ìkẹ́kọ̀ọ́ àti ìpilẹ̀ṣẹ̀ data eval, schema system prompt, allow-list tool-call, àwọn àbájáde ìdánwò kill-switch. Ó ní ojúṣe fún ìbójútó àyípadà nínú iṣẹ́.
  • Ọ̀nà kejì (ẹgbẹ́ MRM). Ó fọwọ́sí agent kí ó tó wọ inú iṣẹ́. Ìròyìn ìfọwọ́sí ká àwọn àmì eval tí olùtà tú síta (MMLU, HumanEval, HellaSwag wúlò ṣùgbọ́n kò tó), àwọn àmì eval pàtàkì bánkì (àkójọ ìfọwọ́sí tirẹ tí o gbé kalẹ̀ láti àwọn àpẹẹrẹ iṣẹ́ — èyí ni iṣẹ́ tí ọ̀pọ̀ bánkì kò fi owó tó síi), àwọn àbájáde red-team prompt-injection, ìṣèwádìí ojúsàájú àti ìdájọ́-òdodo níbi tí workflow bá ní ipa lórí ará-òde, àti gbólóhùn ewu-tó-kù tí a ti wọ̀n.
  • Ọ̀nà kẹta (audit ti inú). Ó dán àwọn ẹnu-ọ̀nà control-plane wò àti ìkún audit-log lórí àyẹ̀wò àwọn ìpinnu iṣẹ́. Ìgbà audit 2027 yóò yàtọ̀ sí ti 2025; pèse fún un báyìí.

Ìbójútó tí ó ń tẹ̀síwájú ṣe pàtàkì jù ìfọwọ́sí lóòótọ́ lọ. Àwọn àkójọ eval pàtàkì bánkì tí ó ń tún ṣiṣẹ́ ní ọ̀sẹ̀-ọ̀sẹ̀ máa ń mu àwọn ìpadà-sẹ́yìn ìmúdójúìwọ̀n àwòrán tí àwọn ìwọ̀n olùtà kò ní fihàn. Ìpèsè tí OpenAI, Anthropic, àti Google ń tú síta yára ju ìpèsè ìfọwọ́sí rẹ; bóyá ààlà náà parí nípa ṣíṣiṣẹ́ àwọn eval tí ó ń tẹ̀síwájú, tàbí ó parí nípa àwárí olùyẹ̀wò fún ọ.

Dídiwọ̀n Ipa Ìṣòwò #

Àwọn ọ̀rọ̀ ìmújáde-iṣẹ́ gbogbogbòò kò la ìjíròrò CFO. Wọ̀n àwọn agent bí ìwọ ti ń wọ̀n àyípadà iṣẹ́ mìíràn:

  • Owó fún ìpinnu pípé, pẹ̀lú owó ìyípadà àti ìtúnṣe àwọn ìpinnu tí ó ṣàṣìṣe. Agent kíkọ SAR tí ó gé àkókò oṣiṣẹ́-BSA dín 40% ṣùgbọ́n tí ó ń dá àwọn fìnránṣẹ́ false-positive 12% ti pa ìjẹ́pàtàkì run, kìí ṣe pé ó dá a sílẹ̀.
  • Ìfọwọ́ kàn afọwọ́ṣe tí a yẹra fún, tí a kà ní nẹ́ọ̀tì àwọn ìfọwọ́kàn tuntun tí ìbójútó control-plane àti ìtọ́jú àdásí ti dá. Èrò náà kìí ṣe láti dín àfiyèsí ènìyàn kù; ó jẹ́ láti yí i padà sí àwọn ìpinnu tí ó ní ipa giga.
  • Ìwọ̀n ìyípadà — ìpín àwọn iṣẹ́ tí agent ṣe tí a yí padà sẹ́yìn láàárín wákàtí 24. Ìwọ̀n ìyípadà tí ó kọjá 2% lórí workflow Ipele-3 jẹ́ ìṣòro ìgbẹ́kẹ̀lé. Lórí 5% jẹ́ ìṣòro control-plane.
  • Ìkún audit-trace — ìpín àwọn ìpinnu pẹ̀lú ìpilẹ̀ṣẹ̀ pípé tí a lè tún kọ́ láti WORM log. Yẹ kí ó jẹ́ 100% lórí àwọn workflow Ipele-3 àti Ipele-4. Ohunkóhun tí ó kéré jẹ́ àṣìṣe ìlànà tí yóò jí nínú audit.

Tí workflow bá yára síi ṣùgbọ́n tí kò ṣe ṣíṣàlàyé, atọ́ka náà gbọdọ̀ jẹ ẹ̀ ní ìyà. Ọ̀nà tó dín jùlọ láti pàdánù àyẹ̀wò òfin ni láti ṣe àbáradógbá fún ìṣèjáde tí a sì sọ trace nù.

Kí Ni Èyí Túmọ̀ Sí Nípa Iru Bánkì #

Àwọn Bánkì Pàtàkì Àgbáyé #

Ìṣòro tí ó le ni ìṣàkóso ní ìwọ̀n: àwọn ọgọ́rùn-ún agent kọjá àwọn ẹ̀ka iṣẹ́, ọ̀kọ̀ọ̀kan pẹ̀lú oníwọ̀n àwòrán tirẹ̀, ọ̀kọ̀ọ̀kan jẹ́ àwárí audit tí ó lè wáyé. Ìnáwó kìí ṣe ìdánwò mìíràn. Ó jẹ́ control plane àárín gbùngbùn, ìpilẹ̀ṣẹ̀ audit-log ìṣọkan, àti benchẹ MRM tí ó lè fọwọ́sí àwọn agent 50-gbé ní ìgbà mẹ́ta kọ̀ọ̀kan. Láìsí agbára yẹn, àwọn agent dé yára ju kí a lè ṣàkóso wọn, ilé-iṣẹ́ náà sì ń kó ìbúgbé SR 11-7 jọ ní ìdákẹ́jẹ́ẹ́.

Àwọn Bánkì Ìṣòwò àti Bánkì Ilé-Iṣẹ́ #

Àwọn workflow tí ó ní ROI gíga jùlọ jẹ́ ìtúnṣe ìsanwó, yíyọ ìwé KYC, ìfọrọ̀wánilẹ́nuwò treasury-services FAQ, àti àwọn rírẹ́ ìpinpin. Gbogbo Ipele-2 tàbí Ipele-3 onílàálà. Ará-òde ilé-iṣẹ́ kò bìkítà pé agent ni ó ṣe iṣẹ́ náà; wọ́n bìkítà pé SLA dára si àti pé ìwọ̀n ìjiyàn dúró fẹ́sẹ̀múlẹ̀. Tọ́ àwọn ìdiwọ̀n hàn, kìí ṣe ìmọ̀ ẹ̀rọ.

Àwọn Bánkì Ìpínlẹ̀ #

Rà, má ṣe kọ́. Yan olùtà kan tí pèpéle agent rẹ̀ ti ní àwọn ìpìlẹ̀ control-plane — OAuth scoping, ìṣọkan OPA, audit logging WORM, kill switch tí a ti dán wò — tí o sì fọwọ́sí pèpéle yẹn lórí àwòrán MRM rẹ. Kíkọ́ control plane àdánidá jẹ́ ìnáwó ọdún púpọ̀ tí kò ṣe ìyàtọ̀ ní ìwọ̀n ìpínlẹ̀. Lo agbára onímọ̀ ẹ̀rọ lórí ìṣèdá workflow àti UX olùṣẹ́ dípò.

Fintech, PSP, àti Àwọn Olùpèsè Ìpìlẹ̀ #

Ìbéèrè ọjà fún àwọn olùtà kìí ṣe "ǹjẹ́ AI agent rẹ ṣe dáradára ju ènìyàn lọ." Ó jẹ́ "ǹjẹ́ pèpéle rẹ ń ṣe trace audit tí ó bámu SR 11-7 jáde lọ́nà tààrà." Àwọn olùtà tí ó lè dahùn pẹ̀lú bẹ́ẹ̀ ni yóò pa àwọn àdéhùn ilé-iṣẹ́. Àwọn olùtà tí kò lè dahùn yóò di nínú àwọn loop proof-of-concept nígbà tí ẹgbẹ́ MRM bánkì ń wá ìdí láti kọ̀ ìfọwọ́sí.

Ìparí #

Agentic AI nínú àwọn bánkì ní 2026 jẹ́ ìṣòro onímọ̀ ẹ̀rọ. Iṣẹ́ tí ó ní ìfẹ́ wà nínú control plane, kìí ṣe nínú àwòrán. Àwòrán LLM ṣe pàṣípààrọ̀; OAuth scoping, semantic router tí a lè sọ àsọtẹ́lẹ̀, àwọn ẹnu-ọ̀nà ìlànà OPA, audit log tí kò ṣe yípadà, àti kill switch kò ṣe pàṣípààrọ̀.

Àwọn ilé-iṣẹ́ tí yóò dàbí ohun tí ó ní ìgbẹ́kẹ̀lé sí àwọn alábojútó ní oṣù 18 ni àwọn tí ń kà gbogbo agent iṣẹ́ gẹ́gẹ́ bí àwòrán SR 11-7 / SS1/23 láti ọjọ́ kìn-ín-ní, pẹ̀lú àwọn àkójọ eval pàtàkì bánkì tí ń ṣiṣẹ́ tẹ̀síwájú àti control plane tí a kọ́ láti ṣàṣìṣe lọ́nà àbò. Àwọn ilé-iṣẹ́ tí kò ṣe bẹ́ẹ̀ yóò ṣàwárí bóyá bench MRM wọn lè dìídì láti mu àwọn àwárí ìtúnṣe 50-gbé ní ìgbà mẹ́ta kọ̀ọ̀kan.

Wọ̀n àwọn agent bí ìwọ ti ń wọ̀n àyípadà iṣẹ́ kankan: owó, ìgbẹ́kẹ̀lé, agbára ìyípadà, ẹ̀rí. OSWorld ní 66.3% ni àjà ìgbẹ́kẹ̀lé rẹ. Ṣètò ní ìbámu.

Àwọn Ìbéèrè Tí A Sábà Béèrè #

Kí ni agentic AI nínú bánkì?

Bounded workflow tí ó dapọ̀ LLM pẹ̀lú tool-call sí àwọn ètò iṣẹ́, guardrail runtime, àti àwọn àyẹ̀wò human-in-the-loop. Iṣẹ́ náà ń ṣẹlẹ̀ nínú workflow, kìí ṣe nínú àwòrán. Tí o bá ti gbọ́ ọ̀rọ̀ "chatbot", o wà nínú ẹ̀ka tí kò tọ́.

Níbo ni àwọn bánkì gbọdọ̀ bẹ̀rẹ̀?

Àwọn workflow Ipele 1 àti Ipele 2 níbi tí ó ti lè wọ̀n ìjẹ́pàtàkì àti tí a sì lè kó ipa búburú: yíyọ CSA clause ISDA, kíkọ SAR, ìtúnṣe ìsanwó, àpadàbọ̀ ìmọ̀ ti inú, ìrànlọ́wọ́ àyẹ̀wò code, ìpín ìwé KYC. Mọ́ Ipele 3 títí control plane rẹ yóò fi mu OAuth scoping, semantic routing, OPA gating, WORM logging, àti kill switch tí a ti dán wò.

Kí ni ewu tí ó ga jùlọ?

Jíjẹ́ kí àwọn agent ṣiṣẹ́ lórí àwọn API iṣẹ́ láìsí guardrail tí a lè sọ àsọtẹ́lẹ̀ láàárín ìjáde LLM àti API. Nọ́ńbà OSWorld 66.3% jẹ́ ìkìlọ̀. Tool-call láìní wrapper ní ìwọ̀n àṣìṣe yẹn lórí SWIFT MT103 tàbí API àkáǹtì àwọn ará-òde ń kọ ìròyìn tí ó burú jùlọ ti ìgbà òfin tó ń bọ̀.

Ǹjẹ́ SR 11-7 wà fún àwọn agent tí ó dá lórí LLM?

Bẹ́ẹ̀ ni. Federal Reserve ti ṣàlàyé pé gbogbo ètò àfikún-sí-ìjáde tí a ń lò nínú àwọn workflow ìpinnu wà lábẹ́ SR 11-7. SS1/23 PRA bo agbègbè kan náà ní UK. Ìṣèpín ewu giga ti òfin AI EU bo ọ̀pọ̀ àpẹẹrẹ ìlò iṣẹ́-ìnáwó. Ìjiyàn "ṣé èyí jẹ́ àwòrán" ti parí; ṣe ní ìbámu.

Báwo ni a yẹ kí a ròyìn agentic AI sí àwọn board?

Nọ́ńbà mẹ́rin fún workflow kọ̀ọ̀kan: ipele ìṣọmọ̀dáṣe, ìkún audit-trace, ìwọ̀n ìyípadà, owó nẹ́ọ̀tì fún ìpinnu. Pẹ̀lú àkójọ ewu-tó-kù tí ó ga jùlọ márùn-ún. Mọ́ slideware model-card.
