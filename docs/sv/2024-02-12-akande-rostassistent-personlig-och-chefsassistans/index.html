Àkàndé: asistente de voz impulsado por GPT para directivos

Arkitektur för en Python-röstassistent med öppen källkod: Whisper, GPT-4, SQLite-cache och fpdf2

Sammanfattning för ledningen / Viktigaste slutsatserna

  • Àkàndé ⧉ är en Python-röstassistent med öppen källkod som kopplar samman OpenAI Whisper tal-till-text, GPT-4 chat completions, en lokal SQLite-svarscache och fpdf2 PDF-export till ett enda röstdrivet arbetsflöde utan behov av molnlagring eller lokala AI-modellvikter.
  • SQLite-cachen lagrar SHA-256-hashar av normaliserade frågesträngar mappade till råa API-svarstext; cache-träffar kostar noll tokens och returnerar på under 10 ms, vilket gör upprepade frågor (som att granska ett beslut från tidigare i ett möte) i princip gratis.
  • Flerturskonversation upprätthålls genom att bygga messages-listan i minnet och skicka den vid varje Chat Completions API-anrop — modellen tar emot hela sessionshistoriken så att den kan hänvisa till tidigare utbyten, på bekostnad av gradvis ökad tokenanvändning per tur.
  • PDF-sammanfattningsgenerering serialiserar sessionens messages-lista till ett formaterat fpdf2-dokument: användarturer och assistentturer märks upp, tidsstämplar infogas och automatisk paginering hanterar sessioner av valfri längd; filen skrivs till det lokala filsystemet, inte upp till molnet.
  • Integritetsgräns: endast den direkta frågan (och sessionshistoriken upp till kontextfönstrets gräns) lämnar enheten — inga ljudinspelningar, inga transkript och inga cachade svar skickas till någon fjärrtjänst utöver OpenAI:s API.

Àkàndé ⧉ är en Python-röstassistent med öppen källkod byggd kring tre sammansättningsbara komponenter: OpenAI Whisper för taligenkänning, GPT-4 Chat Completions API för språkförståelse och -generering, samt en lokal SQLite-databas för svarscachning och sessionspersistens. Resultatet är ett röstdrivet arbetsflöde som kan köras på en bärbar dator utan lokala modellvikter, offlinelagringinfrastruktur eller en containerstapel.

Den här artikeln beskriver den tekniska arkitekturen för varje komponent, designbesluten kring cachning och flerturskontext, samt PDF-exportpipelinen.

Pipelineöversikt #

En enda Àkàndé-interaktion följer denna sekvens:

  1. Ljudinsamling — användaren talar; applikationen spelar in ljud till en tillfällig WAV-fil med sounddevice eller ett kompatibelt ljudbibliotek.
  2. Tal-till-text — WAV-filen skickas till openai.audio.transcriptions.create() (Whisper API); transkriptet returneras som en ren sträng.
  3. Cache-sökning — transkriptet normaliseras (gemener, komprimerat blanksteg) och SHA-256-hashas; hashen slås upp i den lokala SQLite-tabellen response_cache.
  4. API-anrop eller cache-träff — vid miss läggs transkriptet till sessionens messages-lista och skickas till openai.chat.completions.create(); svarstext lagras i cachen.
  5. Text-till-tal — svarstexten konverteras till ljud med openai.audio.speech.create()-endpointen (TTS) eller ett lokalt TTS-bibliotek, och spelas upp.
  6. PDF-export (på begäran) — hela messages-listan serialiseras till ett formaterat fpdf2-dokument och skrivs till disk.

OpenAI-integration: Chat Completions och Whisper #

Àkàndé använder Python SDK:n openai för både taligenkänning och textgenerering. Whisper-transkriptionsanropet:

with open(audio_file_path, "rb") as f:
    transcript = openai.audio.transcriptions.create(
        model="whisper-1",
        file=f,
        language=None  # auto-detect
    )
user_text = transcript.text

Chat Completions-anropet underhåller en sessionsomfattad messages-lista:

messages.append({"role": "user", "content": user_text})

response = openai.chat.completions.create(
    model="gpt-4-turbo-preview",
    messages=messages,
    temperature=0.2,
    max_tokens=1024
)

assistant_text = response.choices[0].message.content
messages.append({"role": "assistant", "content": assistant_text})

Systempromptsen läggs till en gång i sessionens start och styr Àkàndés persona, utdataformat och eventuella domänspecifika begränsningar:

messages = [
    {
        "role": "system",
        "content": (
            "You are Àkàndé, a concise executive assistant. "
            "Respond in plain prose. Do not use markdown. "
            "If asked to summarise, produce three bullet points maximum."
        )
    }
]

Att sätta temperature=0.2 byter kreativ variation mot determinism — viktigt för faktafrågor som att minnas ett beslut från tidigare i sessionen.

SQLite-svarscache #

Cacheschemat är minimalt:

CREATE TABLE IF NOT EXISTS response_cache (
    query_hash  TEXT PRIMARY KEY,
    response    TEXT NOT NULL,
    created_at  INTEGER NOT NULL  -- Unix timestamp
);

Sökning och skrivvägen:

import hashlib, sqlite3, time

def _normalise(text: str) -> str:
    return " ".join(text.lower().split())

def cache_get(conn: sqlite3.Connection, query: str) -> str | None:
    h = hashlib.sha256(_normalise(query).encode()).hexdigest()
    row = conn.execute(
        "SELECT response FROM response_cache WHERE query_hash = ?", (h,)
    ).fetchone()
    return row[0] if row else None

def cache_set(conn: sqlite3.Connection, query: str, response: str) -> None:
    h = hashlib.sha256(_normalise(query).encode()).hexdigest()
    conn.execute(
        "INSERT OR REPLACE INTO response_cache VALUES (?, ?, ?)",
        (h, response, int(time.time()))
    )
    conn.commit()

INSERT OR REPLACE säkerställer att ett cachat svar uppdateras om samma fråga skickas efter en modelluppgradering. En TTL-baserad evikteringsfråga (DELETE WHERE created_at < ?) kan schemaläggas vid uppstart för att begränsa cachestorleken.

Cache-träffsprestanda: en SQLite-sökning på en lokal SSD returnerar på under 1 ms för tabeller med upp till ~100 000 rader. Tur-och-retur-latensen för ett live GPT-4 API-anrop är vanligtvis 600–900 ms för korta svar. För en daglig genomgång med ett antal upprepade frågor eliminerar cachen de flesta API-anrop efter den första sessionen.

PDF-sammanfattningsgenerering #

PDF-export använder fpdf2, ett underhållet Python PDF-bibliotek utan binära beroenden:

from fpdf import FPDF
from datetime import datetime

def export_session_pdf(messages: list[dict], output_path: str) -> None:
    pdf = FPDF()
    pdf.add_page()
    pdf.set_font("Helvetica", size=11)
    pdf.set_margins(20, 20, 20)

    pdf.set_font("Helvetica", "B", 14)
    pdf.cell(0, 10, f"Àkàndé Session — {datetime.now():%Y-%m-%d %H:%M}", ln=True)
    pdf.ln(4)

    for msg in messages:
        if msg["role"] == "system":
            continue
        label = "You" if msg["role"] == "user" else "Àkàndé"
        pdf.set_font("Helvetica", "B", 10)
        pdf.cell(0, 6, label, ln=True)
        pdf.set_font("Helvetica", size=10)
        pdf.multi_cell(0, 5, msg["content"])
        pdf.ln(3)

    pdf.output(output_path)

multi_cell() hanterar radbrytning och automatiska sidbrytningar, så att sessioner av valfri längd producerar ett välformaterat dokument utan manuell pagineringslogik. Utdata är en PDF/A-kompatibel fil utan inbäddade teckensnitt utöver standard Helvetica-måtten.

Integritetsmodell #

Integritetsgränsen i Àkàndé definieras av tre fakta:

  1. Ljud skickas till Whisper API via HTTPS och behålls inte av OpenAI efter API-anropet (enligt OpenAI:s API-datanyttjandepolicy per februari 2024).
  2. Chat Completions API-anrop sänder sessionens messages-lista — som kan innehålla hela konversationshistoriken för flerturs-sessioner.
  3. SQLite-databasen och PDF-filerna finns helt och hållet i det lokala filsystemet; ingen bakgrundssynkronisering till någon molntjänst sker.

För verkställande användningsfall som involverar känsliga ämnen — M&A-diskussioner, personärenden, regulatorisk strategi — bör sessionshistoriken som skickas till API:et granskas mot organisationens AI-användningspolicy före driftsättning. Gränsen max_tokens i systempromptsen kan användas för att förhindra oavsiktlig sändning av kontext som överskrider den avsedda avslöjningsomfattningen.

Vanliga frågor #

Behåller Àkàndé konversationshistoriken efter att sessionen avslutas? messages-listan i minnet kasseras när processen avslutas. Konversationshistoriken behålls bara om användaren utlöser en PDF-export eller om ett anpassat persistenslager läggs till. SQLite-cachen lagrar frågehashar och svarstext, inte den fullständiga konversationskontexten.

Hur hanterar cachen frågor som är liknande men inte identiska? Cachen använder exakt matchnings-hashning på den normaliserade frågesträngen. Två frågor som skiljer sig med ett enda ord producerar olika hashar och resulterar i separata API-anrop. Semantisk cachning (med hjälp av inbäddningslikhet för att matcha nära-dubblettfrågor) skulle kräva ett ytterligare vektorsökningssteg och ingår inte i basimplementationen.

Vilken GPT-modell använder Àkàndé som standard? Standarden är gpt-4-turbo-preview per februari 2024. Modellnamnet är en konfigurationsparameter, så vilken OpenAI chat completion-modell som helst kan ersättas. Att byta till gpt-3.5-turbo minskar API-kostnaden med ungefär 20× per token men minskar resonemangets kvalitet för komplexa flerstegsfrågor.

Kan PDF-exportformatet anpassas? Ja. fpdf2-exportfunktionen accepterar messages-listan som enda obligatorisk inmatning, så teckensnitt, marginaler, sidstorlek, rubrikinnehåll och märkning kan alla ändras genom att redigera exportfunktionen. fpdf2 stöder också att lägga till bilder, tabeller och Unicode-teckensnitt, vilket möjliggör rikare dokumentlayouter för organisationer med specifika varumärkeskrav.
