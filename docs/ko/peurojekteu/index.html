3개의 실천 영역. 하나의 철학.

결제와 정산.

ISO 20022 pain.001 과 pacs.008 툴킷, 은행 명세서 파싱, 구조화 국경 간 결제 메시지로의 이행을 위한 Rust 라이브러리. SWIFT, SEPA, 실시간 결제 시스템에 부합하도록 설계.

결제 도구 탐색 ›

포스트 양자 암호.

CRYSTALS-Kyber (NIST FIPS 203), 해시 프리미티브, 양자 내성 빌딩 블록의 Rust 구현. 금융 인증에서 RSA·타원곡선 시대를 넘어서는 보호 수단.

양자 안전 라이브러리 탐색 ›

도구와 인프라.

직렬화, 로깅, 코드 생성, 날짜·시간을 위한 오픈소스 Rust 라이브러리. 또한 본 사이트를 구축하는 Static Site Generator (SSG)와, 이를 출시 가능하도록 하는 개발 환경.

질문이 있으신가요? 답변드리겠습니다.

이 프로젝트들은 어떤 라이선스로 공개됩니까?

모든 프로젝트는 Apache-2.0 라이선스로 공개됩니다. 각 저장소 루트의 LICENSE 파일이 신뢰할 수 있는 정보 원본입니다.

이 프로젝트들은 운영 환경에서 사용 가능합니까?

프로젝트에 따라 다릅니다. v1.x로 표시된 라이브러리는 안정화되었으며 부하 시험을 거쳤습니다. v1 이전은 견고한 기반이지만 진화 가능성이 있습니다. 각 저장소의 README에 현재 상태가 자세히 설명되어 있습니다. 운영 환경 사용에 대한 구체적인 보증이 필요하신 경우 문의하기를 통하여 연락하여 주십시오.

어떻게 기여하거나 이슈를 보고할 수 있습니까?

각 프로젝트는 github.com/sebastienrousseau에 공개 GitHub 저장소를 보유하고 있습니다. 문제를 기술하는 Issue를 등록(최소 재현 가능 예시 환영)하시거나 Issue에 연결된 Pull Request를 제출하여 주십시오. 기여는 Developer Certificate of Origin에 따르며, 서명된 커밋이 요구됩니다.

규제 대상 은행 환경에서 이 라이브러리를 사용할 수 있습니까?

가능합니다, 통상적인 주의 사항 하에. 이러한 라이브러리는 독립적인 오픈소스 작업물이며, 규제 대상 제품은 아닙니다. 결제 인프라상의 운영 배포 이전에, 통상의 공급망·보안·종속성 검토 절차(내부 미러를 통한 벤더링, SBOM 스캔, Git SHA 또는 암호 핑거프린트에 의한 고정)를 적용하시기 바랍니다.

상업적 지원이나 컨설팅을 제공하십니까?

제공합니다, 사전 선별을 거쳐. 의뢰는 ISO 20022 이행, 포스트 양자 이행 로드맵, 금융 서비스용 응용 AI를 다룹니다. 문의하기에 간략한 브리프, 일정, 적용 가능한 제약을 첨부하여 연락하여 주십시오.

새 출시 소식을 어떻게 받습니까?

사이트의 모든 일자가 표기된 기사는 RSS 피드와 뉴스레터 Banking On Quantum에 알림이 발송됩니다. 개별 저장소도 GitHub에서 릴리스를 공개하므로 직접 팔로우하실 수 있습니다.
