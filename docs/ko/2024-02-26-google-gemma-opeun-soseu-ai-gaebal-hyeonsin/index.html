통찰 #

Google의 OSS AI로의 전환 #

Meta의 Llama에 이어 Google은 Gemma 시리즈를 오픈소스로 공개하였습니다. 이는 Google의 AI 전략에서 중요한 변화를 나타냅니다: 오픈소스가 특정 활용 사례에서 중요하다는 점을 인식하고 있습니다.

아이디어 #

Gemini에 기반한 경량 모델 #

Gemma 2B와 Gemma 7B는 Gemini와 동일한 연구 기반 위에 구축되었으나, 온디바이스, 임베디드, 엣지 컴퓨팅에 최적화되어 있습니다.

혁신 #

상업적 사용에 개방 #

Gemma는 파인튜닝, 재배포, 상업적 사용을 허용하는 라이선스로 출시되었습니다. 이는 Llama 2에 대한 Meta의 접근과 유사하며, Gemma를 실용적인 엔터프라이즈 채택에 개방합니다.

접근 방식 #

파인튜닝 친화적 #

Gemma는 특정 도메인 또는 과제에 대한 파인튜닝을 염두에 두고 설계되었습니다. Hugging Face, JAX/Flax, PyTorch, Google Cloud Vertex AI 모두 Gemma 파인튜닝을 지원합니다.

활용 사례 #

온디바이스 AI와 비공개 엔터프라이즈 배포 #

주요 활용 사례: 모바일 응용 내 온디바이스 AI, 민감 데이터용 비공개 클라우드 배포, 특정 언어 또는 도메인에 대한 파인튜닝 모델, 엣지 컴퓨팅 기기.

결론 #

OSS AI 생태계의 성장 #

Gemma의 출시는 Meta의 Llama, Mistral, Falcon, StableLM 등과 함께 OSS AI 생태계를 키웁니다. 이는 AI 채택자에게 경쟁, 혁신, 선택지를 촉진합니다.
