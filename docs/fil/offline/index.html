Walang kasalukuyang koneksyon sa internet.

Subukan ang mga sumusunod:

  • Suriin ang mga setting ng seguridad na maaaring humaharang sa koneksyon.
  • Suriin ang mga cable at koneksyon.
  • Patunayan ang kalidad ng signal sa iyong lugar.
  • I-clear ang cache at cookies ng browser.
  • I-reset ang iyong modem o router.
  • I-restart ang iyong router.
  • I-off ang airplane mode.
