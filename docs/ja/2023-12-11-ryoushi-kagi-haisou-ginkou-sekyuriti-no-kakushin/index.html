インサイト #

量子鍵配送(QKD)とは何か #

QKD は、量子物理学の法則を使用して、検知不能な傍受の下でも理論的に安全な暗号鍵を 2 つの当事者間で配送します。BB84 のような有名なプロトコルは、量子もつれと不確定性原理に依存しています。

アイデア #

物理に基づく安全性 #

古典的な暗号は計算の難しさに依存していますが、QKD は物理に依存しています。傍受者は、検出可能な痕跡を残さずに量子状態を測定することはできません。これは、量子コンピュータが進化しても変わらない数学的基盤です。

イノベーション #

銀行のための主要なユースケース #

主要な銀行ユースケースには、データセンター間通信、SWIFT メッセージング、ATM ネットワーク、トレジャリーシステム間の流動性更新が含まれます。これらは、最高のセキュリティ保証を必要とする高価値、低ボリュームのリンクです。

課題 #

距離とインフラ #

QKD は、現在の技術では距離が制限されています(光ファイバ上で約 100 km、衛星経由でより長い距離)。これは、エンドツーエンドの QKD ネットワークの構築に投資されたインフラを必要とすることを意味します。

アプローチ #

ハイブリッドアプローチ #

最も実用的なアプローチは、QKD と PQC を組み合わせたハイブリッドです:QKD は最も価値の高いリンクの鍵分配を提供し、PQC はインターネット規模の量子耐性暗号を提供します。

ユースケース #

中央銀行、決済システム、トレジャリー #

中央銀行(中国、英国、スイス、シンガポール)、決済システム、企業のトレジャリーは、QKD パイロットを積極的に実行しています。これらは、量子セキュリティのオペラ的な機能テストです。

規制 #

国家インフラとしての QKD #

英国、中国、その他の国は、QKD ネットワークを国家インフラの一部として開発しています。これは、政府が QKD を長期的に重要だと考えていることを反映しています。

結論 #

物理の保証 #

QKD は、計算の難しさに依存しない暗号 —— 物理の法則のみに依存する暗号 —— を提供します。これは、量子の進歩のレースの中でも安定して残る保証です。すべての主要な銀行は、QKD 戦略を検討すべきです。
