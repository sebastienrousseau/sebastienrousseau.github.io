決済とセトルメント。

ISO 20022 pain.001 と pacs.008 のツールキット、銀行明細パース、構造化国際送金メッセージへの移行のための Rust ライブラリ。SWIFT、SEPA、リアルタイム決済スキーム向けに設計。

質問は? 回答します。

これらのプロジェクトはどのライセンスで公開されていますか?

すべてのプロジェクトは Apache-2.0 ライセンスで公開されています。各リポジトリのルートにある LICENSE ファイルが信頼できる情報源です。

これらのプロジェクトは本番運用に対応していますか?

プロジェクトによります。v1.x とマークされたライブラリは安定化され負荷下でテスト済みです。v1 以前は堅実な基盤ですが進化する可能性があります。各リポジトリの README に現在の状況が詳述されています。本番利用の具体的な保証が必要な場合はお問い合わせください。

どのように貢献または問題報告できますか?

各プロジェクトは github.com/sebastienrousseau に公開 GitHub リポジトリがあります。問題を記述する Issue を開く(最小再現可能例を歓迎)か、Issue にリンクした Pull Request を提出してください。貢献は Developer Certificate of Origin に従い、署名済みコミットが必要です。

規制下の銀行環境でこれらのライブラリを使用できますか?

はい、通常の注意のもとで。これらのライブラリは独立したオープンソース作品であり、規制対象製品ではありません。決済インフラ上の本番展開前に、通常のサプライチェーン、セキュリティ、依存関係レビューのプロセス(社内ミラー経由のベンダリング、SBOM スキャン、Git SHA または暗号フィンガープリントによるピン留め)を適用してください。

商用サポートやコンサルティングを提供していますか?

はい、事前選定のうえで。委託は ISO 20022 移行、ポスト量子移行ロードマップ、金融サービス向け応用 AI を扱います。お問い合わせに、簡単なブリーフ、スケジュール、適用される制約を添えてご連絡ください。

新しいリリースをどのようにフォローしますか?

サイト上のすべての日付付き記事は、RSS フィードとニュースレター Banking On Quantum でお知らせします。個別リポジトリも GitHub でリリースを公開しており、直接フォローできます。
