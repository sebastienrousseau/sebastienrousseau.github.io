Generátor statických webů bezpečný ve výchozím nastavení pro éru AI v roce 2026

Stručně. Publikační infrastruktura je dnes bezpečnostní infrastrukturou. Tento projekt generátoru statických webů v Rustu zachází s CSP, SRI, validací WCAG, strukturovanými metadaty, i18n ve 28 jazycích, lokálními LLM pipeline, WebAssembly ostrovy a streamovanou kompilací jako s výchozím chováním — nikoli jako se zásuvnými moduly, na které si musíte vzpomenout. Web, který právě čtete, byl postaven právě s ním.

Klíčové body:

  • Statický web neznamená bezpečný. CSP, SRI, hygienizace obrázků, správnost metadat a kontroly nasazení stále platí.
  • Přístupnost patří do buildu. Validace WCAG 2.1 AA jako brána buildu, nikoli jako audit po publikaci.
  • Lokální LLM pipeline překonává neprůhledná API. Redakční workflow běžící na pracovní stanici drží koncepty, prompty i data v rozsahu.
  • i18n je prvotřídní cíl kompilace. 28 jazyků generovaných ve stejném průchodu jako EN, s paritou hreflang a slug-map.
  • Streamovaná kompilace škáluje. Více než 100 tisíc stránek za minuty s reprodukovatelným výstupem pro audit.

Mýtus bezpečnosti statických webů #

Statické weby odstraňují celé třídy serverového rizika, ale neeliminují bezpečnostní obavy. Generované stránky nadále načítají skripty, fonty, obrázky, analytiku, styly, kanály, metadata a aktiva třetích stran. Bezpečný generátor má pomáhat vynucovat bezpečné výchozí hodnoty, nikoli nechávat každý web, aby je objevoval znovu.

Publikování v éře AI #

AI mění publikování tím, že zvyšuje rychlost produkce obsahu. To činí kvalitu metadat, recenzní workflow, provenienci, lokalizaci, přístupnost a konzistenci důležitější, nikoli méně důležitou. Statický generátor, který rozumí lokálním LLM workflow, dokáže podpořit produktivitu, aniž by celou pipeline předal externí černé skříňce.

Proč se k problému hodí Rust #

Rust je dobrou volbou pro generátor, který potřebuje rychlost, bezpečnost, streamovanou kompilaci, deterministický výstup a ergonomii příkazové řádky. Volba jazyka posiluje širší poselství projektu: publikační infrastruktura má být dostatečně spolehlivá, aby fungovala v institucionálním měřítku.
