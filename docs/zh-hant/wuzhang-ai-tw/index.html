Accessibility Statement

我們承諾為殘障人士提供數字無障礙訪問。

我們致力於為殘障人士提供數字無障礙訪問，並透過實施適當的無障礙措施持續改善使用者體驗。

支援無障礙的措施

我們力求讓站點對所有使用者儘可能可用，包括：

  • 站點的大部分內容可透過螢幕閱讀器訪問。
  • 跨頁面提供一致的導航。
  • 支援縮放至 400% 而不出現文字溢位。
  • 可透過瀏覽器擴充套件修改顏色、對比度和樣式。
  • 僅透過鍵盤即可瀏覽站點。
  • 為所有非文字內容提供文字替代。
  • 支援語音識別軟體輔助導航。

我們也對站點文字進行了簡化以便理解。

我們的合規狀態

我們承認站點的部分內容並不完全無障礙，但正在積極修正。我們的目標是符合 Web Content Accessibility Guidelines（WCAG）2.1 版本 AA 級別。您可能會遇到以下問題：

  • 影象缺少對輔助技術有用的文字替代。
  • 對色盲使用者而言對比度不足。
  • 缺少鍵盤導航所需的隱藏連結。
  • 未標記的連結在新標籤頁中開啟但未做提示。

反饋問題

如遇到無障礙方面的障礙，請透過聯絡頁面告知我們。我們承諾儘快回覆。

Sebastien Rousseau
