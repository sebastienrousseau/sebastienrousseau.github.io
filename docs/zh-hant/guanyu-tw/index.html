Sebastien Rousseau

透過人工智慧、後量子密碼學與區塊鏈技術的戰略整合，塑造銀行業與金融服務業的未來。

簡介

Sebastien Rousseau 是一位兼具技術與業務背景的高階管理者，擁有 20 多年的支付科技與數字金融未來經驗。他熱衷於透過戰略性整合人工智慧（AI）、後量子密碼學（PQC）與區塊鏈技術，設計下一代銀行與支付產品。

作為滙豐銀行的高階產品經理，Sebastien 成功主導了多款創新產品與服務的研發與釋出，包括滙豐 Treasury API 與滙豐 Banking-as-a-Service（BaaS）產品。這些面向企業客戶的全球解決方案，致力於為滙豐客戶提供無縫的數字體驗。

在加入滙豐之前，Sebastien 在多個複雜的移動專案中擔任關鍵角色，主導設計與運營改進。他曾就職於巴克萊銀行、Shazam Entertainment 與 PayPal。他在倫敦 AKQA 啟動職業生涯，負責移動技術部門，服務過 Nike、RBS、MTV、GAP、Nokia、Target 等全球重要客戶，並主導多項創新移動專案。

Sebastien 在銀行業、金融服務與科技領域的多元經驗，使他成為任何尋求創新與數字轉型組織的寶貴資產。他的戰略與技術雙重視角，可彌合業務需求與技術實施之間的鴻溝，確保解決方案既高效又契合組織目標。

專長領域

  • 支付與結算 — ISO 20022、跨境支付、SEPA Instant、SWIFT gpi。
  • 應用人工智慧 — 生成式人工智慧、大語言模型、銀行運營自動化。
  • 後量子密碼學 — NIST PQC 演算法、協議遷移、長期金融安全。
  • 開源 — 面向金融的 Python 與 Rust 庫（pain001、pacs008、dtt、hsh、kyberlib、shokunin）。
