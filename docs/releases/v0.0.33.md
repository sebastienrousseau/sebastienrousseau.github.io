# sebastienrousseau.github.io 0.0.33

## Highlights ⭐️

* **One fluid type scale**: every heading, lead, body, card, meta and eyebrow on every template uses one of 14 size tokens that scale smoothly from phone to large screen. At 1440 px the H1 on the eleven key pages goes from seven sizes to two.
* **Tag landings in the reader's language**: tag names and descriptions in the 10 indexed locales, with English as the fallback, pending owner review of every string.
* **Search monitoring and a redirect gate**: a weekly Search Console report that raises an issue on a 30% drop, and a CI check that the Worker's 3,170 redirects match the build.
* **Layouts follow the theme again**: the theme now reproduces `_layouts/` exactly, and CI fails if they drift.
* **Design system v2 (`assets/css/design-system.css`)**: wraps each shell stylesheet in `@layer legacy` and appends an unlayered design system with three column widths (`--max`, `--measure`, `--max-wide`) and a 14-step fluid `clamp()` type scale (`--fs-micro` to `--fs-stat`), verified by `.github/ci-tools/visual/design-system.mjs` across 14 routes and 5 viewport widths.
* **Editorial and SEO polish**: synchronises the homepage proof-rail `Updated` stamp from `_data/proof/metrics.json`, renders canonical taxonomy labels on tag pills, gives `/privacy/`, `/terms/`, `/editorial/`, and `/glossary/` distinct H1s, and enforces zero duplicate `<title>` elements across all 35 locales (`scripts/seo_and_audit/check_unique_titles.py`).
* **Live-content drift gate (`scripts/seo_and_audit/check_live_content.py`)**: checks hub markers, unlayered design-system CSS, proof-rail stamp age, RSS item presence on `/` and `/articles/`, and legal H1s in `.github/workflows/deploy-drift.yml`.
* **First-party telemetry (`workers/events.js` and `assets/js/vendor/web-vitals.js`)**: cookie-free `POST /api/event` endpoint writing conversion events and real-user Core Web Vitals (`vital_lcp`, `vital_inp`, `vital_cls`) to Cloudflare Analytics Engine, with a weekly SQL summary script (`scripts/seo_and_audit/events_report.py`).
