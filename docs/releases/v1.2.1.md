# sebastienrousseau.com 1.2.1

This release delivers canonical governance, consolidated documentation, typography polish, and hardened verification.

It establishes gold-standard operational health across build, security, and edge delivery pipelines.

## Highlights ⭐️

* **Governance and Invariants**: Canonical repository standard with dedicated AGENTS.md, DEVELOPMENT.md, SUPPORT.md, and SSH-signed git commit verification.
* **Consolidated Documentation**: Single authoritative documentation root under `docs/` with automated internal and external link resolution gates.
* **Typography and Identity**: Uniform typography standard with zero em dashes across markdown, codebase comments, and configuration.
* **Release Verification**: Automated version consistency verification checking `pyproject.toml`, `CITATION.cff`, `CHANGELOG.md`, and release artifacts.
