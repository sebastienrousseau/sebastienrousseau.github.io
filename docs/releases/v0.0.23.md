# sebastienrousseau.github.io 0.0.23

## Highlights ⭐️

* **PDF service on Pillow 13 ([#503])**: The PDF render service lock moves pillow 12.3.0 to 13.0.0 (37 decoder and parser advisories), brotli 1.2.0 to 1.2.1 (two decoder out-of-bounds writes) and werkzeug 3.1.8 to 3.1.9 (`safe_join`), with certifi and urllib3. WeasyPrint 70 still renders PDFs with embedded images.
* **CI tooling lock patched ([#503])**: certifi (a revoked eMudhra root), filelock and urllib3 move to their fixed releases. Both Python locks now audit clean with `pip-audit`.
* **Shared postbuild names made public ([#503])**: 19 cross-module regexes and helpers in `article_furniture.py` lose their leading underscore, so CodeQL no longer reports them as unused and an edit to one no longer re-raises a dismissed alert. No behaviour changes.

## What's Changed

* fix(deps): patch advisories in the Python locks by @sebastienrousseau in https://github.com/sebastienrousseau/sebastienrousseau.github.io/pull/503
