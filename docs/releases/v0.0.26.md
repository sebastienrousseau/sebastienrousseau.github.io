# sebastienrousseau.github.io 0.0.26

## Highlights ⭐️

* **Four October 2026 articles and landscape banner guard ([#509])**: publishes the four late-October 2026 articles (`2026-10-24-an-ai-s-attack-on-progression-free-sets-a-ledger-of-what-stalled`, `2026-10-25-agentic-ai-breaks-the-assumption-behind-every-task-exposure-forecast`, `2026-10-26-mystery-seeds-behind-nist-curves-were-never-hashes-claude`, and `2026-10-28-why-the-fca-is-regulating-ai-without-an-ai-rulebook`) across all 35 languages, enforces landscape-only (`width > height`) WebP selection in `pick_banner.py`, and replaces seven portrait stock banners with `2584x1597` landscape photographs.
* **ISO 20022 MCP Suite architecture matrix, 2027 FAQ, and SEO metadata ([#509])**: adds the 9-server architecture and clearing rail matrix, a 6-question FAQ accordion on 2026-2027 SWIFT CBPR+ structured/hybrid postal addresses and November 2027 E&I (`camt.056`/`camt.029`), and `SoftwareApplication` + `FAQPage` JSON-LD to `/iso20022-mcp/`, while repairing `og:image`, `twitter:image`, `og:description`, and `twitter:description` across `story` and `page` layouts.
* **PDF renderer SSRF guard, edge API security headers, and canonical Agent API URLs ([#509])**: hardens WeasyPrint subresource fetching in `fly/pdf-render/app.py` with host/scheme allowlisting, a 10 MiB payload cap, in-memory font/CSS LRU caching, and optional `X-Origin-Verify` authentication; wraps early-return Cloudflare Worker API routes (`/mcp/v1/*`, `/api/pdf/*`, `/api/clock/*`, ActivityPub) with `withApiSecurityHeaders`; and moves `build_agent_api.py` after `postbuild.py` in `build.sh` while emitting canonical trailing-slash URLs.
* **Ruff 0.17.2 locked and GitHub Actions updated ([#507], [#508])**: pairs Dependabot's `ruff` 0.17.2 bump with a regenerated `requirements-dev.lock`, updates `actions/setup-python` to 7.1.0 across seven workflows, and updates `github/codeql-action` to 4.39.1.
* **CI tooling advisories patched**: upgrades `msgpack` to 1.2.3 in `requirements-dev.lock` (CVE-2026-114613) and `qs` to 6.17.0 in `.github/ci-tools/lighthouse/` (GHSA-6pq8-jhm2-2vcw), keeping `pip-audit` and `npm audit` at zero vulnerabilities.
