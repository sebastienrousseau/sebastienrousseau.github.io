# sebastienrousseau.github.io 0.0.25

## Highlights ⭐️

* **A steady first view on desktop**: the home page no longer moves when its "Read as" control appears; the control's space is held from the first paint, which takes the desktop layout shift from 0.0032 to 0.
* **An accessibility check that passes at any hour**: the hero clock's digit drums now hold two labels each instead of every value, so the minute hand's layout box stays at its badge and no longer covers the headline, where axe could not measure its contrast at some times of day.
