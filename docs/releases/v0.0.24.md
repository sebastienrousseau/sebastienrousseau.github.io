# sebastienrousseau.github.io 0.0.24

## Highlights ⭐️

* **Banner picker on the live CDN layout ([#504])**: `pick_banner.py` finds the `cloudcdn.pro` checkout beside this one, prints direct `/stocks/images/` URLs instead of the closed `/api/transform` endpoint, and no longer offers responsive size variants as banners.
* **Locale slugs follow translated titles ([#504])**: `translate_post.py --rederive-slugs` renames each translated post to the slug its own title derives and updates `slugs.json`; the romanisation lexicon gains 45 words so Japanese, Chinese, Thai, Arabic and Hebrew titles derive readable slugs.
* **Localised labels in new stubs ([#504])**: locale stubs now carry each language's accessible names for the post-lead summary and author card from the first commit, instead of the English ones.
