# sebastienrousseau.github.io 0.0.31

## Highlights ⭐️

* **One column system across every template**: three column widths (`--col-wide` 1200px, `--col-read` 692px, `--col-mid` 960px for centred display headings only) and one fluid gutter (20px at 390px, 60px at 1440px, 80px from 1920px) replace the ad-hoc container widths in the shared stylesheet. The nav, the H1 and the main column of every left-aligned template now share one content edge at every width; centred heroes stay centred on the same axis.
