futuro della finanza.

Un portfolio di librerie Python, Rust e JavaScript che ho creato e mantengo. Open source, di uso libero, applicate ai pagamenti wholesale, al regolamento transfrontaliero, ai dati finanziari e alla crittografia resistente al quantum.

Python · Pagamenti

pain001

Una libreria Python che automatizza la creazione di file di pagamento ISO 20022 pain.001 da CSV o SQLite. Pensata per la migrazione globale da MT/MX a messaggi strutturati su SWIFT, SEPA e i principali schemi.

Python · Transfrontaliero

pacs008

Genera, valida e consegna messaggi ISO 20022 pacs.008 di bonifico tra istituzioni finanziarie. JSON Schema, validazione XSD, IBAN in 75 paesi, mascheramento dei dati personali conforme a GDPR/PCI-DSS.

KyberLib
