有问题？ 有答案。

这些项目以何种许可证发布？

所有项目均以 Apache-2.0 许可证发布。每个仓库根目录下的 LICENSE 文件是权威来源。

这些项目可用于生产环境吗？

视项目而定。标记为 v1.x 的库已稳定并经过负载测试；v1 之前的库是稳固的基础，但仍可能演进。每个仓库的 README 会说明当前状态；如需针对生产场景的具体保证，请联系我。

如何贡献代码或反馈问题？

每个项目都有公开的 GitHub 仓库，位于 github.com/sebastienrousseau。请开 issue 描述问题（提供最小复现示例尤佳），或在关联 issue 后提交 pull request。贡献遵循 Developer Certificate of Origin，并要求签名提交。

这些库可用于受监管的银行环境吗？

可以，但需遵循惯常的尽职流程。这些库是独立的开源作品，并非受监管产品。在将其部署到任何支付基础设施的生产环境前，请按贵机构常规的供应链、安全与依赖审查流程处理——例如通过内部镜像进行 vendoring、SBOM 扫描、按 Git SHA 或加密指纹固定版本等。

您提供商业支持或咨询服务吗？

提供，按个案筛选。委托范围涵盖 ISO 20022 迁移、后量子迁移路线图，以及应用于金融服务的人工智能。请联系我，并附简短说明、时间表与相关约束。

如何关注新发布？

本站的每篇带日期文章都会通过 RSS 订阅源 与 Banking On Quantum 通讯发布。各仓库也会在 GitHub 上发布 release，可直接关注。
