भुगतान और निपटान।

ISO 20022 pain.001 और pacs.008 टूलकिट, बैंक-स्टेटमेंट पार्सिंग, और संरचित सीमा-पार संदेशों की माइग्रेशन हेतु Rust लाइब्रेरियाँ। SWIFT, SEPA और वास्तविक-समय भुगतान-योजनाओं के लिए डिज़ाइन।

पोस्ट-क्वांटम क्रिप्टोग्राफी।

प्रश्न? उत्तर।

ये परियोजनाएँ किस लाइसेंस के तहत प्रकाशित हैं?

सभी परियोजनाएँ Apache-2.0 लाइसेंस के तहत प्रकाशित हैं। प्रत्येक रिपॉज़िटरी की जड़ में मौजूद LICENSE फ़ाइल आधिकारिक स्रोत है।

क्या ये परियोजनाएँ उत्पादन के लिए तैयार हैं?

यह परियोजना पर निर्भर करता है। v1.x के रूप में चिह्नित लाइब्रेरियाँ स्थिर हैं और भार के अंतर्गत परीक्षित हैं; पूर्व-v1 ठोस आधार हैं लेकिन विकसित हो सकती हैं। प्रत्येक रिपॉज़िटरी का README वर्तमान स्थिति का विवरण देता है; यदि आपको उत्पादन-उपयोग हेतु विशिष्ट गारंटी चाहिए, तो कृपया संपर्क करें।

मैं योगदान कैसे करूँ या किसी समस्या की सूचना कैसे दूँ?

प्रत्येक परियोजना का सार्वजनिक GitHub रिपॉज़िटरी github.com/sebastienrousseau पर उपलब्ध है। समस्या का वर्णन करते हुए एक issue खोलें (न्यूनतम पुनरुत्पादक का स्वागत है) या किसी issue से जुड़ी एक pull request भेजें। योगदान Developer Certificate of Origin द्वारा शासित होते हैं और हस्ताक्षरित कमिट्स की आवश्यकता होती है।

क्या मैं इन लाइब्रेरियों का उपयोग विनियमित बैंकिंग-वातावरण में कर सकता हूँ?

हाँ, सामान्य सावधानियों के साथ। लाइब्रेरियाँ स्वतंत्र ओपन-सोर्स कार्य हैं, कोई विनियमित उत्पाद नहीं। भुगतान-अवसंरचना पर उत्पादन-तैनाती से पहले अपनी सामान्य सप्लाई-चेन, सुरक्षा और निर्भरता-समीक्षा प्रक्रियाएँ लागू करें — अपने आंतरिक मिरर के माध्यम से वेंडरिंग, SBOM स्कैनिंग, Git SHA या क्रिप्टोग्राफिक हस्ताक्षर से पिनिंग।

क्या आप व्यावसायिक समर्थन या परामर्श प्रदान करते हैं?

हाँ, पूर्व-चयन के साथ। सौंपे जाने वाले कार्य ISO 20022 माइग्रेशन, पोस्ट-क्वांटम माइग्रेशन-मार्ग और वित्तीय-सेवाओं हेतु व्यावहारिक AI से संबंधित होते हैं। संक्षिप्त ब्रीफ़, कैलेंडर और लागू बाधाओं के साथ संपर्क करें।

नए रिलीज़ की जानकारी कैसे रखें?

साइट का प्रत्येक दिनांकित लेख RSS फ़ीड और Banking On Quantum न्यूज़लेटर के माध्यम से घोषित किया जाता है। व्यक्तिगत रिपॉज़िटरी भी GitHub पर रिलीज़ प्रकाशित करते हैं जिन्हें आप सीधे फ़ॉलो कर सकते हैं।
