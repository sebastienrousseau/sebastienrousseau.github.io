Àkàndé: GPT-Powered Voice Assistant for Executives

Architectuur van een open-source Python-spraakassistent: Whisper, GPT-4, SQLite-cache en fpdf2

Managementsamenvatting / Kernpunten

  • Àkàndé ⧉ is een open-source Python spraakassistent die OpenAI Whisper voor spraak-naar-tekst, GPT-4 chatcompletions, een lokale SQLite-antwoordcache en fpdf2 PDF-export combineert tot één spraakgestuurd workflow dat geen cloudopslag en geen lokale AI-modelgewichten vereist.
  • De SQLite-cache slaat SHA-256 hashes van genormaliseerde querystrings op die zijn gekoppeld aan ruwe API-antwoordtekst; cache-treffers kosten nul tokens en retourneren in minder dan 10 ms, waardoor herhaalde queries (zoals het herzien van een eerder in een vergadering genomen beslissing) vrijwel gratis zijn.
  • Meerturngesprek wordt bijgehouden door de messages-lijst in het geheugen op te bouwen en deze bij elke Chat Completions API-aanroep door te geven — het model ontvangt de volledige sessiegeschiedenis zodat het kan verwijzen naar eerdere uitwisselingen, ten koste van een incrementeel toenemend tokengebruik per beurt.
  • PDF-samenvattinggeneratie serialiseert de messages-lijst van de sessie naar een opgemaakt fpdf2-document: gebruikers- en assistentbeurten zijn gelabeld, tijdstempels worden ingevoegd en automatische paginering verwerkt sessies van elke lengte; het bestand wordt naar het lokale bestandssysteem geschreven, niet geüpload.
  • Privacygrens: alleen de actieve query (en de sessiegeschiedenis tot de contextvenstergrens) verlaat het apparaat — geen audio-opnamen, geen transcripties en geen gecachte antwoorden worden verzonden naar een andere externe dienst dan de API van OpenAI.

Àkàndé ⧉ is een open-source Python spraakassistent gebouwd rond drie modulaire componenten: OpenAI Whisper voor spraakherkenning, de GPT-4 Chat Completions API voor taalbegrip en -generatie, en een lokale SQLite-database voor het cachen van antwoorden en sessiepersistentie. Het resultaat is een spraakgestuurd workflow dat op een laptop kan worden uitgevoerd zonder lokale modelgewichten, offline opslaginfrastructuur of een containerstack.

Dit artikel beschrijft de technische architectuur van elk component, de ontwerpbeslissingen rond caching en meerturncontext, en de PDF-exportpipeline.

Pipelineoverzicht #

Een enkele Àkàndé-interactie volgt deze volgorde:

  1. Audio-opname — de gebruiker spreekt; de applicatie neemt audio op in een tijdelijk WAV-bestand met sounddevice of een compatibele audiobibliotheek.
  2. Spraak naar tekst — het WAV-bestand wordt ingediend bij openai.audio.transcriptions.create() (Whisper API); het transcript wordt teruggegeven als een eenvoudige string.
  3. Cache-zoekopdracht — het transcript wordt genormaliseerd (kleine letters, witruimte samengevouwen) en SHA-256 gehasht; de hash wordt opgezocht in de lokale SQLite-tabel response_cache.
  4. API-aanroep of cache-treffer — bij een mislukking wordt het transcript toegevoegd aan de messages-lijst van de sessie en verzonden naar openai.chat.completions.create(); de antwoordtekst wordt opgeslagen in de cache.
  5. Tekst naar spraak — de antwoordtekst wordt omgezet naar audio met het eindpunt openai.audio.speech.create() (TTS) of een lokale TTS-bibliotheek, en afgespeeld.
  6. PDF-export (op aanvraag) — de volledige messages-lijst wordt geserialiseerd naar een opgemaakt fpdf2-document en naar schijf geschreven.

OpenAI-integratie: Chat Completions en Whisper #

Àkàndé gebruikt de Python SDK openai voor zowel spraakherkenning als tekstgeneratie. De Whisper-transcriptieaanroep:

with open(audio_file_path, "rb") as f:
    transcript = openai.audio.transcriptions.create(
        model="whisper-1",
        file=f,
        language=None  # auto-detect
    )
user_text = transcript.text

De Chat Completions-aanroep onderhoudt een sessiescoped messages-lijst:

messages.append({"role": "user", "content": user_text})

response = openai.chat.completions.create(
    model="gpt-4-turbo-preview",
    messages=messages,
    temperature=0.2,
    max_tokens=1024
)

assistant_text = response.choices[0].message.content
messages.append({"role": "assistant", "content": assistant_text})

De systeemprompt wordt eenmalig aan het begin van de sessie toegevoegd en bepaalt Àkàndé's persona, uitvoerformaat en domeinspecifieke beperkingen:

messages = [
    {
        "role": "system",
        "content": (
            "You are Àkàndé, a concise executive assistant. "
            "Respond in plain prose. Do not use markdown. "
            "If asked to summarise, produce three bullet points maximum."
        )
    }
]

Het instellen van temperature=0.2 ruilt creatieve variatie in voor determinisme — belangrijk voor feitelijke queries zoals het ophalen van een eerder in de sessie genomen beslissing.

SQLite-antwoordcache #

Het cacheschema is minimaal:

CREATE TABLE IF NOT EXISTS response_cache (
    query_hash  TEXT PRIMARY KEY,
    response    TEXT NOT NULL,
    created_at  INTEGER NOT NULL  -- Unix timestamp
);

Het opzoek- en schrijfpad:

import hashlib, sqlite3, time

def _normalise(text: str) -> str:
    return " ".join(text.lower().split())

def cache_get(conn: sqlite3.Connection, query: str) -> str | None:
    h = hashlib.sha256(_normalise(query).encode()).hexdigest()
    row = conn.execute(
        "SELECT response FROM response_cache WHERE query_hash = ?", (h,)
    ).fetchone()
    return row[0] if row else None

def cache_set(conn: sqlite3.Connection, query: str, response: str) -> None:
    h = hashlib.sha256(_normalise(query).encode()).hexdigest()
    conn.execute(
        "INSERT OR REPLACE INTO response_cache VALUES (?, ?, ?)",
        (h, response, int(time.time()))
    )
    conn.commit()

INSERT OR REPLACE zorgt ervoor dat een gecached antwoord wordt bijgewerkt als dezelfde query wordt ingediend na een modelupgrade. Een TTL-gebaseerde verwijderingsquery (DELETE WHERE created_at < ?) kan bij opstarten worden gepland om de cachegrootte te beperken.

Cache-trefferprestaties: een SQLite-zoekopdracht op een lokale SSD retourneert in minder dan 1 ms voor tabellen tot ~100.000 rijen. De round-trip latentie voor een live GPT-4 API-aanroep is doorgaans 600–900 ms voor korte antwoorden. Voor een dagelijkse briefing met een handvol herhaalde queries elimineert de cache na de eerste sessie de meeste API-aanroepen.

PDF-samenvattinggeneratie #

PDF-export gebruikt fpdf2, een onderhouden Python PDF-bibliotheek zonder binaire afhankelijkheden:

from fpdf import FPDF
from datetime import datetime

def export_session_pdf(messages: list[dict], output_path: str) -> None:
    pdf = FPDF()
    pdf.add_page()
    pdf.set_font("Helvetica", size=11)
    pdf.set_margins(20, 20, 20)

    pdf.set_font("Helvetica", "B", 14)
    pdf.cell(0, 10, f"Àkàndé Session — {datetime.now():%Y-%m-%d %H:%M}", ln=True)
    pdf.ln(4)

    for msg in messages:
        if msg["role"] == "system":
            continue
        label = "You" if msg["role"] == "user" else "Àkàndé"
        pdf.set_font("Helvetica", "B", 10)
        pdf.cell(0, 6, label, ln=True)
        pdf.set_font("Helvetica", size=10)
        pdf.multi_cell(0, 5, msg["content"])
        pdf.ln(3)

    pdf.output(output_path)

multi_cell() verwerkt regelafbreking en automatische pagina-einden, zodat sessies van elke lengte een goed opgemaakt document produceren zonder handmatige pagineringlogica. De uitvoer is een PDF/A-compatibel bestand zonder ingesloten lettertypen buiten de standaard Helvetica-metrieken.

Privacymodel #

De privacygrens in Àkàndé wordt bepaald door drie feiten:

  1. Audio wordt via HTTPS ingediend bij de Whisper API en wordt door OpenAI niet bewaard buiten de API-aanroep (conform het API-gegevensgebruiksbeleid van OpenAI van februari 2024).
  2. Chat Completions API-aanroepen verzenden de messages-lijst van de sessie — die de volledige gespreksgeschiedenis kan bevatten voor meerturnssessies.
  3. De SQLite-database en PDF-bestanden bevinden zich volledig op het lokale bestandssysteem; er vindt geen achtergrondssynchronisatie met een cloudservice plaats.

Voor uitvoerende gebruiksscenario's met gevoelige onderwerpen — M&A-besprekingen, personeelszaken, regulatoire strategie — moet de sessiegeschiedenis die naar de API wordt verzonden worden beoordeeld aan de hand van het AI-gebruiksbeleid van de organisatie alvorens te implementeren. De max_tokens-limiet op de systeemprompt kan worden gebruikt om onbedoelde overdracht van context te voorkomen die de beoogde openbaarmakingsomvang overschrijdt.

Veelgestelde vragen #

Bewaart Àkàndé de gespreksgeschiedenis nadat de sessie is beëindigd? De messages-lijst in het geheugen wordt verwijderd wanneer het proces eindigt. De gespreksgeschiedenis wordt alleen bewaard als de gebruiker een PDF-export activeert of als een aangepaste persistentielaag wordt toegevoegd. De SQLite-cache slaat queryhashes en antwoordtekst op, niet de volledige gesprekscontext.

Hoe gaat de cache om met queries die vergelijkbaar maar niet identiek zijn? De cache gebruikt exact-match hashing op de genormaliseerde querystring. Twee queries die één woord van elkaar verschillen, produceren verschillende hashes en resulteren in afzonderlijke API-aanroepen. Semantisch cachen (waarbij embedding-gelijkenis wordt gebruikt om bijna-dubbele queries te matchen) vereist een extra vectorzoekstap en maakt geen deel uit van de basisimplementatie.

Welk GPT-model gebruikt Àkàndé standaard? De standaard is gpt-4-turbo-preview vanaf februari 2024. De modelnaam is een configuratieparameter, dus elk OpenAI chatcompletionmodel kan worden vervangen. Overschakelen naar gpt-3.5-turbo verlaagt de API-kosten met ongeveer 20× per token, maar vermindert de redeneerqualiteit voor complexe meerstapse queries.

Kan het PDF-exportformaat worden aangepast? Ja. De fpdf2-exportfunctie accepteert de messages-lijst als enige vereiste invoer, zodat lettertype, marges, paginagrootte, koptekstinhoud en labeling allemaal kunnen worden gewijzigd door de exportfunctie te bewerken. fpdf2 ondersteunt ook het toevoegen van afbeeldingen, tabellen en Unicode-lettertypen, waardoor rijkere documentlay-outs mogelijk zijn voor organisaties met specifieke merkvereisten.
