## What's in place

### Security (Phase 4)
- Strict CSP per page: `script-src 'self' <per-page sha256-...> <CDN allowlist>`. Inline JSON-LD is allowed strictly by hash, not by `'unsafe-inline'`.
- Real SRI on every `/_csp/*` asset (`scripts/postbuild.py` computes base64 SHA-256 at build time and rewrites the integrity attribute).
- `public/_headers` ships HSTS preload, X-Content-Type-Options, Referrer-Policy strict-origin-when-cross-origin, COOP same-origin, CORP same-origin, X-Frame-Options SAMEORIGIN, and immutable cache for fingerprinted assets.
- `public/.well-known/security.txt` with disclosure address and 2027 expiry.
- Permissions-Policy meta + header opt-outs for browsing-topics, interest-cohort, join-ad-interest-group, run-ad-auction, attribution-reporting.

### SEO technical (Phase 3)
- Per-page Schema.org JSON-LD wrapped in `@graph` with `BreadcrumbList`:
  - `/` — Person + WebSite + ProfilePage (alumniOf: PayPal, Barclays, Shazam, AKQA, Virgin Group; knowsAbout: 11 topic keywords; sameAs: 5 social profiles).
  - `/about/` — AboutPage referencing the Person `@id`.
  - `/contact/` — ContactPage.
  - `/articles/`, `/papers/`, `/projects/`, `/playlists/` — CollectionPage with topic `about`.
  - Every dated blog post — BlogPosting with full publisher, ImageObject, datePublished, dateModified, keywords, articleSection, mainEntityOfPage.
- Sitemap.xml, news-sitemap.xml, RSS, Atom auto-generated by Shokunin.
- Canonical, hreflang, OG, Twitter cards from frontmatter on every page.

### Accessibility (Phase 2)
- WCAG AAA contrast tokens (`--ink` ≥ 16.5:1, `--ink-soft` ≥ 11:1, `--ink-mute` ≥ 7.4:1 against the active background).
- 44 × 44 touch targets on every interactive (theme toggle, search button, burger, "Back to top").
- Visible focus ring (3 px outline + 6 px soft halo, recolored on dark sections).
- `aria-live="polite"` region announces theme changes ("Dark theme on" / "Light theme on").
- Skip link to `#main`.
- `prefers-reduced-motion` blanket override for animations, transitions, and `smooth` scroll.

### Content (Phase 5)
- Every dated blog post (38 articles) carries `excerpt` (≤ 200 chars derived from first prose) and `last_reviewed` (auto-stamped) frontmatter.
- A "Last reviewed" badge appears on each article body.
- A "Related reading" block (top-3 by tag overlap) appears at the bottom of each article. Idempotent: `scripts/post_enrich.py` re-runs cleanly.
- EPAA expanded to **Emerging Payments Association Asia (EPAA)** linked to `https://emergingpaymentsasia.org/` on first mention in `/`, `/about/`, `/papers/`, and the EPAA article itself.

### Visual (Phase 6)

- Reading-progress bar via CSS `scroll-timeline` (`.ap-progress` at the top of every page). Browsers without scroll-timeline support get a static thin bar.
- IntersectionObserver fade-up on `.reveal` blocks (home sections wear it).
- Dark theme tokens tuned: `--bg #000`, `--card #161617`, AAA-compliant text.

### UX (Phase 7)
- Back-to-top floating action: appears after one viewport height, smooth-scrolls (or instant under `prefers-reduced-motion`).
- Per-page related-articles grid (3 cards) at the bottom of every blog post.
- In-nav search button (forwards to Shokunin's modal via `main.js`).
- Nav: 3-column grid — brand left, menu visually centred, theme + search + Get-in-touch right.

## Phase 1 — performance (now in place)

- Service-worker rewrite (`_layouts/sw.js`): network-first for HTML with offline fallback, stale-while-revalidate for fingerprinted assets + same-origin images, pass-through for cross-origin.
- LCP candidates on every key page carry `loading="eager"` + `fetchpriority="high"`. All other images carry `loading="lazy"` + `decoding="async"` + explicit `width`/`height`.
- Browser caching via `public/_headers` — immutable 1 year on fingerprinted `/_csp/*` / `main.*.js` / `theme-init.*.js`, 5-minute revalidate on HTML + unfingerprinted aliases.
- Reading-progress bar uses CSS `scroll-timeline` (no JS scroll listener) with graceful no-animation fallback.
- IntersectionObserver-driven reveal is rootMargin-tuned and `unobserve`s after first trigger to avoid event work.

## Browser-compat fallbacks (now in place)

- `aspect-ratio` → padding-top reservation via `@supports not (aspect-ratio: 1/1)` for Safari < 15 / Chromium < 88.
- `color-mix()` → pre-computed RGBA fallback for the frosted nav; `@supports (background: color-mix(...))` upgrades when available.
- `:has()` → mobile burger keeps the menu collapsed and dims itself when the engine lacks selector support.
