# Support Guidelines

Thank you for exploring `sebastienrousseau.com`. This document explains the available support channels and how to report issues or ask questions.

---

## 1. Questions and Discussion

If you have questions about the research, payment architecture, or post-quantum cryptography topics published on the site:

* **Email**: You can contact the author directly at [sebastian.rousseau@gmail.com](mailto:sebastian.rousseau@gmail.com).
* **Social**: Reach out via LinkedIn or Bluesky as linked in the website footer.

---

## 2. Bug Reports and Corrections

If you discover a typo, a factual error in an article, broken internal navigation, or a defect in the static site generation pipeline:

* **GitHub Issues**: Open an issue using the relevant issue template at [Issues](https://github.com/sebastienrousseau/sebastienrousseau.github.io/issues).
* **Pull Requests**: For small documentation or editorial fixes, open a pull request targeting the active release iteration branch (`feat/v<next-version>`).

Please check existing open and closed issues before submitting a new report.

---

## 3. Security Vulnerabilities

Please **do not** use public GitHub issues to report suspected security vulnerabilities or privacy concerns.

Follow the instructions in [SECURITY.md](SECURITY.md):
* Email details to [sebastian.rousseau@gmail.com](mailto:sebastian.rousseau@gmail.com).
* PGP public key available at [/.well-known/openpgpkey/hu/](https://sebastienrousseau.com/.well-known/openpgpkey/hu/).
* Initial acknowledgement provided within 48 hours.
