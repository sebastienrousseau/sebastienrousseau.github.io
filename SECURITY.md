# Security policy

Report vulnerabilities privately to **sebastian.rousseau@gmail.com** (PGP key at [`/.well-known/openpgpkey/hu/`](https://sebastienrousseau.com/.well-known/openpgpkey/hu/)). Machine-readable disclosure metadata lives at [`/.well-known/security.txt`](https://sebastienrousseau.com/.well-known/security.txt) per [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).

The full threat model, supported-version matrix, and disclosure timeline live in [`project-docs/security.md`](project-docs/security.md). See [`/about/#security`](https://sebastienrousseau.com/about/#security) for the public-facing acknowledgement page.

Please do **not** open a public GitHub issue for a suspected vulnerability — email first, then we'll coordinate disclosure.
