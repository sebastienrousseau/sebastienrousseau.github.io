## அணுகக்கூடிய மற்றும் நெறிமுறைசார் ML மேம்பாட்டிற்கான Google இன் புரட்சிகர திறந்த மூல AI மாதிரி

Google சமீபத்தில் [**Gemma ⧉**][00] ஐ அறிமுகப்படுத்தியது; இது AI மேம்பாட்டிற்கு அணுகக்கூடிய மற்றும் நெறிமுறைசார் அடித்தளத்தை வழங்க வடிவமைக்கப்பட்ட ஒரு திறந்த மூல செயற்கை நுண்ணறிவு மாதிரி. ஒரு திறந்த மூல மாதிரியாக, Gemma தனது முழு கட்டமைப்பையும், பயிற்சி முறையையும், மாதிரி எடைகளையும், அளபுருக்களையும் அனுமதிக்கப்பட்ட உரிமங்களின் கீழ் வழங்குகிறது; இதனால் வெளிப்புற ஆராய்ச்சியாளர்களும் உருவாக்குநர்களும் அவற்றை சுதந்திரமாக அணுகவும், கற்றுக்கொள்ளவும், அதன் மீது கட்டமைக்கவும், தங்கள் தனித்துவமான தேவைகளுக்கு ஏற்ப தனிப்பயனாக்கவும் முடியும். இந்த வெளிப்படையான அணுகுமுறை, பொறுப்புணர்வைக் காக்கும் வகையில் Gemma இன் மேம்பாட்டு நடைமுறைகளை ஆய்வு செய்யவும் அனுமதிக்கிறது.

`Gemma 2B` மற்றும் `7B` போன்ற அமைப்புகளுடன், இது கைபேசி சாதனங்கள் முதல் மேகக்கணி உள்கட்டமைப்புகள் வரையிலான பரந்த அளவிலான பயன்பாடுகளுக்குச் சேவை செய்கிறது. திறந்த மூல சமூகத்திற்குள் Gemma இன் அறிமுகம், நெறிமுறைசார் AI மீது Google இன் உறுதியான உறுதிப்பாட்டைக் குறிக்கிறது; உலகெங்கிலும் உள்ள உருவாக்குநர்களுடன் புதுமையையும் ஒத்துழைப்பையும் வளர்க்கிறது.

இந்தக் கட்டுரை Gemma இன் கட்டமைப்பையும், macOS உடனான அதன் ஒருங்கிணைப்பையும், நிறுவன தீர்வுகளையும் பரந்த AI நிலப்பரப்பையும் மாற்றியமைக்கும் அதன் ஆற்றலையும் ஆராய்கிறது.

## Gemma ஐ புரிந்துகொள்ளுதல்

### Gemma இன் தொழில்நுட்ப கட்டமைப்பு

Google இன் Gemini கட்டமைப்பு Gemma ஐ ஊக்குவிக்கிறது, மேலும் இது இரண்டு முக்கிய அமைப்புகளில் கிடைக்கிறது:

- **Gemma 2B** மாதிரி குறைந்த நினைவக பயன்பாடு மற்றும் மின் நுகர்வுடன் சாதனத்தில் செயல்திறனுக்காக மேம்படுத்தப்பட்டுள்ளது. இது ஸ்மார்ட்போன்களில் உரையாடல் போட்கள் அல்லது ஸ்மார்ட் ஹோம் சாதனங்கள் போன்ற கைபேசி மற்றும் உட்பொதிக்கப்பட்ட பயன்பாடுகளுக்கு ஏற்றதாக ஆக்குகிறது.

- **Gemma 7B** மாதிரி பெரிய தரவுத்தொகுப்புகள் மற்றும் ஆவணங்களை பகுப்பாய்வு செய்தல் போன்ற மிகவும் சிக்கலான பணிகளுக்கு ஏற்ற கணிசமாக அதிக திறனைக் கொண்டுள்ளது. அதன் இருப்பிடம் தரவுத் தளங்களில் அனுமானங்களை இயக்கும் தரவு மையங்களும் மேகக்கணி உள்கட்டமைப்பும் ஆகும்.

இரண்டும் தனிப்பட்ட திட்டங்கள் முதல் நிறுவன தீர்வுகள் வரையிலான பயன்பாடுகளுக்கு பல்துறை AI கட்டமைப்புத் தொகுதிகளை வழங்குகின்றன.

### Gemma இன் பயிற்சியும் திறன்களும்

அதன் [**தொழில்நுட்ப அறிக்கை ⧉**][01] அடிப்படையில், Gemma மாதிரிகள் (2B மற்றும் 7B) மேம்பட்டவை; வலைத்தள உள்ளடக்கம், கணிதம் மற்றும் நிரலாக்கத்தை வலியுறுத்தும் மிகப்பெரிய தரவுத்தொகுப்புகளில் பயிற்சி பெற்றவை. இந்த மாதிரிகள், தங்கள் முன்னோடியான Gemini போலல்லாமல், பன்மொழி அல்லது பன்முக அம்சங்களுக்கு முன்னுரிமை அளிக்கவில்லை. அவை ஒரு விரிவான சொற்களஞ்சியத்தை உள்ளடக்கியுள்ளன, மேலும் ஒரு புதிய டோக்கனைசேஷன் அணுகுமுறையைப் பயன்படுத்துகின்றன; இது பல்வேறு தரவு வகைகளைக் கையாளுவதை மேம்படுத்துகிறது. மேற்பார்வையிடப்பட்ட கற்றல் மற்றும் மனித பின்னூட்டத்திலிருந்து பலப்படுத்தல் கற்றல் ஆகியவற்றை இணைக்கும் அவற்றின் அறிவுறுத்தல்-சீரமைப்பு, ஆங்கிலத்தில் மட்டுமே கவனம் செலுத்துகிறது; நுணுக்கமான உரை புரிதலுக்கும் உருவாக்கத்திற்கும் மேம்படுத்துகிறது. இந்த முறையியல் புதுமை, சிறப்புத் துறைகளில் அவற்றின் ஆற்றலை அடிக்கோடிட்டுக் காட்டுகிறது; மொழி மாதிரி பயிற்சியின் வளர்ந்து வரும் நிலப்பரப்பை எடுத்துக்காட்டுகிறது.

### Gemma மற்றும் திறந்த மூல சமூகம்

[**அனுமதிக்கப்பட்ட உரிமங்களின் ⧉**][03] கீழ் ஒரு திறந்த மூல வெளியீடாக, நெறிமுறைசார் AI ஒத்துழைப்பை மேம்படுத்துவதற்கான Google இன் உறுதிப்பாட்டையும் Gemma பிரதிபலிக்கிறது. வெளிப்புற உருவாக்குநர்கள் இப்போது Gemma ஐ ஒரு வெளிப்படையான முறையில் கட்டமைக்கவும், ஆய்வு செய்யவும், தனிப்பயனாக்கவும் முடியும்; இது அணுகலை ஜனநாயகப்படுத்தி பொறுப்புணர்வைக் காக்கிறது.

## macOS இல் Ollama உடன் Google Gemma ஐ ஒருங்கிணைத்தல்

[**Ollama ⧉**][02] என்பது macOS அமைப்பில் AI உதவியாளர்களை உள்ளூரில் ஆராய உதவும் ஒரு இடைமுகம் ஆகும். Apple இன் M தொடர் கணினிகளில் Gemma 2B மற்றும் 7B மாதிரிகளை அமைக்க நாம் இதைப் பயன்படுத்துவோம். macOS இல் Ollama உடன் Gemma ஐ ஒருங்கிணைக்கும் செயல்முறையின் வழியாக இந்த வழிகாட்டி உங்களை அழைத்துச் செல்லும்.

கணினியின் செயலி கட்டமைப்பை அச்சிட நீங்கள் uname கட்டளையைப் பயன்படுத்தலாம். Terminal ஐத் திறந்து இயக்கவும்:

```bash
uname -m
```

வெளியீடு `arm64` எனில், உங்களிடம் M தொடர் Mac உள்ளது. அது `x86_64` எனில், உங்களிடம் Intel Mac உள்ளது. இந்த வழிகாட்டி M தொடர் Mac களுக்கானது.

### சூழலை அமைத்தல்

#### 1. Python 3.8+, pip, venv நிறுவப்பட்டுள்ளதை உறுதிப்படுத்தவும்

தொடங்குவதற்கு முன், உங்கள் Mac இல் [**Python 3.8 ⧉**][04] அல்லது அதற்கு மேற்பட்ட பதிப்பு அமைக்கப்பட்டுள்ளதையும், `pip` மற்றும் `venv` கருவிகளையும் உறுதிசெய்யவும். பின்வரும் கட்டளைகளை Terminal இல் இயக்குவதன் மூலம் உங்கள் Python மற்றும் pip பதிப்புகளைச் சரிபார்த்து pip ஐ மேம்படுத்தலாம்:

```bash
python3 --version
pip3 --version
pip3 install --upgrade pip
```

#### 2. சார்புகளைத் தனிமைப்படுத்த ஒரு மெய்நிகர் சூழலை உருவாக்கவும்

Terminal ஐத் திறந்து, கணினி-முழுமையான தொகுப்புகளுடன் முரண்பாடுகளைத் தடுக்க ஒரு மெய்நிகர் சூழலை உருவாக்கவும்.

```bash
python3 -m venv gemma_env
source gemma_env/bin/activate
```

#### 3. macOS க்கான சமீபத்திய Ollama ஐ நிறுவவும்

அதிகாரப்பூர்வ இணையதளத்திலிருந்து macOS க்கான [**சமீபத்திய Ollama ⧉**][05] ஐப் பதிவிறக்கவும். Ollama பயன்பாட்டைப் பிரித்தெடுத்து உங்கள் Applications கோப்புறைக்கு நகர்த்தவும். அதைத் திறந்து அமைப்பு அறிவுறுத்தல்களைப் பின்பற்றவும்.

#### 4. Ollama நிறுவல் வெற்றிகரமாக இருந்ததை உறுதிப்படுத்தவும்

பின்வருவனவற்றை இயக்குவதன் மூலம் Ollama சரியாக நிறுவப்பட்டுள்ளதா எனச் சரிபார்க்கவும்:

```bash
ollama --version
```

Ollama இன் பதிப்பு அச்சிடப்படுவதை நீங்கள் காண வேண்டும்.

### கணினி பரிந்துரைகள்

உகந்த Gemma 2B செயல்திறனுக்கு, உங்களுக்குத் தேவை:

- **செயலி**: பல-மைய Intel i5 அல்லது அதற்கு மேற்பட்டது
- **நினைவகம்**: 16GB RAM (Gemma 7B க்கு 32GB)
- **சேமிப்பகம்**: 50GB இலவச இட SSD
- **macOS**: புதுப்பித்த நிலையில் (Monterey அல்லது அதற்குப் பிந்தையது)

Ollama அமைக்கப்பட்டதுடன், Gemma இன் மாதிரிகளை உள்ளூரில் துவக்கவும் அவற்றுடன் தொடர்பு கொள்ளவும் நீங்கள் தயாராக உள்ளீர்கள்.

## உள்ளூர் Gemma நிகழ்வை துவக்குதல்

### 1. Ollama CLI வழியாக Gemma மாதிரியைத் தொடங்கவும்

நீங்கள் இயக்க விரும்பும் Gemma மாதிரியைத் தேர்ந்தெடுக்கவும்:

- Gemma 2B (சிறிய மாதிரி): `ollama run gemma:2b`
- Gemma 7B (பெரிய மாதிரி): `ollama run gemma:7b`

## Gemma இன் திறந்த மூல தாக்கம்

தனது அறிமுகத்திலிருந்து, Gemma தனது அணுகக்கூடிய மற்றும் ஒத்துழைப்பு சார்ந்த திறந்த மூல அணுகுமுறையின் காரணமாக புதுமையை வேகமாக முடுக்கிவிட்டுள்ளது.

காலப்போக்கில், ஒரு திறந்த மூல தளமாக அதன் இயல்பின் காரணமாக Gemma க்கான கருவிகள், ஒருங்கிணைப்புகள் மற்றும் முற்றிலும் புதிய பயன்பாடுகளின் ஒரு சூழலமைப்பு உருவாகலாம்.

## நிறுவன தீர்வுகளுக்கான Gemma பயன்பாட்டு நிகழ்வுகள்

Google இன் AI மாதிரியான Gemma, குறிப்பிட்ட வணிகத் தேவைகளைப் பூர்த்தி செய்ய அதன் தொழில்நுட்ப கட்டமைப்பு மற்றும் திறந்த மூல இயல்புடன் பல்வேறு நிறுவன தீர்வுகளை வழங்குகிறது.

### 1. அரட்டைப் போட்கள் மற்றும் உரையாடல் முகவர்கள்

Gemma இன் சிறிய மாதிரியான Gemma 2B, சாதனத்தில் செயல்திறனுக்காக மேம்படுத்தப்பட்டுள்ளது; இது **உரையாடல் போட்கள்** மற்றும் **மெய்நிகர் உதவியாளர்களை** உருவாக்குவதற்கு ஏற்றதாக ஆக்குகிறது. நிறுவனங்கள் இந்த AI-இயங்கும் முகவர்களை கைபேசி சாதனங்கள் அல்லது உட்பொதிக்கப்பட்ட அமைப்புகளில் பயன்படுத்தி, விரிவான கணக்கீட்டு வளங்கள் தேவைப்படாமல் வாடிக்கையாளர் சேவை, ஆதரவு மற்றும் ஈடுபாட்டை மேம்படுத்தலாம்.

Gemma இப்போதுதான் வெளியிடப்பட்டிருந்தாலும், அதன் திறன்கள் வாடிக்கையாளர்களுக்கு உதவும் AI அரட்டைப் போட்கள் மற்றும் மெய்நிகர் முகவர்களின் தற்போதைய பயன்பாடுகளுடன் நன்கு ஒத்திசைகின்றன. Gemma முதிர்ச்சியடையும் போது, அடுத்த தலைமுறை உரையாடல் இடைமுகங்களை செயல்படுத்தும் நேரடி ஒருங்கிணைப்புகளைக் காண எதிர்பார்க்கிறோம்.

### 2. தரவு பகுப்பாய்வும் நுண்ணறிவுகளும்

சிக்கலான பணிகளுக்கு அதிக திறனைக் கொண்ட பெரிய Gemma 7B மாதிரி, பெரிய தரவுத்தொகுப்புகள் மற்றும் ஆவணங்களை பகுப்பாய்வு செய்வதற்கு நன்கு ஏற்றது. நிறுவனங்கள் இந்த மாதிரியைப் பயன்படுத்தி பரந்த அளவிலான தரவிலிருந்து நுண்ணறிவுகள், போக்குகள் மற்றும் வடிவங்களைப் பிரித்தெடுக்கலாம்; இது முடிவெடுக்கும் செயல்முறைகள் மற்றும் மூலோபாய திட்டமிடலுக்கு உதவுகிறது.

### 3. உள்ளடக்க உருவாக்கமும் சுருக்கமும்

அறிக்கைகள், கட்டுரைகள் மற்றும் சந்தைப்படுத்தல் பொருட்கள் போன்ற உள்ளடக்கத்தை உருவாக்குவதிலும் சுருக்குவதிலும் Gemma இன் மாதிரிகள் உதவ முடியும். இந்தத் திறன், உயர்தர உள்ளடக்கத்தை உருவாக்க தேவைப்படும் நேரத்தையும் முயற்சியையும் கணிசமாகக் குறைக்கும்; இது வணிகங்களை படைப்பாற்றல் மற்றும் மூலோபாயத்தில் கவனம் செலுத்த உதவுகிறது.

### 4. தனிப்பயனாக்கப்பட்ட மின்னஞ்சல் சந்தைப்படுத்தலும் விளம்பர இலக்கும்

இயல்மொழியைப் புரிந்துகொண்டு உருவாக்குவதன் மூலம், மிகவும் தனிப்பயனாக்கப்பட்ட மற்றும் பயனுள்ள மின்னஞ்சல் சந்தைப்படுத்தல் பிரச்சாரங்களையும் விளம்பர இலக்கு உத்திகளையும் உருவாக்க Gemma நிறுவனங்களுக்கு உதவ முடியும். இந்த பயன்பாட்டு நிகழ்வு மேம்பட்ட வாடிக்கையாளர் ஈடுபாட்டிற்கும் மாற்று விகிதங்களுக்கும் வழிவகுக்கும்.

### 5. விளிம்பு சாதனங்களுக்கான இயல்மொழி செயலாக்கம் (NLP)

Gemma இன் மேம்படுத்தல்கள், விளிம்பு சாதனங்களில் நேரடியாக NLP பணிகளை இயக்குவதற்கு ஏற்றதாக ஆக்குகின்றன. இந்தத் திறன், சில்லறை விற்பனை, உற்பத்தி மற்றும் IoT பயன்பாடுகளில் போன்ற நிகழ்நேர வணிக முடிவெடுத்தல் மற்றும் மேலும் தடையற்ற நிஜ-உலக ஒருங்கிணைப்புகளை அனுமதிக்கிறது.

### 6. உருவாக்குநர்களுக்கான குறியீட்டு நுண்ணறிவு

குறியீட்டுத் திருத்தம் மற்றும் மேம்பாட்டுப் பணிகளுக்கான இயல்மொழி இடைமுகங்களை வழங்குவதன் மூலம் உருவாக்குநர் உற்பத்தித்திறனை Gemma மேம்படுத்த முடியும். எடுத்துக்காட்டாக, உருவாக்குநர்கள் குறியீட்டு பரிந்துரைகள், செயல்பாடுகளின் விளக்கங்கள், பிழைத்திருத்த உதவி மற்றும் குறியீட்டு மதிப்பாய்வுகளைப் பெற உரையாடல் வினவல்களைப் பயன்படுத்தலாம். Gemma சூழலையும் சொற்பொருளையும் பகுப்பாய்வு செய்து பொருத்தமான பரிந்துரைகளை வழங்கும். இந்த "AI ஜோடி நிரலாளர்" பணிப்பாய்வுகளை நெறிப்படுத்தவும், பிழைகளைக் குறைக்கவும், AI-இயங்கும் தயாரிப்புகளின் மேம்பாட்டை முடுக்கவும் உதவ முடியும்.

### 7. பன்முக பயன்பாடுகள்

உரை, குரல் மற்றும் காட்சி களங்களில் தகவலைச் செயலாக்கும் அதன் திறனுடன், குறுக்கு-முகத்தன்மை பயன்பாட்டு நிகழ்வுகளுக்கு Gemma பல்துறையானது. இந்த அம்சம், மெய்நிகர் உண்மை (VR) மற்றும் மேம்படுத்தப்பட்ட உண்மை (AR) அனுபவங்கள் போன்ற மிகவும் இயல்பான மற்றும் உள்ளுணர்வுள்ள வழிகளில் பயனர்களுடன் தொடர்பு கொள்ள வேண்டிய பயன்பாடுகளுக்கு குறிப்பாக பயனளிக்கும்.

Gemma இன் திறந்த மூல இயல்பும் தொழில்நுட்ப பல்துறைத்திறனும், செயல்பாட்டுத் தேவைகள் முழுவதும் AI ஐப் பயன்படுத்த விரும்பும் நிறுவனங்களுக்கு அதை மதிப்புமிக்க கருவியாக ஆக்குகின்றன. வாடிக்கையாளர் அனுபவத்தை மேம்படுத்தும் மெய்நிகர் உதவியாளர்கள் மற்றும் அரட்டைப் போட்களை உருவாக்குவதில் Gemma திறமையானது, மேலும் பெரிய அளவிலான தரவு பகுப்பாய்வைக் கையாள முடியும். அதன் திறந்த மூல மாதிரியும் புதுமையையும் ஒத்துழைப்பையும் ஊக்குவிக்கிறது; நிறுவனங்கள் தங்கள் தேவைகளைப் பூர்த்தி செய்ய Gemma ஐ தனிப்பயனாக்க அனுமதிக்கிறது.

## எதிர்காலம் என்ன வைத்திருக்கிறது?

## முடிவுரை

Gemma இன் அறிமுகம் AI துறையில் ஒரு திருப்புமுனை தருணம்; மேலும் அணுகக்கூடிய, நெறிமுறைசார் மற்றும் ஒத்துழைப்பு சார்ந்த மேம்பாட்டு நடைமுறைகளை நோக்கிய ஒரு மாற்றத்தை எடுத்துக்காட்டுகிறது. அது தொடர்ந்து பரிணமித்து வருகையில், AI இன் எதிர்காலத்தை வடிவமைப்பதில் Gemma ஒரு முக்கிய பங்கை வகிக்க அமைந்துள்ளது; நெறிமுறைசார் தரநிலைகளைக் கடைப்பிடிக்கும் அதே வேளையில் திறந்த மூல திட்டங்கள் எவ்வாறு புதுமையை இயக்க முடியும் என்பதற்கான ஒரு வரைபடத்தை வழங்குகிறது.
