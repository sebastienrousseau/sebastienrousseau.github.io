## Ìdí tí Shor's algorithm ṣì fi jẹ́ òṣùwọ̀n

Ìwé náà ni "Shor's algorithm compiled on cat qubits: 22 593 qubits for RSA-2048 in 3.14 days" láti ọwọ́ Axel Pappalardo, Dahmun Goudarzi àti òǹkọ̀wé ẹlẹgbẹ́ mẹ́jọ, tí ọ̀pọ̀ nínú wọn wà ní Alice & Bob ní Paris. A tẹ̀ ẹ́ jáde ní 2026 gẹ́gẹ́ bí ìwé IACR Cryptology ePrint Archive 2026/2665.

Ní 1994, Peter Shor ṣàfihàn quantum algorithm kan láti ṣe factoring nọ́mbà ńlá tàbí láti ṣírò discrete logarithm ní polynomial time. Lẹ́yìn ohun tí ó ju ọdún ọgbọ̀n lọ, ó ṣì jẹ́ iṣẹ́ ìtọ́kasí fún fault-tolerant quantum hardware. Àwọn ìdí rẹ̀ jẹ́ ti ìṣe, kì í ṣe ti ìfẹ́ àtijọ́.

Àkọ́kọ́, ìṣòro náà rọrùn láti sọ, èsì rẹ̀ sì rọrùn láti ṣàyẹ̀wò. Èkejì, kò sí classical algorithm tí a mọ̀ tí ó lè ṣe factoring àwọn integer tí ó tóbi tó ti cryptography, bí àpẹẹrẹ RSA key tí ó ju 2048 bit lọ, ní àkókò tí ó bọ́gbọ́n mu. So méjèèjì pọ̀, o ó rí ìdánwò tí ó mọ́: ṣíṣe Shor's algorithm ní àṣeyọrí ní irú ìwọ̀n bẹ́ẹ̀ jẹ́ ẹ̀rí tó lágbára pé a ṣe ìṣirò náà lórí quantum computer. Àyè díẹ̀ ló wà láti jiyàn bóyá ìdáhùn náà tọ́, àyè díẹ̀ sì wà láti sọ pé ẹ̀rọ classical ló ṣe iṣẹ́ náà.

Ànímọ́ kan náà tí ó sọ algorithm náà di ìdánwò rere ló mú kí ó ṣòro láti yege. Nítorí ìjìnlẹ̀ tí ó nílò, ìṣirò náà kò lè ṣàṣeyọrí láìsí quantum error correction ní ìwọ̀n ńlá. Ọ̀kẹ́ àìmọye logical operation gbọ́dọ̀ ṣẹlẹ̀ láìsí àṣìṣe, ìpele mélòó kan ju ẹgbẹẹgbẹ̀rún operation tí ẹ̀rọ láìsí error correction lè ṣe. Àlàfo yẹn ni gbogbo ìtàn ẹ̀ka náà. Kò sí ẹni tí yóò dí i nípa kíkọ́ physical qubit tí ó dára díẹ̀ sí i; encoding ló gbọ́dọ̀ dí i, ìbéèrè tí ó dùn mọ́ni sì ni bí owó rẹ̀ ṣe lè kéré tó.

Àwọn ẹ̀yà discrete logarithm náà ṣe pàtàkì. Fún ECDLP, discrete logarithm lórí elliptic curve, ìkọlù classical tí ó dára jùlọ tí a mọ̀ jẹ́ exponential. Ìdàgbàsókè ECDLP algorithm ti rí ọ̀nà ìmúdára mẹ́ta ọ̀tọ̀ọ̀tọ̀ tí ó yọjú nínú àwọn ìwé àìpẹ́ yìí. Ní ẹ̀gbẹ́ factoring, iṣẹ́ ìṣáájú láti ọwọ́ Chevignard et al. àti Gidney dín iye logical qubit kù láti ìlọ́po mélòó kan ìwọ̀n key sí ìdajì rẹ̀. Algorithm náà kò dúró jẹ́ẹ́, gbogbo ìṣirò hardware sì gbọ́dọ̀ jẹ́ kíkà lòdì sí àfojúsùn algorithm tí ń yí padà.

## Fífi ẹ̀rọ wéra nílò àdéhùn lórí metric

Ìṣirò ohun èlò wúlò nìkan bí a bá lè fi méjì wéra, ìyẹn sì nílò àdéhùn lórí ohun tí a ó kà. Ìwé náà to application tí a gbé yẹ̀wò, iye logical qubit, iye physical qubit, àpapọ̀ àkókò ìṣiṣẹ́ àti iye shot. Ọ̀kọ̀ọ̀kan ní ìtumọ̀ tí ó yẹ kí a pa mọ́ ní kedere.

Logical qubit jẹ́ qubit tí error rate rẹ̀ kéré, tí ó wá láti quantum error correction tí a lò sí àwùjọ physical qubit tí a lè ṣe, tí error rate wọn ga. Iye shot ni ìpíndọ́gba iye ìgbà tí a ó ṣe algorithm náà kí ó tó ṣàṣeyọrí. Ìpààrọ̀ láàrin iye physical qubit àti àkókò sábà máa ń ṣeé ṣe, ìdí nìyí tí nọ́mbà kan ṣoṣo lè ṣini lọ́nà; algorithm kan náà lórí hardware kan náà lè ní àwọn ojú àmì mélòó kan lórí ìlà kan.

Kárí àwọn ìwé, metric pàtàkì méjì tí a fi ń wé architecture ni iye physical qubit àti àpapọ̀ àkókò ìṣiṣẹ́. Àwọn nọ́mbà méjì yẹn ni àpilẹ̀kọ yìí ń padà sí, àwọn méjì yẹn sì ni èsì ìwé náà fi hàn.

Ìwé náà tún ṣàlàyé ìdí tí àwọn metric wọ̀nyí fi dára sí i kíákíá. Ọ̀pá mẹ́ta tí ó dá wà láàrin ara wọn ló ń mú metric pàtàkì méjèèjì dára sí i, wọ́n sì ṣàlàyé ìdàgbàsókè kíákíá Shor's algorithm láti 1994 sí 2026. Ọ̀kan nínú wọn, algorithm ìpele gíga, jẹ́ dídín iye logical qubit kù, dídín iye gate olówó iyebíye kù, tàbí mímú probability àṣeyọrí dára sí i. Ìwé kọ̀ọ̀kan tí ó mú iṣẹ́ Shor's algorithm dára sí i ń ṣiṣẹ́ lórí ọ̀pá kan sí mẹ́ta, ó sì ń ṣàlàyé mẹ́ta-nínú-ọ̀kan: algorithm pàtó kan, pẹpẹ hardware pàtó kan àti QEC implementation pàtó kan. Mẹ́ta-nínú-ọ̀kan ìwé yìí ni Shor's algorithm pẹ̀lú adder tí a ṣàtúnṣe, superconducting cat qubits, àti architecture cat-code méjì.

## Ohun tí ó mú cat qubit yàtọ̀

Ìmọ̀ ẹ̀rọ qubit tí a gbé yẹ̀wò ni dissipative cat qubit, tí ó jẹ́ ti ìdílé superconducting qubit. Ẹ̀yà kan, Kerr-cat qubit, ni a fi two-photon drive mú dúró dípò. Transmon ni ọ̀nà superconducting tí Gidney–Ekerå gbé kalẹ̀, nítorí náà ojú àfiwé ṣe kedere.

Encoding náà yàtọ̀ ní ìpìlẹ̀. Transmon ń fi ipò pamọ́ sí ìpele agbára méjì ti anharmonic oscillator. Cat qubit ní tirẹ̀ ń fi ipò pamọ́ sí superposition ti coherent state méjì tí phase wọn lòdì sí ara wọn nínú electromagnetic mode kan, àwọn tí a ń pè ní Schrödinger cat states.

Àbájáde tí ó ṣe pàtàkì fún kíka ohun èlò ni àìdọ́gba nínú noise. Fún cat qubits, bit-flip rate ń dín kù ní exponential pẹ̀lú paramita tí a lè ṣàtúnṣe, iye photon nínú cat state, nígbà tí phase-flip rate ń pọ̀ sí i ní linear nìkan pẹ̀lú paramita yìí. O lè ra ìdènà bit-flip púpọ̀, kí o sì san ìtanràn phase-flip díẹ̀ péré. Bias yẹn láàrin irú noise méjèèjì ń jẹ́ kí ètò error correction tí ó rọrùn ṣeé ṣe, bí architecture repetition code, pẹ̀lú ìpín logical-sí-physical qubit tí ó kéré púpọ̀, nítorí phase-flip nìkan ló nílò àtúnṣe. Error correction code tí ó ga jù, bí LDPC codes, ń dín ìpín náà kù sí i.

Èyí ni àríyànjiyàn fún gbogbo iṣẹ́ náà. Bí hardware bá fún ọ ní noise channel tí ó ti tẹ̀ sí ẹ̀gbẹ́ kan tẹ́lẹ̀, code tí a ṣe yí irú àṣìṣe kan ṣoṣo ká nílò physical qubit tí ó kéré púpọ̀ fún logical qubit kọ̀ọ̀kan ju code tí a kọ́ fún noise tí ó dọ́gba lọ. Ìṣirò inú ìwé yìí jẹ́ ìdánwò bí àríyànjiyàn yẹn ṣe lè dé tó nínú iṣẹ́ pípé tí a ṣe compile rẹ̀.

Noise model náà kéré ní ìmọ̀ọ́mọ̀. A ṣàkópọ̀ rẹ̀ pẹ̀lú paramita kan ṣoṣo, pZ, phase-flip probability, èyí tí ìpín láàrin κ2 (two-photon dissipation, ipá tí ó ń mú cat state dúró) àti κ1 (one-photon loss, ipá tí ó ń ba cat state jẹ́) ń darí jùlọ. Àwọn òǹkọ̀wé pè é ní ànímọ́ hardware tí ó ṣe kókó. A gbà pé bit flip kò tó nǹkan. Di gbólóhùn tí ó kẹ́yìn yẹn mú; ó gbé ìwúwo ju bí ó ti kọ́kọ́ hàn lọ.

## Láti algorithm dé physical qubit

A kọ́ ìṣirò náà nípasẹ̀ àwọn ìpele abstraction. Ìpele tí ó ga jùlọ ni Algorithm layer, èyí tí nínú iṣẹ́ yìí jẹ́ àpèjúwe Shor's algorithm àti àwọn subroutine rẹ̀. A ń ṣàpèjúwe àwọn algorithm ní ìpele yìí pẹ̀lú block diagram, pseudo-code àti àwòrán mathimátíìkì ti àwọn ìyípadà tí a lò sí àwọn register.

Lábẹ́ rẹ̀ ni Logical layer wà, ìpele abstraction tí ó kéré jùlọ tí ó ṣì dá dúró láìgbára lé ìmọ̀ ẹ̀rọ quantum tí a gbé yẹ̀wò, èyí tí ó jẹ́ kí àfiwé algorithm láìka hardware sí ṣeé ṣe. Ní ìpele yìí, a ṣàpèjúwe subroutine kọ̀ọ̀kan ní pàtó ní ti logical qubit àti logical gate tàbí logical operation. Ìyapa yẹn wúlò fún ẹnikẹ́ni tí ń fi algorithm wéra: a lè ṣèdájọ́ àbá méjì lórí iye owó logical kí ẹnikẹ́ni tó jiyàn lórí hardware tí yóò ṣe é.

Ìwé náà wá lọ sísàlẹ̀ sí i. A ṣe compile àwọn subroutine tí ó ga jùlọ sí physical-qubit operation lórí architecture méjì, ọ̀kan dá lórí repetition cat codes, èkejì dá lórí LDPC cat codes. Compile yẹn ló ya iṣẹ́ yìí sọ́tọ̀ kúrò ní ìṣirò ẹ̀yìn ìwé. A kò fà àwọn nọ́mbà náà jáde láti iye logical pẹ̀lú multiplier àfikún tí ó dúró sójú kan; wọ́n wá láti àwọn operation tí a ṣe compile rẹ̀.

Ọ̀pọ̀ ẹ̀yà tuntun ni a nílò láti dé ibẹ̀. Àwọn òǹkọ̀wé ṣe parity-Cnot gate fún cat qubits, wọ́n fa multi-target Cnot gate gùn sí architecture LDPC-cat, wọ́n sì ṣàtúnṣe ìlànà active injection sí àwọn architecture cat-qubit. Wọ́n tún ṣàtúnṣe adder láti inú ìṣirò ohun èlò Gidney ti 2025 fún factoring RSA-2048 sí àwọn architecture cat-qubit. Níkẹyìn, wọ́n so compile adder wọn àti ìṣirò ohun èlò tí kò péye tó fún phaseup pọ̀ mọ́ àwọn àgbékalẹ̀ factory àti compile lookup láti inú ìṣirò ohun èlò FeMoco ti Kroell et al.

Ṣàkíyèsí àtúnlò náà. Adder wá láti ìṣirò factoring; factory àti compile lookup wá láti ìṣirò chemistry. Yíyá láti application kan sí òmíràn jẹ́ àmì pé àwọn bíríkì ìkọ́lé fault-tolerant computation ń di ohun èlò ìpìlẹ̀ tí a pín dípò àgbékalẹ̀ àdáni. Ó tún jẹ́ ìránnilétí pé a ṣe ìṣirò tí kò péye tó fún phaseup ju adder lọ, nítorí náà kì í ṣe gbogbo ẹ̀yà ló ní ìpéye kan náà.

## Èsì: ojú àmì mẹ́ta

RSA-2048 ni ìṣètò tí àwọn òǹkọ̀wé ṣe compile rẹ̀ pátápátá, àti nínú ìṣètò yẹn ó nílò nǹkan bí cat qubit 23,000 àti ọjọ́ 3.14. Nígbà tí a bá fi àyè ra àkókò, ó ń parí ní wákàtí 1.25 lórí nǹkan bí cat qubit 611,000, ìpààrọ̀ tí ìwé náà fà jáde láti ìṣètò tí a ṣe compile rẹ̀. Nọ́mbà yẹn wà ní ẹ̀gbẹ́ tí ó dára lórí ìlà space-time ní ti ìyára: ó ju wákàtí kan lọ díẹ̀ fún ìwọ̀n key tí kò sí classical algorithm tí a mọ̀ tí ó lè ṣe factoring rẹ̀ ní àkókò tí ó bọ́gbọ́n mu.

Ojú àmì kejì jẹ́ àbá. A ṣàlàyé FFDLP-512 gẹ́gẹ́ bí àpẹẹrẹ ìṣòro FFDLP fún prime group 512-bit àti exponent 80-bit. Àwọn òǹkọ̀wé dábàá rẹ̀ gẹ́gẹ́ bí benchmark àárín, ó sì nílò nǹkan bí cat qubit 6,700 àti ìṣẹ́jú 21. Shor's algorithm fún FFDLP kò ná àyè púpọ̀, èyí tí ó bá iye qubit tí ó fẹ́rẹ̀ jẹ́ ìpele méjì nísàlẹ̀ nọ́mbà RSA-2048 mu.

Mo rò pé benchmark àárín yìí ni èrò tí ó wúlò jùlọ nínú ìwé náà fún ẹnikẹ́ni tí ń kọ́ hardware. Àfojúsùn qubit 611,000 jẹ́ ibi tí a ń lọ; kò sọ ohun tí ẹgbẹ́ kan yóò fi hàn ní ọdún tí ń bọ̀. Benchmark ní nǹkan bí cat qubit 6,700 àti ìṣẹ́jú 21 fúnni ní ibùdó tí ó súnmọ́ tí ó ṣì ń lo ìdílé algorithm kan náà. Àríyànjiyàn ìwé náà ni pé FFDLP-512 ń lo gbogbo bíríkì tí RSA-2048 nílò, nítorí náà ó lè fi ìṣiṣẹ́ Shor's algorithm láti ìbẹ̀rẹ̀ dé òpin gidi hàn láìsí ọ̀nà àbùjá. Ó tún sọ ní gbangba pé a lè ṣe cryptanalysis ìṣòro yìí ní classical, nítorí náà iye benchmark náà wà nínú jíjẹ́ àmì ìlọsíwájú fún ẹ̀rọ náà, kì í ṣe fífọ́ cryptography fúnra rẹ̀.

## Àròsọ ọdún 100

Báyìí, gbólóhùn tí ó yẹ kí a dì mú. A gbà pé bit flip kò tó nǹkan, ìwé náà sì sọ ohun tí ìyẹn túmọ̀ sí ní ti hardware: ìbéèrè pé kò sí bit-flip bá bit-flip time tó nǹkan bí ọdún 100 mu.

Nọ́mbà tí ó le ni ìyẹn, àwọn òǹkọ̀wé kò sì fi í sílẹ̀ bẹ́ẹ̀. A lè dẹ̀ ìbéèrè náà kù sí bit-flip time tó nǹkan bí wákàtí kan nípa lílo ìpele concatenation àfikún sínú bit-flip error-correcting code distance-3. A ti dábàá àwọn architecture bí Elevator code tẹ́lẹ̀ láti pèsè bit-flip correction, nítorí náà èrò fífi ìpele kan kún un tí yóò bójú tó bit-flip channel tí ó ṣẹ́kù ní àpẹẹrẹ ìṣáájú.

A ṣírò iye owó náà, ọ̀rọ̀ ìwé náà sì ṣọ́ra bẹ́ẹ̀: àwọn òǹkọ̀wé ṣírò pé iye owó RSA-2048 yóò ga sí nǹkan bí cat qubit 45,000. Ìṣirò ni èyí, kò sì yẹ kí a kà á sí èsì tí a ṣe compile rẹ̀ bí nọ́mbà 23,000. Síbẹ̀, ìrísí ìpààrọ̀ náà yẹ ní sísọ ní kedere. Code òde ń dẹ̀ ìbéèrè lórí bit-flip time kù ní ìlọ́po tí ó ju mílíọ̀nù kan lọ, ní iye owó physical qubit tí ó fẹ́rẹ̀ jẹ́ ìlọ́po méjì: láti nǹkan bí 23,000 sí nǹkan bí 45,000, pẹ̀lú àkókò ìṣiṣẹ́ tí ó kéré jùlọ ọjọ́ 3.14.

Kò yẹ kí a fi nọ́mbà 45,000 wé ti 611,000. Nọ́mbà tí ó tóbi jù ni òpin ìlà space-time tí ó yára jùlọ; èyí tí ó kéré jù ni ìṣètò tí a ṣe compile rẹ̀ pẹ̀lú ìpele ààbò bit-flip àfikún, nítorí náà ó jẹ́ àfikún lórí 23,000, kì í ṣe ìdínkù 611,000. Ohun tí a lè sọ ni pé ìbéèrè ọdún 100 jẹ́ àròsọ àgbékalẹ̀, kì í ṣe òfin ìṣẹ̀dá, àti pé àwọn òǹkọ̀wé tọ́ka sí ọ̀nà concatenation láti yí i ká.

## Kíka èsì náà gẹ́gẹ́ bí olùdásílẹ̀ tàbí onímọ̀ ẹ̀rọ

Fún àwọn òǹkàwé onímọ̀ ẹ̀rọ, ẹ̀kọ́ ìṣe ni pé ìṣirò náà ń san èrè fún wíwo àwọn àròsọ tí ó gbé ìwúwo. Mẹ́ta ló yọ jáde.

Àkọ́kọ́ ni noise bias. Gbogbo ohun tí ó jẹ mọ́ ìpín logical-sí-physical tí ó kéré dá lórí pé a ń dènà bit-flip ní exponential nínú iye photon nígbà tí phase-flip ń pọ̀ sí i ní linear nìkan. Bí pẹpẹ kan kò bá lè pèsè àìdọ́gba yẹn, àǹfààní repetition-code àti LDPC-code tí a ṣàpèjúwe níbí kò ní tẹ̀lé e.

Èkejì ni ìpín κ2 sí κ1. Ìwé náà pè é ní ànímọ́ hardware tí ó ṣe kókó, àti pé níwọ̀n bí noise model ti dín kù sí paramita kan ṣoṣo pZ tí ìpín yẹn ń darí jùlọ, òun ni nọ́mbà tí ó yẹ kí a máa wò nínú ìlànà ọ̀nà hardware cat-qubit èyíkéyìí. Ẹgbẹ́ tí ó lè jábọ̀ pZ lábẹ́ ipò iṣẹ́ gidi ń fún ọ ní ìwọlé tí ìṣirò yìí ní ìmọ̀lára sí jùlọ, ó kéré tán gẹ́gẹ́ bí noise model ìwé náà fúnra rẹ̀.

Ẹ̀kẹta ni bit-flip time, èyí tí a ti sọ̀rọ̀ lé lórí. Pa pọ̀, àwọn àròsọ mẹ́ta wọ̀nyí ló ṣàlàyé agbègbè tí àwọn nọ́mbà àkọ́kọ́ ti dúró.

Fún àwọn olùdásílẹ̀, kíkà tí ó wúlò kéré ju àsọtẹ́lẹ̀ lọ. Ìwé náà kò fúnni ní ọjọ́ tí a ó kọ́ èyíkéyìí nínú èyí, kò sì yẹ kí a mú ohunkóhun nínú ìwé náà bí ọjọ́ bẹ́ẹ̀. Ohun tí ó pèsè ni àwòrán ilẹ̀ tí a ti wọ̀n láti ànímọ́ hardware sí iye ohun èlò, pẹ̀lú àfiwé architecture méjì tí a sọ ní gbangba àti benchmark àárín. Irú ohun èlò yẹn ló ń jẹ́ kí olùdókòwò tàbí ẹgbẹ́ hardware béèrè ìbéèrè pàtó: ṣé qubit rẹ pàdé ìbéèrè pZ àti bit-flip tí ìṣirò náà gbà?

Kókó kan tún wà nípa ọ̀nà. Àwọn òǹkọ̀wé ṣe compile àwọn subroutine tí ó ga jùlọ dípò kí wọ́n fà á gùn láti iye logical, wọ́n tún lo àwọn ẹ̀yà láti inú ìṣirò mìíràn tí a ti tẹ̀ jáde, wọ́n sì sọ ibi tí wọ́n ti ṣe nọ́mbà tí kò péye tó nìkan, bí ti phaseup. Ìṣípayá yẹn nípa àwọn apá tí ó kúnná àti àwọn tí ó ṣì rí rọ̀ọ́rọ̀ ló mú kí ìṣirò náà ṣeé ṣàyẹ̀wò, ṣíṣeé ṣàyẹ̀wò sì ni ànímọ́ tí ó ṣe pàtàkì jùlọ nínú ẹ̀ka tí àwọn nọ́mbà àkọ́kọ́ ti ń yí ní ìpele púpọ̀ láàrin ìwé kan sí òmíràn.

## Ibi tí ìṣirò náà fi ẹ̀ka náà sí

Ìdàgbàsókè kíákíá Shor's algorithm láti 1994 sí 2026 wá láti ọ̀pá mẹ́ta tí ó dá wà láàrin ara wọn, ìwé yìí sì fa gbogbo wọn ní ọ̀nà tirẹ̀: àtúnṣe algorithm ti adder, pẹpẹ hardware pàtó nínú superconducting cat qubits, àti QEC implementation méjì tí a ṣe compile wọn sí physical operation. Èsì rẹ̀ ni àwọn nọ́mbà tí a ṣàlàyé dáadáa fún RSA-2048: nǹkan bí cat qubit 23,000 àti ọjọ́ 3.14 nínú ìṣètò tí a ṣe compile rẹ̀, wákàtí 1.25 lórí nǹkan bí cat qubit 611,000 nígbà tí a fi àyè ra àkókò, àti cat qubit 45,000 tí a ṣírò bí bit-flip time bá jẹ́ nǹkan bí wákàtí kan péré tí ìpele concatenation àfikún sì ń bójú tó àwọn bit-flip.

Ìbéèrè ṣíṣí tí ìwé náà gbé dìde ni èyí tí ó jókòó láàrin nọ́mbà 23,000 àti 45,000. Bit-flip time tó nǹkan bí ọdún 100 jẹ́ àfojúsùn tí ó le; bit-flip time tó nǹkan bí wákàtí kan rọrùn púpọ̀ jù, ní iye owó ìpele code distance-3 tí àwọn òǹkọ̀wé ṣírò ìnáwó rẹ̀ dípò kí wọ́n ṣe compile rẹ̀. Bóyá ó máa rọrùn fún àwọn ẹgbẹ́ hardware láti tì bit-flip time sí nọ́mbà tí ó le jù, tàbí láti gba àkókò kúkúrú kí wọ́n sì san owó ìpele àfikún, ni ìpinnu tí ìṣirò yìí gbé síwájú wọn. Ọ̀nà tí ó mọ́ jù láti mọ̀ ju jíjiyàn lórí RSA-2048 ti wà lórí tábìlì: kọ́ sí FFDLP-512, ní nǹkan bí cat qubit 6,700 àti ìṣẹ́jú 21, kí o sì wo èwo nínú ọ̀nà méjèèjì ló kọ́kọ́ dé ibẹ̀.

## Àwọn Ìbéèrè Tí A Máa Ń Béèrè

**Cat qubit mélòó ni ìwé náà ṣírò fún factoring RSA-2048?**
Nínú ìṣètò tí a ṣe compile rẹ̀ pátápátá, nǹkan bí cat qubit 23,000 (22,593) àti ọjọ́ 3.14. Nígbà tí a bá fi àyè ra àkókò, RSA-2048 ń parí ní wákàtí 1.25 lórí nǹkan bí cat qubit 611,000. Àwọn nọ́mbà wọ̀nyí gbà pé error-correction cycle jẹ́ 1 µs, reaction time jẹ́ 10 µs, phase-flip noise pẹ̀lú pZ = 5 × 10⁻⁴, kò sì sí bit-flip.

**Kí ni nọ́mbà qubit 45,000 túmọ̀ sí?**
Ó jẹ́ ìṣirò àwọn òǹkọ̀wé fún RSA-2048 nígbà tí bit-flip time jẹ́ nǹkan bí wákàtí kan péré, nítorí náà a nílò ìpele bit-flip code distance-3 àfikún. Ó jẹ́ àfikún lórí ìṣètò qubit tó nǹkan bí 23,000, pẹ̀lú àkókò ìṣiṣẹ́ tí ó kéré jùlọ ọjọ́ 3.14, kì í ṣe ìdínkù nọ́mbà qubit 611,000.

**Kí ni FFDLP-512, kí sì ni ìdí tí a fi dábàá rẹ̀?**
FFDLP-512 jẹ́ àpẹẹrẹ ìṣòro finite-field discrete logarithm fún prime group 512-bit àti exponent 80-bit. Ìwé náà dábàá rẹ̀ gẹ́gẹ́ bí benchmark àárín tí ó ń lo gbogbo bíríkì tí RSA-2048 nílò, ní nǹkan bí cat qubit 6,700 àti ìṣẹ́jú 21. A lè ṣe cryptanalysis rẹ̀ ní classical, nítorí náà ó jẹ́ àmì ìlọsíwájú hardware, kì í ṣe fífọ́ cryptography fúnra rẹ̀.

**Kí ló dé tí cat qubits fi nílò physical qubit tí ó kéré fún logical qubit kọ̀ọ̀kan?**
Fún cat qubits, bit-flip rate ń dín kù ní exponential pẹ̀lú iye photon nínú cat state, nígbà tí phase-flip rate ń pọ̀ sí i ní linear nìkan. Bias yẹn túmọ̀ sí pé phase-flip nìkan ló nílò àtúnṣe, èyí tí ó jẹ́ kí architecture repetition code pẹ̀lú ìpín logical-sí-physical qubit tí ó kéré púpọ̀ ṣeé ṣe. LDPC cat codes ń dín ìpín náà kù sí i.

**Paramita hardware wo ni ìwé náà pè ní kókó?**
A ṣàkópọ̀ noise model pẹ̀lú paramita kan ṣoṣo, pZ, phase-flip probability, èyí tí ìpín láàrin two-photon dissipation (κ2) àti one-photon loss (κ1) ń darí jùlọ. Ìwé náà pè é ní ànímọ́ hardware tí ó ṣe kókó. Bit-flip time ni àròsọ mìíràn tí ó gbé àwọn nọ́mbà àkọ́kọ́.
