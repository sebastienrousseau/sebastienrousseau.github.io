# PSD2 Mú Àwọn Báńkì Kọ́ API. FiDA Mú Wọn Wọlé Sí Ọjà.

**Lábẹ́ PSD2, báńkì kan lè tẹ̀lé òfin fúnra rẹ̀.** Kọ́ endpoint náà, tẹ ìwé-ìlànà rẹ̀ jáde, dé àmì ìwàláàyè-ìṣiṣẹ́ tí a gbé kalẹ̀, ó parí. Àbá Financial Data Access ti Ìgbìmọ̀ Yúróòpù fẹ́ gba ààyè yẹn kúrò. Ìtẹ̀lé-òfin yóò gba ọ̀nà financial data sharing scheme — àdéhùn ìlànà tí a ń jíròrò láàrin àwọn data holder, data user àti àwọn aṣojú oníbàárà — kò sì sí ilé-iṣẹ́ kan tí ó lè dá ọ̀kan sílẹ̀ nìkan. Iṣẹ́ ẹ̀rọ ni ìdajì kékeré. Ìdajì tí ó tóbi jù ni ìjíròrò ọjà nípa scope, ọ̀pá-ìwọ̀n, liability àti iye owó, ó sì ń ṣẹlẹ̀ báyìí, nígbà tí ọ̀pọ̀ àwọn báńkì ń dúró de ìwé ìkẹyìn.

> **Àkópọ̀ fún Àwọn Aláṣẹ**
>
> - **Ipò náà ṣe pàtàkì kí ìlànà tó tẹ̀lé e.** A gbé FiDA kalẹ̀ ní oṣù Kẹfà 2023 gẹ́gẹ́ bí ara pákéèjì financial data access àti ìsanwó. Ó farahàn lórí àkọsílẹ̀ ìfagilé 2025 tí ó jò jáde, ó yè wọ inú ètò iṣẹ́ ìkẹyìn, ó sì ṣì wà nínú trilogue. Kò sí ohun tí ó wà nísàlẹ̀ tí ó jẹ́ òfin tí a ti pinnu.
> - **Scheme ni ohun ìṣàkóso òfin náà.** Àwọn financial data sharing scheme ni yóò gbé àwọn ọ̀pá-ìwọ̀n àjọṣe, ohun tí interface gbọ́dọ̀ ní, àdéhùn liability àti ọ̀nà ìyanjú ìjà kalẹ̀. Àwọn òfin tí báńkì bá ṣèrànwọ́ láti kọ tàbí tí ó jogún ni yóò pinnu ewu rẹ̀.
> - **Compensation ń yí gbogbo iṣẹ́ náà padà.** Ní kété tí ààyè bá gba iye owó tí a so mọ́ ìnáwó ìpèsè, báńkì nílò àwòṣe ìnáwó tí ó lè dúró lábẹ́ ìbéèrè, kì í ṣe API gateway nìkan. Díẹ̀ lára wọn ló ní ọ̀kan.
> - **Iṣẹ́ ìkọ́lé náà kì í ṣe API.** Ọ̀pọ̀ ilé-iṣẹ́ lè ṣí endpoint sílẹ̀. Díẹ̀ ló lè wá, ṣe déédéé, kí wọ́n sì fi ìdí ìdára hàn nínú dátà mọ́gẹ́ẹ̀jì, owó ìfẹ̀yìntì àti insurance tí kò tíì kúrò nínú product silo rẹ̀ rí.

## Ìlànà Tí Ó Fẹ́rẹ̀ Má Wáyé

Gbogbo ìlànà tí a bá kọ́ lórí FiDA gbọ́dọ̀ bẹ̀rẹ̀ pẹ̀lú ọ̀rọ̀ òtítọ́ nípa ibi tí fáìlì náà wà ní tòótọ́.

Ìgbìmọ̀ náà gbé e kalẹ̀ ní **oṣù Kẹfà 2023**, pẹ̀lú pákéèjì ìsanwó tí ó gbé PSD3 àti Payment Services Regulation. Ní ìbẹ̀rẹ̀ ọdún 2025, àkọsílẹ̀ ètò iṣẹ́ Ìgbìmọ̀ náà tí ó jò jáde fi hàn pé a lè fagilé FiDA — a ròyìn rẹ̀ nígbà náà gẹ́gẹ́ bí ìdáhùn sí àníyàn nípa ẹrù tí ó wà lórí àwọn ilé-iṣẹ́ ìṣúnná owó EU. Ètò iṣẹ́ ìkẹyìn fi í sílẹ̀ láàrin àwọn àbá tí ó ṣẹ́kù, ìjíròrò sì ń tẹ̀síwájú. Ó ti gba inú trilogue kọjá, àwọn ilé-iṣẹ́ náà sì ń ṣiṣẹ́ lọ sí àdéhùn òṣèlú, pẹ̀lú ìretí pé àwọn ojúṣe yóò wọlé lẹ́sẹẹsẹ lẹ́yìn ìfọwọ́sí bí a ṣe ń dá àwọn scheme sílẹ̀.

Nǹkan méjì ni ó tẹ̀lé ìtàn yẹn, wọ́n sì ń fa ara wọn sí ọ̀nà òdìkejì.

Àbá náà **lè yè lóṣèlú ṣùgbọ́n kò dáàbò bò lóṣèlú**, nítorí náà ètò tí ó gbà pé ìwé lọ́wọ́lọ́wọ́ yóò jáde láìyípadà ti fi ara rẹ̀ hàn sí ewu. Scope, àkókò àti ọ̀nà compensation ni gan-an àwọn ìpèsè tí ń yí padà nínú trilogue.

Ní àkókò kan náà, àwọn apá tí ó ṣeé ṣe kí ó yè jùlọ ni àwọn tí ó jẹ́ **ti ìṣètò** — ìṣàkóso tí ó dá lórí scheme, àwọn permission dashboard, compensation ní ìpìlẹ̀ — nítorí pé wọ́n jẹ́ ìkọ́lé àbá náà, kì í ṣe àwọn òṣùwọ̀n rẹ̀. Àwọn náà sì ni ó ní àkókò ìkọ́lé tí ó gùn jùlọ.

Ìdúró tí ó tọ́ nítorí náà kì í ṣe "dúró de ìwé ìkẹyìn" bẹ́ẹ̀ sì ni kì í ṣe "kọ́ sí àkọsílẹ̀ lọ́wọ́lọ́wọ́". Ó jẹ́ láti kọ́ àwọn agbára tí gbogbo àpẹẹrẹ tí ó ṣeé ṣe yóò béèrè, àti láti wà níbi tí a ti ń pinnu àwọn òṣùwọ̀n náà.

## Ìyapa Ìṣètò Mẹ́ta Kúrò Lọ́dọ̀ PSD2

Kíka FiDA gẹ́gẹ́ bí PSD2 pẹ̀lú àkọsílẹ̀ endpoint tí ó gbòòrò ni àṣìṣe tí yóò náni jùlọ.

### Tábìlì 1: Ohun tí ó yí padà ní tòótọ́

| Ìwọ̀n | PSD2 | FiDA bí a ṣe gbé e kalẹ̀ |
| ---- | ---- | ---- |
| **Bí o ṣe ń tẹ̀lé òfin** | Kọ́ interface kí o sì tẹ̀ ẹ́ jáde; ìṣe ẹlẹ́nìkan-ṣoṣo | Wọ financial data sharing scheme; àdéhùn oníbùdó-púpọ̀ |
| **Dátà tí ó wà nínú scope** | Àwọn account ìsanwó | Mọ́gẹ́ẹ̀jì, awin, ìfowópamọ́, ìdókòwò, crypto-assets, owó ìfẹ̀yìntì, non-life insurance |
| **Ìnáwó ààyè** | Ọ̀fẹ́ fún ẹgbẹ́ ẹlẹ́ẹ̀kẹta | Àwọn data holder lè béèrè compensation tí ó bọ́gbọ́n mu tí a so mọ́ ìnáwó ìpèsè |
| **Ẹni tí ó gbé ọ̀pá-ìwọ̀n kalẹ̀** | Alábòójútó ń gbé àbájáde kalẹ̀; báńkì kọ̀ọ̀kan yan ọ̀nà ìmúṣẹ tirẹ̀ | Scheme náà ń gbé àwọn ọ̀pá-ìwọ̀n àjọṣe àti ohun tí interface gbọ́dọ̀ ní kalẹ̀ |
| **Ìdarí oníbàárà** | Ìfọwọ́sí fún ìsopọ̀ kọ̀ọ̀kan | Permission dashboard tí data holder gbọ́dọ̀ pèsè |
| **Ibi tí ewu wà** | Ìwàláàyè àti ààbò interface rẹ | Bákan náà: àdéhùn scheme, liability allocation nínú àdéhùn, àti àbájáde ìyanjú ìjà |

Ìlà àkọ́kọ́ àti ìkẹta ni àwọn tí ó ń yí ìrísí ètò náà padà.

## Scheme Ni Ohun Ìṣàkóso Òfin Náà

Lábẹ́ PSD2, ojú ìtẹ̀lé-òfin báńkì kan jẹ́ API tirẹ̀. Lábẹ́ FiDA bí a ṣe kọ ọ́, ojú ìtẹ̀lé-òfin jẹ́ **ìwé-ìlànà tí a jíròrò pẹ̀lú àwọn ẹnìkejì**, títí kan àwọn ilé-iṣẹ́ tí ó fẹ́ dátà rẹ.

Financial data sharing scheme jẹ́ àdéhùn ìlànà láàrin àwọn data holder, data user àti àwọn aṣojú oníbàárà tàbí oníbàárà-ọjà. A retí pé yóò gbé àwọn ọ̀pá-ìwọ̀n àjọṣe fún pínpín dátà àti ìbéèrè interface kalẹ̀, yóò gbé liability nínú àdéhùn tí àwọn ọmọ ẹgbẹ́ rẹ̀ ní kalẹ̀, yóò sì pèsè ọ̀nà dispute resolution tí ó ṣiṣẹ́.

Ka àkọsílẹ̀ yẹn gẹ́gẹ́ bí ìwé ìforúkọsílẹ̀ ewu, ìtumọ̀ rẹ̀ kò sì ní tù ọ́ lára. Ẹnìkan yóò pinnu bí a ó ṣe pín liability nígbà tí data user bá ṣì dátà oníbàárà tí ó gbà gba interface rẹ lò. Ẹnìkan yóò pinnu ọ̀pá-ìwọ̀n ìdára dátà tí a ó fi dì ọ́ mú, àti ohun tí ó jẹ́ ìbéèrè tí ó tọ́. Bí báńkì kò bá wà nínú yàrá náà, àwọn ẹgbẹ́ tí èrè ọjà wọn wà nínú ààyè gbòòrò, iye owó kékeré àti liability tí ó dùbúlẹ̀ lórí holder ni yóò ṣe àwọn ìpinnu wọ̀nyẹn.

Èyí ni apá tí ó kù jùlọ ní ohun èlò nínú ètò FiDA gbogbogbò. Àwọn ilé-iṣẹ́ ti yan àwọn ayàwòrán-ìkọ́lé, wọn kò sì yan olùjíròrò kankan.

## Compensation Ń Sọ Ojúṣe Di Ọjà

PSD2 fi dandan lé àwọn báńkì lórí láti fún ni ní ààyè sí account ìsanwó lọ́fẹ̀ẹ́. Àbá FiDA gba ipò mìíràn: àwọn data holder lè béèrè **compensation tí ó bọ́gbọ́n mu** lọ́wọ́ àwọn data user, tí a so mọ́ ìnáwó ṣíṣe dátà náà wà, lórí ọ̀nà ìṣirò tí ó ṣe kedere, tí ó hàn gbangba, tí kò sì ṣe ojúsàájú.

Ìyípadà kan yẹn ń sọ ojúṣe di ohun tí ó sún mọ́ ìlà ọjà tí a ṣàkóso — ó sì béèrè agbára tí ọ̀pọ̀ báńkì kò tíì nílò rí.

### Tábìlì 2: Ohun tí ipò compensation tí ó lẹ́sẹ̀ nílẹ̀ gbọ́dọ̀ dáhùn

| Ìbéèrè | Ìdí tí ó fi le | Ohun tí o nílò kí o tó lè dí owó lé e |
| ---- | ---- | ---- |
| Elòó ni ìpèsè ń ná ní tòótọ́? | Ìnáwó tàn káàkiri ìkọ́lé-ẹ̀rọ, ààbò, ìrànlọ́wọ́ àti ìtẹ̀lé-òfin, kò sì sí ọ̀kan nínú wọn tí a pín fún ọjà dátà lọ́wọ́lọ́wọ́ | Àwòṣe ìnáwó tí ó pín ìnáwó pátákò àjọṣe fún ìpèsè dátà |
| Ṣé ọ̀nà ìṣirò náà kò ṣe ojúsàájú? | Àwọn data user ọ̀tọ̀ọ̀tọ̀ yóò ní ìwọ̀n iṣẹ́ àti èrè tí ó yàtọ̀ gan-an | Àkọsílẹ̀ iye owó tí a tẹ̀ jáde tí ó lè dúró lábẹ́ ìwádìí ọmọ ẹgbẹ́ scheme tí kò fẹ́ ẹ |
| Ṣé ó lè sọ̀ kalẹ̀? | A pinnu pé compensation gbọ́dọ̀ tẹ̀ sí ìpele tí ó rẹlẹ̀ jùlọ ní ọjà, kì í ṣe láti fi iye owó lé ààyè kúrò | Ìṣètò tí ó ṣiṣẹ́ fún data user kékeré, kì í ṣe fún èyí tí ó tóbi nìkan |
| Ṣé o lè fi ẹ̀rí rẹ̀ hàn? | Iye owó di ohun ìwádìí àwọn alábòójútó àti ti ìdíje ní kété tí a bá tẹ̀ ẹ́ jáde | Ìṣirò tí a lè ṣàyẹ̀wò, kì í ṣe nọ́mbà tí a jíròrò lé lórí |

Àwọn ilé-iṣẹ́ tí yóò mú èyí dáadáa ni àwọn tí ó bẹ̀rẹ̀ sí í ṣírò ìnáwó ìpèsè dátà **báyìí**, nígbà tí ó ṣì jẹ́ iṣẹ́ inú ilé, dípò nínú ìjíròrò scheme níbi tí nọ́mbà náà ti di ipò tí wọ́n gbọ́dọ̀ dáàbò bò.

## Iṣẹ́ Ìkọ́lé Náà Kì Í Ṣe API

Iṣẹ́ ẹ̀rọ tí ó ṣe pàtàkì kì í ṣe interface. Gbogbo ohun tí ó wà lẹ́yìn rẹ̀ ni.

Dátà account ìsanwó ti wà ní ìṣètò tẹ́lẹ̀, ó ti wà ní àkókò gidi tẹ́lẹ̀, ètò kan ṣoṣo pẹ̀lú olóhun kan ṣoṣo ló sì ni í tẹ́lẹ̀. Dátà mọ́gẹ́ẹ̀jì, owó ìfẹ̀yìntì, ìdókòwò àti insurance kò jẹ́ ọ̀kan nínú àwọn nǹkan wọ̀nyẹn. Ó dùbúlẹ̀ nínú àwọn product silo tí ọjọ́ orí wọn yàtọ̀, pẹ̀lú àwọn ìdámọ̀ oníbàárà ọ̀tọ̀ọ̀tọ̀, dátà ìtọ́kasí ọ̀tọ̀ọ̀tọ̀ àti ìtumọ̀ ọ̀tọ̀ọ̀tọ̀ fún pápá kan náà. Nínú ìwé àkọsílẹ̀ nìkan ni apá kan rẹ̀ wà.

Agbára mẹ́ta ni ó gba àkókò ìdúró jùlọ, kò sì sí ọ̀kan nínú wọn tí ó sinmi lé ìwé ìkẹyìn.

**Ìpele entity resolution oníbàárà.** Sísin ìbéèrè dátà túmọ̀ sí mímọ̀ pé oníbàárà mọ́gẹ́ẹ̀jì, ẹni tí ó ní owó ìfẹ̀yìntì àti ẹni tí ó ní account lọ́wọ́lọ́wọ́ jẹ́ ẹni kan náà, pẹ̀lú ìdánilójú tí ó ga tó láti tú dátà sílẹ̀ lórí rẹ̀. Ọ̀pọ̀ ilé-iṣẹ́ ni ó rí i pé entity resolution wọn rẹlẹ̀ ju bí wọ́n ṣe rò lọ ní gan-an àkókò tí wọ́n gbìyànjú rẹ̀.

**Ṣíṣe dátà ọjà ní déédéé.** Scheme yóò pinnu àwọn ọ̀nà àjọṣe. Ohunkóhun tí wọ́n bá jẹ́, iṣẹ́ mímú dátà ọjà àtijọ́ bá ọ̀pá-ìwọ̀n ìta *èyíkéyìí* mu jẹ́ iṣẹ́ kan náà, òun sì ni ohun tí ó tóbi jùlọ nínú ètò náà.

**Ipò ìyọ̀nda gẹ́gẹ́ bí ìkọ́lé-ẹ̀rọ.** Dashboard jẹ́ ojú-ìwòye. Lábẹ́ rẹ̀ ni àkọsílẹ̀ tí ó dúró ṣinṣin, tí a lè ṣàyẹ̀wò gbọ́dọ̀ dùbúlẹ̀: ìyọ̀nda wo ni a fún ni, ẹni tí ó fúnni, lórí dátà wo, fún ìgbà mélòó, àti ìgbà tí a fà á sẹ́yìn — tí gbogbo ètò tí ó ń sin ìbéèrè lè wádìí ní àkókò gidi. Àwọn ilé-iṣẹ́ tí ó kọ́ dashboard náà kí wọ́n tó kọ́ ìwé-ìkọsílẹ̀ ìyọ̀nda ń kọ́ ohun tí wọn yóò tún kọ́ lẹ́ẹ̀kejì.

## Ìtọ́sọ́nà Ìṣiṣẹ́

1. **Fi ẹnìkan sínú ìjíròrò scheme náà.** Kì í ṣe ayàwòrán-ìkọ́lé — olùjíròrò ọjà tí ó ní àṣẹ lórí liability àti ìdíyelé. Èyí ni ìṣe tí ó ní agbára jùlọ tí ó wà, òun sì ni èyí tí a sábà ń sún síwájú jùlọ.
2. **Ṣírò ìnáwó ìpèsè dátà báyìí.** Kọ́ àwòṣe ìpínsí nígbà tí ó ṣì jẹ́ ìbéèrè inú ilé. Ọ̀nà ìṣirò compensation tí a dá sílẹ̀ lábẹ́ ìkìmọ́lẹ̀ ìjíròrò kò ní dúró lábẹ́ ìwádìí.
3. **Bẹ̀rẹ̀ entity resolution kí a tó pinnu scope.** Gbogbo àpẹẹrẹ FiDA béèrè kí o mọ̀ pé oníbàárà rẹ jẹ́ oníbàárà kan. Kò sí ohun tí ó yí padà nínú ìyẹn ní trilogue.
4. **Kọ́ ìwé-ìkọsílẹ̀ ìyọ̀nda, kì í ṣe dashboard.** Ohun tí ojú ń rí jẹ́ iṣẹ́ front-end ọ̀sẹ̀ kan. Àkọsílẹ̀ tí ó wà lábẹ́ rẹ̀ ni apá tí ó ní ìrù ọdún méjì.
5. **Ka àwọn silo náà pẹ̀lú òtítọ́.** Dá àwọn ọjà tí ó wà nínú scope tí kò lè pèsè dátà tí ó ní ìṣètò, tí ó sì wà lọ́wọ́lọ́wọ́ rárá mọ̀. Àkọsílẹ̀ yẹn ni ètò gidi náà.
6. **Tọ́pinpin scope, kì í ṣe àkọlé ìròyìn.** Àwọn òṣùwọ̀n tí ó ṣeé ṣe kí ó yí padà jùlọ ní trilogue — ọjà wo, dátà wo, àkókò wo — ni gan-an àwọn tí ètò rẹ gbọ́dọ̀ lè gbà láìjẹ́ pé o tún un kọ́.

PSD2 kọ́ àwọn báńkì láti mú dátà ṣíṣí gẹ́gẹ́ bí ìnáwó ìtẹ̀lé-òfin tí a gbọ́dọ̀ dín kù. Èrò yẹn kì í ṣe ibi ìbẹ̀rẹ̀ tí ó tọ́ níhìn-ín. Nígbà tí ààyè bá ní iye owó, tí a bá fi ìjíròrò pinnu scope rẹ̀, tí ó sì bo àwọn ọjà tí báńkì ń jèrè lórí ní tòótọ́, àwọn ilé-iṣẹ́ tí ó bá mú un gẹ́gẹ́ bí ọjà ni yóò gbé àdéhùn kalẹ̀ fún àwọn tí ó mú un gẹ́gẹ́ bí ẹrù.

## Àwọn Ìbéèrè Tí A Sábà Ń Béèrè

**Ṣé FiDA ti di òfin?**  
Rárá. A gbé e kalẹ̀ ní oṣù Kẹfà 2023 gẹ́gẹ́ bí ara pákéèjì financial data access àti ìsanwó, ó sì ṣì wà nínú ìlànà ìṣòfin EU, lẹ́yìn tí ó ti gba inú trilogue kọjá. A fi kún àkọsílẹ̀ ìfagilé tí ó jò jáde ní ìbẹ̀rẹ̀ ọdún 2025, lẹ́yìn náà a fi í sílẹ̀ nínú ètò iṣẹ́ ìkẹyìn ti Ìgbìmọ̀ náà. Scope, àkókò àti ọ̀nà compensation jẹ́ àwọn ìpèsè tí ó ṣì lè yí padà.

**Báwo ni ó ṣe yàtọ̀ sí PSD2 ní ìṣe?**  
Ọ̀nà mẹ́ta tí ó ṣe pàtàkì. Ìtẹ̀lé-òfin yóò gba financial data sharing scheme dípò interface tí o kọ́ fúnra rẹ; àwọn data holder lè béèrè compensation tí ó bọ́gbọ́n mu dípò pípèsè ààyè lọ́fẹ̀ẹ́; dátà tí ó wà nínú scope sì gbòòrò kọjá àwọn account ìsanwó dé mọ́gẹ́ẹ̀jì, awin, ìfowópamọ́, ìdókòwò, crypto-assets, owó ìfẹ̀yìntì àti non-life insurance.

**Kí ni financial data sharing scheme?**  
Àdéhùn ìlànà láàrin àwọn data holder, data user àti àwọn aṣojú oníbàárà tàbí oníbàárà-ọjà. A retí pé yóò gbé àwọn ọ̀pá-ìwọ̀n dátà àti interface àjọṣe kalẹ̀, yóò pín liability nínú àdéhùn láàrin àwọn ọmọ ẹgbẹ́, yóò sì pèsè dispute resolution. Nítorí pé ó ń pinnu àwọn àdéhùn tí a ó fi dì ọ́ mú, ìjẹ́-ọmọ-ẹgbẹ́ àti ipa jẹ́ ìbéèrè ìlànà, kì í ṣe ti iṣẹ́ ọ́fíìsì.

**Bí ìwé náà kò bá tíì parí, kí ni a lè kọ́ ní ọ̀nà tí ó wúlò báyìí?**  
Àwọn apá tí gbogbo àpẹẹrẹ nílò: entity resolution oníbàárà káàkiri àwọn product silo, ṣíṣe dátà ọjà àtijọ́ ní déédéé sí ọ̀pá-ìwọ̀n ìta, àti ìwé-ìkọsílẹ̀ ìyọ̀nda tí ó dúró ṣinṣin lábẹ́ dashboard náà. Kò sí ọ̀kan nínú wọn tí ó sinmi lé bí scope tàbí àkókò yóò ṣe dúró, gbogbo àwọn mẹ́tẹ̀ẹ̀ta sì ní àkókò ìdúró gígùn.

**Ṣé kí a kọ FiDA tàbí kí a tẹ̀wọ́gbà á?**  
Kíkọ àbá tí ó ti yè nínú ìgbìyànjú ìfagilé kan jẹ́ ìlò búburú fún fèrèsé àkókò tí ó ṣẹ́kù. Ìbéèrè tí ó wúlò jù ni bóyá ilé-iṣẹ́ rẹ jẹ́ data holder tàbí data user ní àpapọ̀ nínú àwọn abala tí ó jẹ ọ́ lógún — nítorí ìyẹn ni yóò pinnu bóyá o fẹ́ kí ọ̀nà ìṣirò compensation ga tàbí kí ó rẹlẹ̀, a sì ń yanjú àríyànjiyàn yẹn nínú scheme, kì í ṣe ní Brussels.
