Fún ohun tó ju ààbọ̀ ọ̀rúndún lọ, ìtẹ̀síwájú kọ̀ǹpútà tẹ̀lé òfin Moore: kíkó ìlọ́po méjì transistor sórí silicon ní gbogbo oṣù méjìdínlógún sí mẹ́rìnlélógún. Ṣùgbọ́n nínú ẹ̀ka tuntun physical AI àti robotics tí ń dá ṣiṣẹ́, òfin Moore ti kọlu àwọn òfin thermodynamics. Àwọn drone tí ń dá fò, robot ẹlẹ́sẹ̀ mẹ́rin, apá robot fún iṣẹ́ abẹ àti ọkọ̀ tí ń wa ara rẹ̀ kò lè gbé àwọn GPU ìpele server tí ń jẹ watt 700 tàbí ilé-ìṣọ́ ìtutù. Ní Economist Enterprise Physical AI and Robotics Summit ní London ní ọjọ́ 13 Oṣù Kẹwàá 2026, Taner Ozcelik, Alága àti Olórí Àgbà Mythic AI, darapọ̀ mọ́ Kenneth Cukier fún ìjíròrò fireside kan tí ó ṣàyẹ̀wò ìyípadà ńlá nínú ètò tí a nílò láti fọ́ ìdènà yìí: kíkọjá òfin Moore nípasẹ̀ analog compute-in-memory (CIM) àti àwọn modular chiplet.

## Ògiri thermodynamic: ìdí tí physical AI kò fi lè gbé inú cloud

Nínú ìjókòó fireside tí àkọlé rẹ̀ jẹ́ *Moving past Moore’s law: the power behind high-performance robotics*, Kenneth Cukier gbé ìṣòro ìmọ̀-ẹ̀rọ pàtàkì tí ìdáṣiṣẹ́ ilé-iṣẹ́ ń dojú kọ kalẹ̀: àwọn àwòṣe artificial intelligence ń pọ̀ sí i ní ìwọ̀n parameter àti agbára òye, ṣùgbọ́n àwọn ẹ̀rọ ti ara ń ṣiṣẹ́ lábẹ́ ààlà SWaP-C tí ó le (Size, Weight, Power, and Cost).

Ààlà AI òde-òní dúró sórí àwọn hyperscale data centre tí ń fa megawatt 150 tàbí jù bẹ́ẹ̀ lọ káàkiri àwọn agbo server ńlá. Gẹ́gẹ́ bí Ozcelik ṣe tọ́ka sí, ètò yìí ń ṣiṣẹ́ ní ìwọ̀n agbára tí ó jìnnà sí àwọn àmì ìtọ́kasí ẹ̀dá alààyè ní ìlọ́po mílíọ̀nù. Ọpọlọ ènìyàn ń ṣe ìṣọ̀kan ìmọ̀lára àti ìṣípòpadà ní àkókò gidi, ìrònú olóye àti ìrìn-àjò ìrí-àti-àyè nínú power envelope ti ara tí ó tó nǹkan bí watt 20.

Nínú ìtàn, àwọn onímọ̀-ẹ̀rọ robotics gbìyànjú láti yẹra fún ààlà compute inú ẹ̀rọ nípa gbígbé inference lọ sí cloud. Síbẹ̀, ní àwọn àyíká ilé-iṣẹ́, ọkọ̀ òfuurufú àti ààbò tí iṣẹ́ wọn ṣe pàtàkì jùlọ, ìdáṣiṣẹ́ tí ó gbára lé cloud kò ṣeé ṣe rárá nínú ètò:

1. **Ìyàtọ̀ latency àti jitter**: Ìṣàkóso robot oníyára nínú ìyípo títì nílò ìmúdójúìwọ̀n mọ́tò tí ó dájú ní 50Hz sí 1,000Hz (ìrìn-àjò-padà tí kò tó millisecond 20). Àwọn nẹ́tíwọ́kì cellular àti Wi-Fi ń mú packet jitter, frame tí ó sọnù àti ìfòsókè latency wá tí ó ń mú kí apá robot ju ohun tí wọ́n gbé sílẹ̀ tàbí kí ọkọ̀ tí ń dá wa kùnà láti dé ààlà bíréèkì.
2. **Kíkún bandwidth**: Ṣíṣàn ọ̀pọ̀lọpọ̀ fídíò 4K tí a kò fún pọ̀ àti LiDAR point cloud láti ọ̀pọ̀lọpọ̀ robot alárìnkiri káàkiri ilé-iṣẹ́ kan máa ń jẹ RF bandwidth àdúgbò tán kíákíá, ó sì ń mú owó cloud egress gíga wá.
3. **Òmìnira iṣẹ́ àti ìsopọ̀ tí a ń jà lé lórí**: Nínú wíwa ohun-àlùmọ́nì lábẹ́ ilẹ̀, ọ̀nà abẹ́lẹ̀ tí kò ní GPS, ibi ìkọ́lé tí ó jìnnà tàbí àyíká ológun, àwọn ìsopọ̀ nẹ́tíwọ́kì ìta kò sí rárá tàbí a ń dí wọn mọ́lẹ̀ ní ìmọ̀ọ́mọ̀. Àwọn ètò tí ń dá ṣiṣẹ́ gbọ́dọ̀ gbé gbogbo òye iṣẹ́ wọn sórí ara ẹ̀rọ edge fúnra rẹ̀.

Fífi àwọn GPU alágbára àṣà sínú robot ní ìjìyà ti ara tirẹ̀: thermal throttling, àwọn heat sink ńlá tí ń fi ìwúwo àìnílò kún ẹrù, àti jíjẹ agbára gíga tí ń dín àkókò fífò bátírì kù láti wákàtí sí ìṣẹ́jú.

## Àbá ètò: Compute-In-Memory (CIM)

Láti yanjú ìdènà thermodynamic, Mythic AI ti gbé ìmọ̀-ọgbọ́n ètò kan síwájú: dípò gbígbé data síwá-sẹ́yìn láàárín àwọn ẹ̀ka ìṣiṣẹ́ àti àwọn adágún ìrántí tí ó yàtọ̀, ìrántí fúnra rẹ̀ ni ó gbọ́dọ̀ di kọ̀ǹpútà.

### Físíìsì matrix multiplication oní-transistor-kan
Nínú digital computing àtijọ́, ṣíṣírò matrix dot product nílò mímú ẹgbẹẹgbẹ̀rún iye weight 8-bit tàbí 16-bit láti DRAM ìta nípasẹ̀ àwọn bus line high-capacitance, kíkó wọn sínú cache register, ṣíṣe ìsọdipúpọ̀ nínú digital ALU, àti kíkọ àbájáde padà sí ìrántí. Ju ìdá 90% agbára lọ ni a ń lò láti gba agbára sí àti láti tú agbára kúrò nínú àwọn ìlà copper interconnect láàárín àwọn chip.

Àwọn ètò in-memory compute ń fi físíìsì analog circuit rọ́pò gbígbé data digital yìí:

**Ṣíṣètò weight.** A ń ṣètò àwọn weight neural network tààrà sínú àwọn non-volatile memory cell (bíi flash tí a ti yí padà tàbí resistive RAM) gẹ́gẹ́ bí analog conductance ($G$). Lẹ́yìn tí a ti ṣètò wọn, àwọn weight máa ń dúró sójú kan nínú memory array; a kì í mú wọn tàbí gbé wọn rárá nígbà inference.

**Ìṣàtúnṣe voltage input.** A ń yí àwọn input activation (bíi visual token láti kámẹ́rà) padà sí ìpele analog voltage ($V$) a sì ń darí wọn gba àwọn word line array.

**Ìsọdipúpọ̀ òfin Ohm.** Bí voltage input ṣe ń kọjá nínú memory cell kọ̀ọ̀kan, òfin Ohm ($I = V \times G$) ń ṣe ìsọdipúpọ̀ analog lójú ẹsẹ̀, ó ń dá iná mànàmáná tí ó bá àbájáde ìsọdipúpọ̀ input àti weight tí a fi pamọ́ mu.

**Ìkójọpọ̀ Kirchhoff's Current Law.** Lórí àwọn bit line inaro, iná láti ẹgbẹẹgbẹ̀rún memory cell tí ó wà ní ìbámu ń dàpọ̀ fúnra wọn gẹ́gẹ́ bí Kirchhoff's Current Law ($\sum I = 0$).

Nítorí náà, flash memory array kan ṣoṣo ń ṣe gbogbo matrix-vector multiplication nínú clock cycle kan ṣoṣo, ó ń ṣiṣẹ́ ní ìpele físíìsì láìsí mímú ìrántí kankan. Lẹ́yìn náà a ń yí iná analog tí a kó jọ padà sí iye digital nípasẹ̀ àwọn high-speed analog-to-digital converter (ADC) ní etí array.

## Ọgbọ́n modular chiplet

Bí analog compute-in-memory tilẹ̀ ń yanjú ìṣirò agbára àti latency, fífẹ̀ silicon ká àwọn ẹ̀ka ìṣòwò oríṣiríṣi nílò ìrọ̀rùn nínú packaging. Dípò ṣíṣe àwọn system-on-chip (SoC) ńlá oníkan ṣoṣo - tí ó ń jìyà ìwọ̀n àbùkù tí ń gòkè lọ́nà exponential, èso wafer tí kò dára àti ètò ọjà tí kò ṣeé yí padà - Ozcelik ṣàlàyé ọgbọ́n modular chiplet kan.

Lábẹ́ ìlànà yìí, a ń ṣe àwọn in-memory compute tile kékeré tí a ṣe déédéé lọ́tọ̀ọ̀tọ̀, a sì ń lẹ̀ wọ́n mọ́ àwọn interposer nípa lílo advanced packaging:

1. **Àwọn high-speed die-to-die interconnect tí a ṣe déédéé**: Nípa lílo àwọn ìlànà tuntun bíi Universal Chiplet Interconnect Express (UCIe), àwọn chiplet ń bá ara wọn sọ̀rọ̀ nípasẹ̀ àwọn micro-bump pẹ̀lú bandwidth density gíga àti latency ní ìpele picosecond.
2. **Àkópọ̀ oníyàtọ̀**: Olùṣètò ètò lè so in-memory chiplet méjì pọ̀ mọ́ ARM control processor olówó pọ́ọ́kú fún ẹrù drone fúyẹ́, tàbí kó chiplet mẹ́rìndínlógún jọ pẹ̀lú àwọn high-speed PCIe interface láti ṣe server accelerator card fún àwọn edge data centre.
3. **Compilation gbogbo-gbòò àti pínpín iṣẹ́**: Compiler layer kan ṣoṣo ń gba àwọn deep learning graph àṣà (ONNX, PyTorch) ó sì ń pín àwọn layer àwòṣe ká chiplet topology tí ó wà fúnra rẹ̀, ó ń mú ìrìn-àjò data dára jù láti dín ìbánisọ̀rọ̀ láàárín àwọn chiplet kù.

## Ìfiwéra ètò: àwọn ìlànà compute fún edge robotics

| Abala ètò | Digital GPU àṣà (NVIDIA Jetson / Orin) | Edge NPU àdáyanrí (Google Coral / Hailo) | Analog Compute-In-Memory chiplet (Mythic AI) |
|---|---|---|---|
| **Ọ̀nà ìṣiṣẹ́ ìpìlẹ̀** | Digital SIMD/tensor core tí ń mú weight láti LPDDR5/HBM | Digital systolic array pẹ̀lú ìpamọ́ weight nínú on-chip SRAM | Analog array oní-transistor-kan tí ń ṣe matrix multiply níbẹ̀ gan-an |
| **Ẹrù gbígbé data** | Gíga (gbígba agbára DRAM/SRAM bus láìdáwọ́dúró; ìṣòfò agbára 85%+) | Àárín (SRAM cache inú ló dín in kù) | Kò sí gbígbé data inú; weight ń dúró nínú ìrántí títí láé |
| **Power envelope inference** | 30W sí 75W+ (ó nílò fáànù ìtutù àti heat sink wúwo) | 5W sí 15W (ìtutù aláìṣiṣẹ́ tàbí díẹ̀) | 10W sí 20W (ìtújáde ooru aláìṣiṣẹ́ ní àyè kékeré gan-an) |
| **Ìṣiṣẹ́ agbára (TOPS/W)** | 2 sí 5 TOPS/Watt (ní ìpele ètò) | 10 sí 25 TOPS/Watt | 50 sí 200+ TOPS/Watt (ìṣiṣẹ́ ìmọ̀-ìjìnlẹ̀ 10x-1000x) |
| **Bill-of-materials (BOM) ẹ̀rọ** | £500 sí £2,500+ fún compute module kọ̀ọ̀kan | £100 sí £350 fún accelerator board kọ̀ọ̀kan | Dọ́là mẹ́wàá-mẹ́wàá fún chiplet kọ̀ọ̀kan ní ìṣelọ́pọ̀ ńlá |
| **Memory bottleneck (Von Neumann)** | Le gan-an; memory bandwidth ló dín in kù (GB/s sí TB/s) | Àárín; agbára on-chip SRAM ló dín in kù (MBs) | Kò sí; bandwidth array bá memory matrix inú mu |
| **Ẹ̀ka lílò tí a fojú sun** | Àwọn ọkọ̀ tí ń dá wa olówó ńlá àti robot àyẹ̀wò ilé-iṣẹ́ | Àwọn kámẹ́rà ọlọ́gbọ́n àti ẹ̀rọ IoT fúyẹ́ | Robotics ìfọwọ́kàn oníyára, drone ológun àti AI ọkọ̀ |

*Orísun: Àkópọ̀ data ìjíròrò fireside àti àwọn àpèjúwe ètò semiconductor tí a gbé kalẹ̀ ní Economist Enterprise Physical AI and Robotics Summit (Convene 200 Aldersgate, London, 13 Oṣù Kẹwàá 2026).*

## Ohun tí èyí túmọ̀ sí ní ẹ̀ka kọ̀ọ̀kan

Ìfọwọ́sí ìṣòwò in-memory compute dá lórí wíwọnú àwọn ilé-iṣẹ́ tí ààlà agbára àti owó ti dí lílo àwọn foundation model tó ga lọ́wọ́ nínú ìtàn.

### Ààbò ológun àti àwọn ètò aláìní awakọ̀
Nínú àwọn ohun èlò ààbò edge, ìṣiṣẹ́ agbára ń yí padà tààrà sí ìwàláàyè ní pápá iṣẹ́ àti gígùn iṣẹ́ àṣẹ. Àwọn ètò òfuurufú kékeré aláìní awakọ̀ (sUAS) àti àwọn rover ilẹ̀ ológun ni ìwúwo bátírì dín kù gidigidi. Fífi GPU àṣà sínú drone ìṣàwárí ń dín àkókò rẹ̀ lójú òfuurufú kù ní ìdá 30% sí 50% kìkì láti fún AI perception stack ní agbára.

Ìbáṣepọ̀ Mythic AI pẹ̀lú Lockheed Martin dojú kọ fífi in-memory compute sínú àwọn ètò edge ológun, agbo drone tí ń dá fò àti àwọn ibùdó ìṣọ́ jíjìnnà. Nípa dídín jíjẹ agbára compute kù láti 50W sí ìsàlẹ̀ 10W, àwọn drone ológun ń ní àkókò fífò tó gùn nígbà tí wọ́n ń ṣe multi-modal object classification, ìṣiṣẹ́ àmì ogun ẹ̀rọ-itanna àti visual-inertial odometry níbẹ̀, ní àwọn pápá iṣẹ́ tí a ń jà lé lórí tí kò sì ní GPS.

### Ìmọ̀ àyíká ọkọ̀ àti AI inú ọkọ̀
Nínú ẹ̀ka ọkọ̀, àwọn olùṣe tier-one ń dojú kọ fífúnpọ̀ èrè tó le. Bí àwọn ọkọ̀ iná mànàmáná olówó ńlá tilẹ̀ lè gbé owó kọ̀ǹpútà ìwakọ̀ aládàáṣe tí a fi omi tutù ti £2,000, àwọn ọkọ̀ àwọn ará ìlú kò lè ṣe bẹ́ẹ̀.

Ìbáṣepọ̀ Honda Motor pẹ̀lú Mythic AI ń kojú ìdènà ìṣòwò yìí. Àwọn olùṣe ọkọ̀ nílò AI chip tí ó tọ́ fún ọkọ̀, tí a ń ṣe ní ọ̀pọ̀lọpọ̀, tí owó wọn jẹ́ dọ́là mẹ́wàá-mẹ́wàá dípò ọgọ́rọ̀ọ̀rún, tí ó lè ṣiṣẹ́ ètò ìṣọ́ awakọ̀, blind-spot object segmentation àti 360-degree surround perception láìnílò àwọn ìyípo ìtutù omi dídíjú tí ń fi owó ìṣelọ́pọ̀ àti ìdíjú àkójọpọ̀ kún un.

### Àwọn edge data centre ilé-iṣẹ́ àti mobile fulfillment
Bí a tilẹ̀ ṣe in-memory compute fún edge ní pàtàkì, Mythic ń ṣe ọgbọ́n afárá kan ní ìmọ̀ọ́mọ̀ nípa pípèsè àwọn PCIe accelerator card fún àwọn edge data centre àti àwọn ibùdó fulfillment ilé-ìpamọ́ ẹrù. Ní àwọn ibi tí ọgọ́rọ̀ọ̀rún autonomous mobile robot (AMR) wà, ààlà ìlà iná mànàmáná àti ìtutù ibẹ̀ ń dín àwọn edge server rack tí ń ṣiṣẹ́ àwòṣe ìṣọ̀kan agbo robot kù. Àwọn in-memory accelerator card ń jẹ́ kí àwọn ibi wọ̀nyí sọ inference throughput àdúgbò di púpọ̀ láìṣe àtúnṣe ètò agbára iná mànàmáná.

## Ìfaradà supply chain àti ìpínlẹ̀ ìṣelọ́pọ̀

Apá pàtàkì kan nínú àlàyé Ozcelik dá lórí òmìnira supply chain. Ìmọ̀tuntun hardware kò ní ìtumọ̀ bí a kò bá lè ṣe silicon, kó o sínú packaging kí a sì fi ránṣẹ́ ní ìwọ̀n ńlá ní ọ̀nà tí ó ṣeé gbẹ́kẹ̀lé.

Mythic AI ti dá ètò ìṣelọ́pọ̀ kan sílẹ̀ tí ó tàn ká àwọn orílẹ̀-èdè:

- **Ìṣelọ́pọ̀ silicon**: Ìṣelọ́pọ̀ in-memory wafer pàtàkì dúró sí Tokyo, Japan, ó ń jàǹfààní nínú aṣáájú Japan tí a ti mọ̀ nínú ìṣelọ́pọ̀ semiconductor tí ó péye àti àwọn analog/flash process node tí ó ti dàgbà.
- **Advanced packaging àti àkójọpọ̀**: A ń fi àwọn wafer ránṣẹ́ sí Yúróòpù (Jámánì ní pàtàkì) fún advanced chiplet dicing, multi-die substrate bonding àti automated optical inspection.
- **Ìfọwọ́sí àtúnṣe**: Ilé-iṣẹ́ náà ń parí ìfọwọ́sí àtúnṣe silicon rẹ̀ tuntun báyìí, ó ń dojú kọ yíyí àwọn ìwọ̀n èso yàrá ìwádìí padà sí Statements of Work (SOW) tí ó ṣeé tún ṣe ní ìpele ìṣelọ́pọ̀ fún ìṣelọ́pọ̀ ńlá ọkọ̀ àti ààbò.

Ọ̀nà agbègbè-púpọ̀ yìí ń yẹra fún àìlágbára ìṣèlú ibi kan ṣoṣo, nígbà tí ó ń fún àwọn alábàáṣiṣẹ́pọ̀ ilé-iṣẹ́ ní Yúróòpù àti Éṣíà ní supply chain tí ó tàn ká onírúurú ibi.

## Ìparí

Ìjíròrò fireside láàárín Taner Ozcelik àti Kenneth Cukier ní Economist Enterprise Physical AI and Robotics Summit ṣàlàyé òtítọ́ ti ara tí yóò darí ẹ̀wádún tó ń bọ̀ ti àwọn ètò tí ń dá ṣiṣẹ́. Òfin Moore, gẹ́gẹ́ bí ìwọ̀n rírọrùn ti ìdàgbàsókè transistor, kò tó mọ́ láti fún ìyípadà physical AI ní agbára.

Níwọ̀n ìgbà tí àwọn ètò kọ̀ǹpútà bá ṣì dì mọ́ ìyapa logic àti ìrántí ti Von Neumann, robotics yóò máa wà lábẹ́ ààlà ìwúwo bátírì, ìtújáde ooru àti owó bill-of-materials tí ó ga jù. Nípa yíyípadà láti gbígbé data digital sí àwọn analog in-memory compute array àti modular chiplet topology, ìmọ̀-ẹ̀rọ semiconductor ń mú fífò ìṣiṣẹ́ tí àwọn ètò tí ń dá ṣiṣẹ́ nílò wá.

Ìyípadà láti agbo data centre 700W sí edge silicon 15W ni ẹnu-ọ̀nà gidi sí ìdáṣiṣẹ́ ti ara. Ní ìparí gbogbo rẹ̀, àwọn robot tí ń ṣiṣẹ́ ní ayé gidi gbọ́dọ̀ tẹ̀lé àwọn òfin agbára ti ayé gidi; in-memory compute ni ètò tí ó ń so silicon àti ẹ̀dá alààyè pọ̀.

## Àwọn Ìbéèrè Tí A Sábà Ń Bèèrè

**Kí ni Von Neumann bottleneck nínú AI hardware?**
Von Neumann bottleneck túmọ̀ sí ààlà throughput àti agbára tí ìyapa ti ara láàárín central processing unit (ALU) àti ìrántí ètò (DRAM) ń fà. Nínú iṣẹ́ artificial intelligence, tí ó ní bílíọ̀nù matrix multiplication nínú, àwọn processor ń lo ju ìdá 85% gbogbo agbára wọn àti ọ̀pọ̀ clock cycle kìkì fún gbígbé data síwá-sẹ́yìn gba copper bus, èyí tí ó ń dá ìdènà ooru àti latency tó le sílẹ̀.

**Báwo ni analog Compute-In-Memory (CIM) ṣe ń ṣiṣẹ́?**
Compute-In-Memory ń ṣe iṣẹ́ ìṣirò tààrà nínú memory cell láìgbé data. A ń fi àwọn weight neural network pamọ́ gẹ́gẹ́ bí ipò analog conductance nínú àwọn non-volatile memory cell. Nígbà tí a bá fi input voltage sí array, iná ń ṣàn gba àwọn cell gẹ́gẹ́ bí òfin Ohm ($I = V \times G$), ó sì ń dàpọ̀ lórí àwọn bit line gẹ́gẹ́ bí Kirchhoff's Current Law. Èyí ń parí gbogbo matrix-vector multiplication ní ìgbésẹ̀ ti ara kan ṣoṣo.

**Kí nìdí tí in-memory compute fi ṣe pàtàkì gan-an fún robotics àti drone?**
Àwọn robot alárìnkiri àti drone ń ṣiṣẹ́ lábẹ́ ààlà Size, Weight, Power, and Cost (SWaP-C) tí ó le. Wọ́n gbára lé bátírì inú wọn, wọn kò sì lè gbé àwọn radiator ìtutù wúwo tàbí ẹ̀rọ agbára oníwatt gíga. In-memory compute ń pèsè ìṣiṣẹ́ agbára tí ó ga jù ní ìlọ́po 10x sí 1,000x, èyí tí ó ń jẹ́ kí robot ṣiṣẹ́ àwọn àwòṣe vision-language-action dídíjú níbẹ̀ nínú power envelope ti 10W sí 20W nígbà tí wọ́n ń pa àkókò bátírì mọ́.

**Kí ni àǹfààní ọ̀nà chiplet lórí chip oníkan ṣoṣo?**
Àwọn chip oníkan ṣoṣo ń kó gbogbo ẹ̀ka iṣẹ́ jọ sórí silicon die ńlá kan ṣoṣo. Bí die ṣe ń tóbi sí i, ìwọ̀n àbùkù ìṣelọ́pọ̀ ń gòkè lọ́nà exponential, ó ń dín èso ìṣelọ́pọ̀ kù, ó sì ń mú owó ẹyọ kọ̀ọ̀kan pọ̀ sí i. Ètò chiplet ń pín ètò náà sí àwọn silicon die kékeré tí a ṣe déédéé, tí a ń ṣe lọ́tọ̀ọ̀tọ̀ pẹ̀lú èso gíga, tí a sì ń so pọ̀ nípasẹ̀ àwọn high-speed micro-bump. Èyí ń gba ètò modular tí ó rọrùn láyè, tí a ṣe fún àwọn ìbéèrè agbára àti form factor ilé-iṣẹ́ pàtó.

**Ta ni àwọn alábàáṣiṣẹ́pọ̀ ìṣòwò pàtàkì fún ìmọ̀-ẹ̀rọ yìí?**
Pẹpẹ in-memory compute Mythic AI dúró lọ́wọ́lọ́wọ́ lórí ìbáṣepọ̀ ilé-iṣẹ́ ńlá méjì: Lockheed Martin, tí ó ń fi ètò náà sínú àwọn drone ààbò ológun, àwọn pẹpẹ robot aláìní awakọ̀ àti àwọn ibùdó ààbò ààlà láti mú àkókò bátírì gùn sí i; àti Honda Motor, tí ó ń fojú sun AI chip olówó pọ́ọ́kú tí ó tọ́ fún ọkọ̀ fún ìmọ̀ àyíká ọkọ̀ àti òye inú ọkọ̀.
