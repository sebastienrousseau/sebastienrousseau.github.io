> **Àkópọ̀ fún Àwọn Aláṣẹ**
>
> - RFC náà jẹ́ ìwé IETF-stream, Standards Track tí a dá ọjọ́ rẹ̀ sí November 2026 (ISSN 2070-1721), tí M. Ounsworth àti J. Gray ti Entrust, M. Pala ti OpenCA Labs, J. Klaußner ti Bundesdruckerei GmbH àti S. Fluhrer ti Cisco Systems kọ.
> - Ìpìlẹ̀ rẹ̀ ni pé RSA, DSA àti àwọn ẹ̀yà elliptic curve wọn yóò di aláìlera sí ìkọlù quantum. Àìdánilójú kan ṣoṣo ni àkókò.
> - Ó kọ́ àwọn PQ/T hybrid pẹ̀lú ML-DSA (FIPS 204) gẹ́gẹ́ bí ẹ̀yà post-quantum, tí a so mọ́ RSASSA-PSS, RSASSA-PKCS1-v1_5, ECDSA, Ed25519 tàbí Ed448.
> - A fi composite náà hàn gẹ́gẹ́ bí algorithm atomic kan ṣoṣo, nítorí náà protocol lè gbára lé cryptographic agility tí ó wà dípò kí a yí wọn padà.
> - Ìfọwọ́sí ìlànà tuntun ló ń darí àwọn àpapọ̀ púpọ̀ náà, ìwé náà sì dárúkọ àwọn nǹkan mélòó kan tí kò pèsè.

## Kí ló dé tí a fi nílò hybrid signature rárá

Ìwé náà ni RFC 10073, *Composite Module-Lattice-Based Digital Signature Algorithm (ML-DSA) for Use in X.509 Public Key Infrastructure*, tí IETF tẹ̀ jáde ní November 2026, tí M. Ounsworth, J. Gray, M. Pala, J. Klaußner àti S. Fluhrer kọ.

RFC náà bẹ̀rẹ̀ láti ìpìlẹ̀ kan tí ó sọ láìsí àfikún ìkìlọ̀: àwọn signature algorithm àtijọ́ bí RSA, DSA àti àwọn ẹ̀yà elliptic curve wọn yóò di aláìlera sí ìkọlù quantum. Ó gbé ipò náà kalẹ̀ gẹ́gẹ́ bí ọ̀ràn àkókò nìkan. Ó sọ pé a ó fọ́ àwọn algorithm àtijọ́ ní ọjọ́ iwájú ṣùgbọ́n wọn yóò ṣì lágbára ní àárín àkókò yìí, àìdánilójú kan ṣoṣo sì ni ìgbà wo.

Àgbékalẹ̀ yẹn ṣe pàtàkì nítorí ó kọ ìtumọ̀ ọ̀lẹ ti ìṣòro náà. Bí ìfọ́ bá dájú tí ọjọ́ nìkan ni a kò mọ̀, dídúró kì í ṣe àṣàyàn aláìdásí. Ṣùgbọ́n ìwé náà sọ òótọ́ bákan náà nípa iye owó lílọ ní kùtùkùtù. Ètò ìṣípò tí ó yára lè béèrè ìgbékalẹ̀ àwọn algorithm post-quantum cryptography (PQC) ṣáájú kí a tó mú ìmúṣẹ wọn le tàbí fọwọ́ sí wọn pátápátá. RFC náà ṣọ́ra níbí, àwa náà gbọ́dọ̀ ṣọ́ra: ó sọ "lè", kì í ṣe "yóò".

Gbé ìfúnpá méjèèjì yẹn sí ẹ̀gbẹ́ ara wọn, ìdí fún hybrid á sì yọ jáde. O fẹ́ ààbò lòdì sí ọjọ́ iwájú quantum, ṣùgbọ́n àwọn algorithm tuntun àti ìmúṣẹ wọn ṣì kéré. RFC náà sọ pé ààbò dátà algorithm méjì lè jẹ́ ohun tí a fẹ́ fún àkókò gígùn, láti dáàbò bo lòdì sí àìlera ààbò àti àwọn àbùkù ìmúṣẹ mìíràn nínú àwọn ìmúṣẹ tuntun. Èdè náà tún jẹ́ àfilọ́wọ̀. Ìwé náà dámọ̀ràn ìdí kan; kò sọ pé òun ti fi hàn pé hybrid ni ìpinnu tí ó tọ́ nígbà gbogbo.

Ó yẹ kí a mọ ohun tí composite ń fún ọ ní kedere. Àwọn algorithm composite ń pa ààbò díẹ̀ mọ́ kódà bí ọ̀kan nínú àwọn algorithm ẹ̀yà wọn bá fọ́. Gbólóhùn náà ni "ààbò díẹ̀", kì í ṣe ààbò kíkún, RFC náà kò sì ṣe àsọdùn rẹ̀. Ìtumọ̀ ìṣe ni pé ìkùnà nínú ẹ̀yà kan kò fi ọ́ sílẹ̀ láìní nǹkankan fúnra rẹ̀.

## Ìwé náà àti àwọn òǹkọ̀wé rẹ̀

Ṣáájú kí a tó yíjú sí ẹ̀rọ, orísun náà yẹ fún ìpínrọ̀ kan, nítorí àwọn olùdásílẹ̀ àti onímọ̀-ẹ̀rọ tí ń wọn standard kan gbọ́dọ̀ mọ irú standard tí ó jẹ́. RFC náà wà nínú stream Internet Engineering Task Force (IETF), ẹ̀ka rẹ̀ sì ni Standards Track. A tẹ̀ ẹ́ jáde ní November 2026, ó sì gbé ISSN 2070-1721. Ọ̀rọ̀ àkọsílẹ̀ boilerplate ṣàpèjúwe rẹ̀ gẹ́gẹ́ bí ìwé Internet Standards Track: ọjà IETF tí ó dúró fún ìfohùnṣọ̀kan àwùjọ IETF, tí IESG sì ti fọwọ́ sí fún ìtẹ̀jáde.

Àtòjọ òǹkọ̀wé náà kárí àjọ mẹ́rin. M. Ounsworth àti J. Gray wá láti Entrust, M. Pala láti OpenCA Labs, J. Klaußner láti Bundesdruckerei GmbH àti S. Fluhrer láti Cisco Systems. Èmi kò ní ka ohun tí ó ju ohun tí ìwé náà ṣe àtìlẹ́yìn fún sínú àkójọ yẹn. Ohun tí àtòjọ náà fi hàn ni pé èyí kì í ṣe iṣẹ́ olùtajà kan ṣoṣo.

Ìwé náà tún sọ fún àwọn òǹkàwé bí wọn yóò ṣe ka èdè normative rẹ̀. Àwọn ọ̀rọ̀ kókó bí "MUST" àti "SHOULD" ni a ó túmọ̀ bí a ṣe ṣàlàyé nínú BCP 14 (RFC 2119 àti RFC 8174) nígbà tí, àti kìkì nígbà tí, wọ́n bá fara hàn ní lẹ́tà ńlá pátápátá. Ìyẹn ni àṣà déédé, ṣùgbọ́n òun ni ìdí tí "should" ní lẹ́tà kékeré nínú specification yìí kò fi ní agbára pàtàkì kankan. Specification náà tún bá àwọn ọ̀rọ̀ tí a ṣàlàyé nínú RFC 9794 mu.

## Public key kan, signature value kan

Ìpinnu àgbékalẹ̀ àárín gbùngbùn rọrùn láti sọ. Algorithm composite náà fi public key kan àti signature value kan hàn, nítorí náà a lè kà á sí algorithm atomic kan ṣoṣo ní ìpele protocol.

Èyí jẹ́ àṣàyàn onígboyà ju bí ó ti kọ́kọ́ hàn lọ, mo sì rò pé òun ló tọ́. RFC náà ṣàlàyé ìyàtọ̀ náà tààrà: ọ̀pọ̀ PQ/T hybrid béèrè ìyípadà protocol láti mú un di "hybrid aware", nígbà tí specification yìí fi hybrid náà hàn gẹ́gẹ́ bí algorithm tí ó dá dúró, nítorí náà ó lè lo àwọn ẹ̀rọ cryptographic agility tí ó wà tẹ́lẹ̀.

Ronú nípa ohun tí èyí túmọ̀ sí fún ẹnikẹ́ni tí ó ní láti fi ọjà ránṣẹ́. Hybrid tí protocol gbọ́dọ̀ yé ni hybrid tí ó fọwọ́ kan gbogbo protocol tí ó fẹ́ lò ó. Hybrid tí ó dà bí algorithm mìíràn èyíkéyìí ni èyí tí ó wọ inú ẹ̀rọ ìdúnàádúrà tàbí ìdánimọ̀ algorithm tí ó wà tẹ́lẹ̀. RFC náà ṣàlàyé "algorithm" nínú àyíká yìí gẹ́gẹ́ bí èyí tí ó tọ́ka sí iṣẹ́ èyíkéyìí tí ó ní Object Identifier (OID) tí a forúkọ sílẹ̀ fún lílò nínú ASN.1 AlgorithmIdentifier. Composite ní ìdánimọ̀ tirẹ̀ nínú ètò yẹn, ètò àyíká rẹ̀ sì ń ṣe é bí yóò ti ṣe algorithm mìíràn èyíkéyìí.

Kókó ọ̀rọ̀ kan tí ó jọ mọ́ ọn ṣàlàyé ohun tí RFC náà ń sọ àti ohun tí kò sọ. Ó ṣàlàyé Protocol Backwards Compatibility gẹ́gẹ́ bí ànímọ́ kan níbi tí a ti lè fi ẹ̀yà tuntun kún protocol láìsí ìyípadà kankan sí specification protocol náà àti ìyípadà díẹ̀ péré sí ìmúṣẹ rẹ̀. Ọ̀nà algorithm atomic dojú kọ irú àfikún aláìnífàyàwọ́ yẹn gan-an. RFC náà gbé èyí kalẹ̀ gẹ́gẹ́ bí èrò àgbékalẹ̀: àwọn protocol bí PKCS #10, CMP, X.509, CMS àti Trust Anchor Format gbọ́dọ̀ lè ṣe àwọn algorithm composite bí wọn yóò ti ṣe algorithm mìíràn èyíkéyìí, láìsí pé ìpele protocol nílò "hybrid awareness" kankan.

## Ohun tí ó wà nínú composite

Ìdajì post-quantum ni ML-DSA, Module-Lattice-Based Digital Signature Algorithm tí a ṣàlàyé nínú FIPS 204. Specification náà lò ó gẹ́gẹ́ bí ẹ̀yà Post-Quantum ti àwọn PQ/T hybrid rẹ̀. Ìdajì àtijọ́ wá láti inú àkójọ tí a ṣàlàyé. A pèsè àwọn ìmúṣẹ ètò Composite ML-DSA tí ó dá lórí ML-DSA, RSASSA-PSS, RSASSA-PKCS1-v1_5, ECDSA, Ed25519 àti Ed448.

Abala ọ̀rọ̀ ṣàlàyé ẹ̀yà àtijọ́ kọ̀ọ̀kan. RSA fara hàn gẹ́gẹ́ bí Probabilistic Signature Scheme, RSASSA-PSS, tí a ṣàlàyé nínú RFC 8017. ECDSA ni Elliptic Curve Digital Signature Algorithm tí a ṣàlàyé nínú FIPS 186-5. EdDSA ni Edwards-curve Digital Signature Algorithm tí a ṣàlàyé nínú RFC 8410, pẹ̀lú àkójọ parameter méjì: Ed25519 àti Ed448. A lo Public Key Infrastructure (PKI) bí a ṣe ṣàlàyé rẹ̀ nínú RFC 5280, DER sì túmọ̀ sí Distinguished Encoding Rules bí a ṣe ṣàlàyé nínú X.690.

Ìwé náà fúnni ní àpẹẹrẹ kékeré ti ohun tí a kà sí ẹ̀yà cryptographic composite. Àwọn àpẹẹrẹ rẹ̀ ni àwọn algorithm asymmetric bí "ML-DSA-65" tàbí "RSASSA-PSS". A sì lo "signature" ní gbòòrò: signature cryptographic oní-nọ́mbà, láìsí ìrònú nípa algorithm wo.

Àpilẹ̀kọ yìí kò wọ inú ìkọ́lé inú ti composite signature, èyí tí RFC náà ṣàlàyé nínú àwọn abala tirẹ̀ lórí key generation, signing, verification àti serialisation. Ohun tí ó ṣe pàtàkì níbí ni pé ìrísí tí a rí láti òde, key kan àti signature kan, ni ànímọ́ tí ìyókù àgbékalẹ̀ náà gbára lé.

## Kí ló dé tí àpapọ̀ fi pọ̀ tó bẹ́ẹ̀

Bí o bá wo àtòjọ àwọn algorithm ẹ̀yà tí o sì ń ṣe kàyéfì ìdí tí specification kan yóò fi ṣàlàyé ìsopọ̀ tó bẹ́ẹ̀, RFC náà dáhùn ní kedere. Sísin ọ̀ràn lílò ìfọwọ́sí ìlànà tuntun, ju ìbéèrè àgbékalẹ̀ mìíràn lọ, ni ohun tí ó fa iye àpapọ̀ algorithm púpọ̀ nínú specification yìí. Ó fi kún un pé a ṣe àwọn àpapọ̀ náà láti bá ìtọ́sọ́nà ìlànà mu ní àwọn agbègbè kan.

Ìrònú tí ó wà lẹ́yìn ọ̀ràn lílò náà ṣọ́ra ṣùgbọ́n ó ṣe kedere. Ní àwọn ipò kan, ó lè rọrùn láti tún fọwọ́ sí ọjà kan tí ó wà nípa fífi Post-Quantum kún un nípasẹ̀ PQ/T hybrid sí ojútùú tí ó ti bá ìlànà mu láìyí ẹ̀yà àtijọ́ padà, ju rírọ́pò ẹ̀yà àtijọ́ lọ. Ní ọ̀rọ̀ mìíràn, olùtajà tí ó ní algorithm àtijọ́ tí a ti fọwọ́ sí lè fẹ́ fi í sílẹ̀ láìfọwọ́kàn, kí ó sì so ìdajì post-quantum mọ́ ẹ̀gbẹ́ rẹ̀. Ìfẹ́ yẹn ń ṣiṣẹ́ kìkì bí specification bá fúnni ní ìsopọ̀ fún algorithm àtijọ́ èyíkéyìí tí ọjà náà ti ń lò. Ìdí nìyí tí ó fi gbòòrò.

Èyí jẹ́ ìdúró àgbékalẹ̀ tí mo rí pé ó yíni lọ́kàn padà, ó sì jẹ́ àtúnṣe tí ó wúlò sí èrò pé standard gbọ́dọ̀ kéré jùlọ. Àtòjọ kúkúrú yóò mọ́ jù, ṣùgbọ́n yóò fipá mú àwọn ọjà kan láti pààrọ̀ ẹ̀yà tí a ti fọwọ́ sí, èyí tí ó jẹ́ iye owó gan-an tí àwọn àpapọ̀ náà fẹ́ yẹra fún. Àtòjọ gígùn ni iye owó pípàdé àwọn ọjà tí a ń ṣàkóso níbi tí wọ́n wà.

RFC náà tún ṣọ́ra láti dènà gbígbòòrò yẹn láti di ẹrù fún àwọn òǹkàwé. A retí pé àwọn àjọ yóò yàn láti gbé algorithm composite kan, tàbí iye díẹ̀ nínú wọn, kalẹ̀, àwọn olùmúṣẹ díẹ̀ gan-an ni yóò sì nílò láti bìkítà nípa gbogbo àtòjọ náà. Ṣàkíyèsí ìṣọ́ra náà: "a retí". Ó jẹ́ àsọtẹ́lẹ̀ nípa ìhùwàsí ìgbékalẹ̀, kì í ṣe ìbéèrè. Ṣùgbọ́n ó sọ fún ọ bí o ṣe máa ka ìwé náà. A kò retí pé kí o ṣe ìmúṣẹ ohun gbogbo; a retí pé kí o rí ìsopọ̀ tìrẹ.

## Ohun tí specification náà fi sílẹ̀

Standard tí ó dára ṣe kedere nípa ààlà rẹ̀, èyí sì ṣe bẹ́ẹ̀. Ààlà mẹ́rin yọ jáde.

Èkíní, specification náà kò ṣàlàyé algorithm mandatory-to-implement kankan. Pẹ̀lú ìrètí pé àwọn àjọ yóò yan composite kan tàbí díẹ̀, èyí túmọ̀ sí pé interoperability láàrin ẹgbẹ́ méjì gbára lé bóyá wọ́n ti yan àwọn àpapọ̀ tí ó bá ara wọn mu. RFC náà kò yan àṣàyàn àkọ́kọ́ tí gbogbo ènìyàn gbọ́dọ̀ ṣe àtìlẹ́yìn fún, ó sì kìlọ̀ pé iye àpapọ̀ lè pín ecosystem sí àwọn ẹgbẹ́ kékeré tí kò lè bá ara wọn ṣiṣẹ́ nígbà tí àwọn àwùjọ ọ̀tọ̀ọ̀tọ̀ bá yan àwọn àkójọ tí kò kọjá ara wọn. Ó gba àwọn àjọ ní àwọn agbègbè ohun èlò pàtó níyànjú láti ṣàlàyé profile tí ó yan iye composite díẹ̀. Èmi yóò tọ́ka sí èyí gẹ́gẹ́ bí àbájáde ìṣe kan ṣoṣo tí ó ṣe pàtàkì jùlọ fún ẹgbẹ́ tí ń pète ìgbékalẹ̀: ìwọ yóò nílò láti fohùnṣọ̀kan lórí ìsopọ̀ rẹ pẹ̀lú àwọn alábàáṣiṣẹ́ rẹ dípò kí o rò ó.

Èkejì, a kò pèsè backwards compatibility ní ìtumọ̀ pé àwọn ètò tí a ti mú dójú ìwọ̀n yóò máa bá àwọn ètò àtijọ́ ṣiṣẹ́ pọ̀. Ó yẹ kí a ya èyí sọ́tọ̀ sí kókó ìpele protocol tí ó wà lókè. RFC náà ṣàlàyé Application Backwards Compatibility gẹ́gẹ́ bí ànímọ́ tí ó fi hàn bóyá ohun èlò tí a ti mú dójú ìwọ̀n àti èyí tí a kò tíì mú dójú ìwọ̀n lè fi ìbánisọ̀rọ̀ múlẹ̀ ní àṣeyọrí. Section 10.3 ṣe kedere: àwọn ẹ̀rọ inú ìwé náà kò pèsè application backwards compatibility, kìkì àwọn ètò tí a ti mú dójú ìwọ̀n ni yóò lóye àwọn OID tí ó ṣàlàyé, a ó sì nílò àwọn ẹ̀rọ àfikún níbi tí a bá ti béèrè ànímọ́ yẹn. Àgbékalẹ̀ algorithm atomic ń ràn lọ́wọ́ pẹ̀lú ìyípadà protocol, ṣùgbọ́n kò sọ pé òun yanjú bóyá ohun èlò tí a ti mú dójú ìwọ̀n lè bá èyí tí a kò tíì mú dójú ìwọ̀n sọ̀rọ̀.

Ẹ̀kẹta, ààlà ànímọ́ ààbò kan wà. Composite ML-DSA wúlò níbi tí ó bá ṣe ìtẹ́wọ́gbà láti ní signature primitive pẹ̀lú ànímọ́ EUF-CMA tí ó lágbára díẹ̀ dípò ànímọ́ Strong Unforgeability under Chosen Message Attack (SUF-CMA) tí ó lágbára jù, èyí tí Composite ML-DSA kò pèsè. Bí ohun èlò rẹ bá gbára lé SUF-CMA, ètò yìí kò bá a mu bí a ṣe ṣàlàyé rẹ̀. Ìyẹn jẹ́ ààlà tí ó mọ́ tí a lè ṣàyẹ̀wò, olùdásílẹ̀ tí ń ṣe àgbéyẹ̀wò ètò náà sì gbọ́dọ̀ dán àwọn ìbéèrè tirẹ̀ wò lòdì sí i ṣáájú kí ó tó lọ síwájú.

Ẹ̀kẹrin, àti ní ìwọ̀ntúnwọ̀nsì, ìwé náà gbà pé ìfúnpá àkókò fúnra rẹ̀ ní ewu, bí a ti sọ ṣáájú: a lè gbé àwọn ìmúṣẹ PQC kalẹ̀ ṣáájú kí a tó mú wọn le tàbí fọwọ́ sí wọn pátápátá. Composite jẹ́ ìdínkù ewu yẹn, kì í ṣe ìmúkúrò rẹ̀.

## Kíka àmì-ìkọ̀wé náà

Àwọn olùmúṣẹ yóò lo àkókò pẹ̀lú àpèjúwe algorithm, nítorí náà àkíyèsí lórí àṣà wọn wúlò. Àpèjúwe algorithm lo syntax tí ó jọ Python. Àmì || dúró fún ìsopọ̀ byte array méjì, àmì [:] sì dúró fún gígé byte array.

Fún àwọn function tí ó dá iye púpọ̀ padà, ìwé náà lo (a, b) láti dúró fún iye méjì, tí ó sábà máa ń fi hàn pé function kan dá iye púpọ̀ padà, pẹ̀lú ẹ̀rọ ìgbéjáde gangan (tuple, struct, output parameter, abbl.) tí a fi sílẹ̀ fún olùmúṣẹ. Gbólóhùn ìkẹyìn yẹn jẹ́ òmìnira tí a mọ̀ọ́mọ̀ fúnni: specification náà bìkítà nípa ohun tí a dá padà, kì í ṣe bí èdè rẹ ṣe dì í. Àmì (a, _) dúró fún ìsopọ̀ níbi tí a ti kọ iye kan, èkejì nínú ọ̀ràn yìí, sílẹ̀.

Signature function tẹ̀lé àpẹẹrẹ kan náà. Àmì func(a) -> b dúró fún function tí a ń pè ní func tí ó gba a gẹ́gẹ́ bí input tí ó sì ṣe b jáde. Func<TYPE>() sì dúró fún function tí a fi <TYPE> ṣe parameter, tí ó túmọ̀ sí pé ìmúṣẹ rẹ̀ yóò ní ìyàtọ̀ kékeré gẹ́gẹ́ bí TYPE abẹ́lẹ̀. Àṣà ìkẹyìn yìí ni ó jẹ́ kí àpèjúwe kan bo àwọn algorithm abẹ́lẹ̀ púpọ̀ láìtún un kọ fún ọ̀kọ̀ọ̀kan, èyí tí ó bá specification tí ó kárí àwọn ẹ̀yà RSA, ECDSA àti EdDSA pẹ̀lú ML-DSA mu.

Kò sí èyí tí ó jẹ́ ohun ìyanu, ṣùgbọ́n òun ni apá ìwé náà tí ìwọ yóò ṣí sílẹ̀ nígbà tí o bá ń kọ code, ìpinnu láti fi ẹ̀rọ ìdápadà iye púpọ̀ sílẹ̀ fún olùmúṣẹ sì jẹ́ ìgbàwọlé tí ó bọ́gbọ́n mu sí oríṣiríṣi èdè tí a ń lò.

## Ibi tí èyí fi ẹgbẹ́ tí ń pète ìṣípò sí

Bí a bá kó àwọn ẹ̀yà wọ̀nyí sínú àgbékalẹ̀ ìpinnu, RFC náà fún ọ ní nǹkan mẹ́ta tí ó wúlò, ó sì ní kí o pèsè méjì.

Ohun tí ó fún ọ ni ìdí, ìrísí àti ààlà. Ìdí ni ìfúnpá méjì tí a ti ṣàpèjúwe: àwọn algorithm àtijọ́ yóò ṣubú sí ìkọlù quantum ní àkókò tí a kò dájú, nígbà tí a lè má tíì mú àwọn ìmúṣẹ tuntun le tàbí fọwọ́ sí wọn pátápátá. Ìrísí ni composite atomic, pẹ̀lú public key kan àti signature value kan, tí ó ń pa ààbò díẹ̀ mọ́ bí ẹ̀yà kan bá fọ́. Ààlà ni àtòjọ ààlà tí ó wà lókè: kò sí algorithm mandatory-to-implement, kò sí ìbò backwards compatibility tààrà, àti EUF-CMA dípò SUF-CMA.

Ohun tí ó ní kí o pèsè ni àṣàyàn àpapọ̀ àti àdéhùn interoperability. Nítorí specification náà kò dárúkọ algorithm mandatory-to-implement kankan, yíyan ìsopọ̀ jẹ́ ojúṣe rẹ, bí Section 10.4 tilẹ̀ fúnni ní àtòjọ kúkúrú ìmọ̀ràn fún àwọn ọ̀ràn lílò tí ó wọ́pọ̀. Bí a bá ti fọwọ́ sí ọjà rẹ pẹ̀lú algorithm àtijọ́ kan pàtó, ìrònú ìfọwọ́sí tuntun tọ́ka sí àpapọ̀ tí ó fi ẹ̀yà yẹn sílẹ̀. Bí o bá ń kọ́ nǹkan tuntun láìsí ìbéèrè ìlànà tàbí ìmúṣẹ àtijọ́ láti ronú nípa rẹ̀, RFC náà dámọ̀ràn pé kí o pọkàn pọ̀ sórí id-MLDSA65-ECDSA-P256-SHA512, èyí tí ó sọ pé ó pèsè ìwọ̀ntúnwọ̀nsì àpapọ̀ tí ó dára jùlọ láàrin iṣẹ́ àti ààbò.

Àríyànjiyàn tí ó bọ́gbọ́n mu wà pé pínpín iṣẹ́ yìí ló tọ́ fún standard ní ìpele yìí. Pípàṣẹ àpapọ̀ kan ì bá ti sin àwọn ìgbékalẹ̀ kan, ì bá sì ti fi àwọn mìíràn sílẹ̀ láìní ọ̀nà, pàápàá àwọn tí ìtọ́sọ́nà ìlànà agbègbè dè. Kíkọ̀ láti pàṣẹ ń jẹ́ kí specification náà wúlò ní àwọn agbègbè wọ̀nyẹn, ní iye owó títì ìgbésẹ̀ ìṣọ̀kan sí àwọn olùgbàwọlé. RFC náà yan ìrọ̀rùn, ó sì sọ fún ọ bẹ́ẹ̀.

Èmi yóò tún takò ìtumọ̀ àṣìṣe kan tí ó ń dánni wò pẹ̀lú ìwọ̀ntúnwọ̀nsì. Gbólóhùn pé àwọn olùmúṣẹ díẹ̀ gan-an ni yóò nílò láti bìkítà nípa gbogbo àtòjọ náà lè dún bí ìyọ̀ǹda láti fojú fo gbígbòòrò specification náà. Kì í ṣe bẹ́ẹ̀. Ó jẹ́ gbólóhùn nípa ẹni tí ó ru iye owó gbígbòòrò yẹn: specification náà gbà á kí ọ̀pọ̀ ìgbékalẹ̀ má baà ní láti gbà á. Bí o bá jẹ́ òǹkọ̀wé library tàbí olùtajà tí ń sin àwọn oníbàárà tí a ń ṣàkóso, gbígbòòrò náà lè jẹ́ ìṣòro rẹ; bí o bá jẹ́ àjọ kan tí ń yan composite kan, kì í ṣe bẹ́ẹ̀ ní pàtàkì. RFC náà ṣọ́ra lórí ìrètí náà, èmi náà yóò sì kà á sí àsọtẹ́lẹ̀ dípò ìdánilójú.

## Àwọn ìbéèrè tí specification náà fi sílẹ̀ ní ṣíṣí

Okùn méjì nínú ìwé náà yẹ fún àbójútó nítorí specification náà fúnra rẹ̀ tọ́ka sí wọn láìyanjú wọn.

Èkíní ni gígùn ìṣípò. RFC náà sọ pé ààbò dátà algorithm méjì lè jẹ́ ohun tí a fẹ́ fún àkókò gígùn, àti pé ètò ìṣípò lè yára. Gbólóhùn méjèèjì yẹn ń fa ara wọn ní ọ̀nà tí ó dùn mọ́ni: ìṣípò yíyára sí PQC ń jiyàn fún ìgbékalẹ̀ ṣáájú kí ìmúle tó parí, nígbà tí àkókò ìdáàbòbò gígùn ń jiyàn fún pípa ìdajì àtijọ́ mọ́ fún ìgbà pípẹ́ lẹ́yìn náà. Bí àwọn àjọ ṣe máa pa ẹ̀yà méjèèjì mọ́ pẹ́ tó gan-an jẹ́ ìbéèrè tí ìwé náà gbé dìde ní àìtààrà tí kò sì dáhùn.

Èkejì ni backwards compatibility. RFC náà sọ pé àwọn ẹ̀rọ rẹ̀ kò pèsè application backwards compatibility rárá àti pé a ó nílò àwọn ẹ̀rọ àfikún níbi tí a bá ti béèrè rẹ̀. Ó tò àwọn protocol tí ìṣípò àti interoperability nílò ìrònú nínú wọn, láti TLS 1.3 àti IKEv2 dé S/MIME, eIDAS document signing àti code signing, ṣùgbọ́n ó fi àgbékalẹ̀ àwọn ẹ̀rọ àfikún wọ̀nyẹn sílẹ̀ fún àwọn protocol àti ohun èlò fúnra wọn.

Fún àwọn ẹgbẹ́ tí ń pinnu ibi tí wọn yóò kọ́kọ́ ná akitiyan sí, ìbéèrè kejì yẹn dà bí ibi tí ó dára jù láti bẹ̀rẹ̀: kì í ṣe èwo nínú àwọn àpapọ̀ ni kí a gbà, ṣùgbọ́n bí ohun èlò tí a ti mú dójú ìwọ̀n yóò ṣe hùwà nígbà tí ẹgbẹ́ ní òdìkejì kò tíì ṣí.

## Àwọn Ìbéèrè Tí A Máa Ń Béèrè

**Kí ni Composite ML-DSA?**
Composite ML-DSA jẹ́ ètò PQ/T hybrid signature tí a ṣàlàyé nínú RFC 10073. Ó so ML-DSA, tí a ṣàlàyé nínú FIPS 204, pọ̀ mọ́ algorithm àtijọ́ bí RSASSA-PSS, RSASSA-PKCS1-v1_5, ECDSA, Ed25519 tàbí Ed448. Àwọn méjèèjì fi public key kan àti signature value kan hàn, nítorí náà protocol lè kà á sí algorithm atomic kan.
**Kí ló dé tí RFC náà fi ṣàlàyé àpapọ̀ algorithm tó pọ̀ bẹ́ẹ̀?**
RFC náà sọ pé sísin ọ̀ràn lílò ìfọwọ́sí ìlànà tuntun, ju ìbéèrè àgbékalẹ̀ mìíràn lọ, ló fa iye àpapọ̀ púpọ̀ náà. Olùtajà kan lè rí i pé ó rọrùn láti tún fọwọ́ sí ọjà kan nípa fífi ẹ̀yà post-quantum kún ẹ̀gbẹ́ ẹ̀yà àtijọ́ tí ó ti bá ìlànà mu ju rírọ́pò rẹ̀ lọ. A retí pé àwọn àjọ yóò gbé algorithm composite kan tàbí iye díẹ̀ kalẹ̀.
**Algorithm composite wo ni ìgbékalẹ̀ tuntun gbọ́dọ̀ fi bẹ̀rẹ̀?**
RFC náà kò dárúkọ algorithm mandatory-to-implement kankan. Fún àwọn ohun èlò tí kò ní ìbéèrè ìlànà tàbí ìmúṣẹ àtijọ́ láti ronú nípa rẹ̀, Section 10.4 dámọ̀ràn pípọkàn pọ̀ sórí id-MLDSA65-ECDSA-P256-SHA512. Ó tún fúnni ní ìmọ̀ràn fún àwọn ohun èlò tí ó béèrè RSA, tí iṣẹ́ àti bandwidth ṣe pàtàkì fún, tàbí tí ó gba NIST PQC Level 5 nìkan.
**Ṣé Composite ML-DSA ń jẹ́ kí àwọn ètò tí a ti mú dójú ìwọ̀n máa bá àwọn àtijọ́ ṣiṣẹ́?**
Rárá. RFC náà sọ pé àwọn ẹ̀rọ rẹ̀ kò pèsè application backwards compatibility rárá àti pé kìkì àwọn ètò tí a ti mú dójú ìwọ̀n ni yóò lóye àwọn OID tí ó ṣàlàyé. Níbi tí a bá ti béèrè ànímọ́ yẹn, a ó nílò àwọn ẹ̀rọ àfikún.
**Ànímọ́ ààbò wo ni Composite ML-DSA kò pèsè?**
Kò pèsè Strong Unforgeability under Chosen Message Attack (SUF-CMA), kìkì ànímọ́ EUF-CMA tí ó lágbára díẹ̀. RFC náà sọ pé àwọn ohun èlò tí ààbò SUF-CMA ṣe pàtàkì fún kò gbọ́dọ̀ lò ó, àti pé ó jẹ́ NOT RECOMMENDED níbi tí a kò tíì fi hàn pé EUF-CMA ṣe ìtẹ́wọ́gbà.
