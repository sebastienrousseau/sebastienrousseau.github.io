## Ìdí tí èsì yìí fi ṣe pàtàkì fún àwọn tí ń gbé cryptographic software jáde

A ṣàpèjúwe Signal gẹ́gẹ́ bí ìlànà àgbáyé tí gbogbo ènìyàn ń tẹ̀lé fún ìfiránṣẹ́ end-to-end encrypted, a sì ti gbé oríṣiríṣi ẹ̀yà protocol náà kalẹ̀ nínú WhatsApp, app Messenger ti Meta, àti Google Messages. Nígbà tí protocol kan bá wà lábẹ́ ọ̀pọ̀ ìjíròrò bẹ́ẹ̀, àlàfo tó wà láàárín àpẹẹrẹ tí a fi hàn pé ó ní ààbò lórí ìwé àti compiled code tí ń ṣiṣẹ́ ní tòótọ́ kò jẹ́ ọ̀rọ̀ ẹ̀kọ́ lásán mọ́. Proof lórí ìwé lè jẹ́ aláìlábàwọ́n nígbà tí implementation ń ṣe nǹkan mìíràn pátápátá.

Àlàfo yẹn ni iṣẹ́ yìí dojú kọ. Àwọn òǹkọ̀wé fúnni ní àwọn proof àkọ́kọ́ ti àwọn ànímọ́ ààbò ní ìpele protocol fún implementation cryptographic protocol kan tí a gbé kalẹ̀ káàkiri tí a kò sì yí padà. Ka gbólóhùn yẹn lẹ́ẹ̀mejì, nítorí pé gbogbo àfikún àpèjúwe ń ṣiṣẹ́. Ìpele protocol túmọ̀ sí pé àwọn proof náà kan àwọn ànímọ́ bíi forward secrecy, kì í ṣe àìsí àṣìṣe memory nìkan. Tí a gbé kalẹ̀ káàkiri túmọ̀ sí libsignal, kì í ṣe àpẹẹrẹ ìwádìí. Tí a kò yí padà túmọ̀ sí pé kò sí ẹni tí ó tún code náà kọ sí ìrísí tí ó rọrùn fún prover.

Fún àwọn olùdásílẹ̀, ìtumọ̀ ìṣe ni iye owó. Àwọn òǹkọ̀wé gbé formal verification kalẹ̀ gẹ́gẹ́ bí ọ̀nà mìíràn yàtọ̀ sí wíwá bug lẹ́yìn tí ó bá ti ṣẹlẹ̀: ènìyàn ń sọ àwọn ànímọ́ ìpéye àti ààbò tí software system kan gbọ́dọ̀ mú ṣẹ, lẹ́yìn náà ó ń fi ìṣirò hàn pé system náà mú wọn ṣẹ. Wọ́n ṣàpèjúwe rẹ̀ gẹ́gẹ́ bí ohun tí ó ti gbówó jù fún ọ̀pọ̀ software tẹ́lẹ̀. Èsì àwọn òǹkọ̀wé fi hàn pé AI lè mú kí ó ṣeé ṣe fún àwọn system gidi. Síbẹ̀, case study tí ó tóbi tó báyìí jẹ́ ẹ̀rí tí ó wúwo ju èyí tí ọ̀pọ̀ ẹ̀sùn nínú pápá yìí máa ń ní.

## Ìṣòro verification le ju bí ó ṣe hàn lọ

Àwọn ohun èlò orísun framework náà tọ́ka sí àmì ìwọ̀n kan tí a mọ̀ dáadáa fún bí verification ṣe lè le tó: CompCert, C compiler tí a ti ṣàyẹ̀wò, tí ó gba ọdún mẹ́fà iṣẹ́ ènìyàn kan láti ṣàyẹ̀wò, gẹ́gẹ́ bí iye tí a ròyìn níbí. Ẹ ṣọ́ra pẹ̀lú iye yẹn, nítorí pé àlàyé inú àkámọ́ nípa ọdún iṣẹ́ ènìyàn jẹ́ ìkọ́lé orísun náà, kì í ṣe ọ̀rọ̀ tí a fà yọ tààrà. Kókó náà ṣì dúró: ṣíṣàyẹ̀wò software tí ó lágbára ti jẹ́ ìfaramọ́ ọlọ́dún-púpọ̀.

A sọ pé ṣíṣàyẹ̀wò code agbára-ilé-iṣẹ́ tí ó ti wà tẹ́lẹ̀ tún le jù bẹ́ẹ̀ lọ, nítorí pé prover kò lè yí code náà padà láti mú proof rọrùn. Library production tí optimising compiler kó jọ ni àpẹẹrẹ gan-an fún èyí. Bí o bá ní òmìnira láti tún ètò program náà ṣe, o lè ṣe é kí proof jáde wá ní ìrọ̀rùn. Bí o bá gbọ́dọ̀ gba code náà bí ó ṣe wà, o jogún gbogbo ọ̀nà ìkọ̀wé tí ó nira àti gbogbo ìpinnu compiler.

AlphaProof Code mọ̀ọ́mọ̀ yan ọ̀nà tí ó le jù. A kó Rust code tí a kò yí padà jọ pẹ̀lú compiler àṣà, a sì gbé executable náà sínú Lean pẹ̀lú semantics ti AArch64. Ní pàtó, àwọn òǹkọ̀wé so libsignal pọ̀ mọ́ command-line harness kékeré kan wọ́n sì kó o jọ pẹ̀lú rustc compiler àṣà sí AArch64 Linux machine code. Machine code ni ohun tí a ń fi ẹ̀rí hàn nípa rẹ̀. Àfojúsùn yẹn lágbára ju èrò ní ìpele source lọ, nítorí pé o kò ní láti gbẹ́kẹ̀lé compiler mọ́ pé yóò pa àwọn ànímọ́ tí o ti fi hàn mọ́.

Ìpinnu àpẹẹrẹ tí ó ṣe pàtàkì jù nínú framework náà ni ohun tí ó kọ̀ láti gbẹ́kẹ̀lé. A kò gbẹ́kẹ̀lé àwọn proof ọlọ́pọ̀-mílíọ̀nù-ìlà tí AI agents ṣe, nítorí pé kernel ti Lean ń kọ àṣìṣe ọgbọ́n kankan nínú proof. Ní ọ̀nà mìíràn, nítorí pé kernel ti Lean ló ń ṣàyẹ̀wò proof náà ní ìparí, ìgbẹ́kẹ̀lé àwọn èsì kò dúró lórí ìgbẹ́kẹ̀lé àwọn proving agents.

Èyí ṣe pàtàkì nítorí pé, gẹ́gẹ́ bí àwọn òǹkọ̀wé ṣe sọ ọ́, ìgbẹ́kẹ̀lé àwọn èsì kò dúró lórí ìgbẹ́kẹ̀lé àwọn proving agents: kernel ti Lean ló ń ṣàyẹ̀wò proof náà ní ìparí. Gẹ́gẹ́ bí ìwé náà ṣe sọ, gatekeeper agent ń gba proof kan kìkì bí kernel ti Lean bá ṣàyẹ̀wò rẹ̀ tí Lean comparator sì fìdí rẹ̀ múlẹ̀ pé ó ń fi ẹ̀dà specification tí a pa mọ́ sí ẹ̀gbẹ́ hàn gẹ́lẹ́. Àwọn àdéhùn méjì nìyẹn. Proof náà gbọ́dọ̀ wúlò, ó sì gbọ́dọ̀ jẹ́ proof gbólóhùn tí ó tọ́. A ṣe àdéhùn kejì láti dáàbò bo lọ́wọ́ ìkùnà àrékérekè kan: agent kan tí ó yí gbólóhùn náà padà tí ó sì fi ohun tí ó rọrùn ju èyí tí a béèrè hàn. Comparator ń ṣàyẹ̀wò pé gbólóhùn náà àti gbogbo definition tí ó gbára lé jọra pátápátá pẹ̀lú ẹ̀dà tí a pa mọ́, àti pé proof náà ń lo standard axioms ti Lean nìkan.

Nítorí náà trusted base kéré ní ìfiwéra pẹ̀lú proof náà fúnra rẹ̀. Nǹkan bí ìlà 27,000 ti specifications tí a gbẹ́kẹ̀lé àti AArch64 semantics ló ń gbé nǹkan bí ìlà mílíọ̀nù 6.3 ti proof ró. Àkíyèsí olùṣàyẹ̀wò ní òpin, ìpín yìí sì sọ ibi tí o yẹ kí o lò ó sí fún ọ.

Ṣùgbọ́n specification ni ibi àìlera, àwọn òǹkọ̀wé sì sọ bẹ́ẹ̀ ní gbangba. Specification nínú AlphaProof Code ní àkójọ Lean theorem statements pẹ̀lú gbogbo definition tí wọ́n gbára lé. A gbọ́dọ̀ gbẹ́kẹ̀lé e, a kò sì lè ṣàyẹ̀wò rẹ̀ láìfọwọ́ ènìyàn, àbùkù kan sì lè dín ìdánilójú tí theorem náà ń fúnni kù. Theorem tí ó ń ṣe assumptions tí ó há jù lórí àwọn input, tí ó ń sọ àwọn ànímọ́ aláìlágbára ti output nìkan, tàbí tí ó ń fi ìdíwọ̀n díẹ̀ jù sórí existentially quantified witnesses lè dúró kódà fún code tí ó ní bug. Bí àṣìṣe nínú specification bá dín agbára attacker kù, ìdánilójú ààbò náà yóò dín kù pẹ̀lú.

Àwọn definition tún lè ní extern contracts tí ó ń ṣàlàyé àwọn assumptions nípa àwọn apá system tí ó wà lóde ààlà verification campaign náà. Ààlà olóòótọ́ ni wọ́n, ṣùgbọ́n ààlà ni wọ́n: ohunkóhun tí ó wà lẹ́yìn extern contract ni a gbà pé ó rí bẹ́ẹ̀, a kò fi ẹ̀rí rẹ̀ hàn.

Nítorí náà, iye àkọlé, ìlà mílíọ̀nù 6.3, ni iye tí ó kéré jù ní pàtàkì nígbà tí o bá ń pinnu bóyá kí o gbẹ́kẹ̀lé èsì náà. Ìlà 27,000 ni èyí tí ó yẹ kí a kà.

## Ohun tí a fi ẹ̀rí rẹ̀ hàn nípa Signal

Àwọn proof náà bo PQXDH handshake post-quantum àti Triple Ratchet ti Signal, wọ́n sì fìdí forward secrecy, authentication, post-compromise security àti handshake secrecy múlẹ̀. A ṣe PQXDH handshake àti Triple Ratchet láti rí i dájú pé àwọn ìfiránṣẹ́ wà ní ààbò kódà nígbà tí àwọn kan nínú àwọn key bá ti bàjẹ́, àti kódà lòdì sí àwọn ọ̀tá ọjọ́ iwájú tí ó ní ààyè sí quantum computer.

Àṣà modelling àtijọ́ méjì ló ń ṣàlàyé ohun tí "ààbò" túmọ̀ sí níbí. Symbolic model, tí a tún mọ̀ sí Dolev–Yao model, ń ka àwọn cryptographic primitives sí "black boxes" àìnírí tí ó ń ṣe àwọn ànímọ́ ààbò àṣà. Computational model ń fi ìṣòro àwọn primitives ìsàlẹ̀ dín àǹfààní àṣeyọrí attacker tí ó yára kù. Computational security proof sọ pé reduction kan wà láti ìkọlù lórí protocol sí rírú assumption ìsàlẹ̀ kan.

Àwọn model méjèèjì ń fúnni ní ìdánilójú tí ó yàtọ̀, a sì pín àwọn èsì ní ìbámu pẹ̀lú èyí. Àwọn proof tí agents kọ fìdí forward secrecy, post-compromise security, àti àṣírí àti òtítọ́ ìfiránṣẹ́ múlẹ̀ tààrà fún compiled binary lòdì sí àwọn classical attacker. Nínú symbolic model, wọ́n fìdí handshake secrecy múlẹ̀ lòdì sí quantum attacker ọjọ́ iwájú. Òǹkàwé tí ó ṣọ́ra gbọ́dọ̀ di ìyàtọ̀ yẹn mú. Èsì lòdì sí quantum adversary ni a sọ nínú symbolic model, àwọn èsì lòdì sí classical attacker sì ni a sọ tààrà fún compiled binary.

Ìṣòro kejì wà tí ó ṣàlàyé ìdí tí iṣẹ́ specification fi le. Àwọn specification tí ó wà tẹ́lẹ̀ ń ṣàyẹ̀wò handshake àti ratchet lọ́tọ̀ọ̀tọ̀, wọ́n sì ṣáájú post-quantum ratchet ti Signal; àwọn formal model ti Signal tẹ́lẹ̀ ṣàyẹ̀wò handshake àkọ́kọ́ rẹ̀ àti ratchet rẹ̀ lọ́tọ̀ọ̀tọ̀. Proof nípa protocol bí a ṣe gbé e kalẹ̀ nílò méjèèjì papọ̀, pẹ̀lú post-quantum ratchet. Pẹ̀lú ìtọ́sọ́nà ènìyàn, àwọn agents fẹ àwọn specification tí ó wà tẹ́lẹ̀ lójú dé protocol bí a ṣe gbé e kalẹ̀. Àpẹẹrẹ tí ó dára ni èyí ti collaboration model ní ìṣe: ìwé ìwádìí ń fúnni ní ibi ìbẹ̀rẹ̀, ènìyàn ń darí, àwọn agents sì ń ṣe ìfẹ̀lójú náà.

Àwọn òǹkọ̀wé tún sọ pé iṣẹ́ wọn fi hàn pé AI lè ṣàyẹ̀wò machine code lòdì sí àwọn specification ọlọ́rọ̀ láti inú ìwé ìwádìí, títí kan àwọn ànímọ́ ìbáṣepọ̀ láàárín stateful program àti adaptive adversary. Irú ànímọ́ tí ó yẹ fún àkíyèsí ni èyí. Stateful program tí ó dojú kọ adaptive adversary ni ipò gan-an tí messaging client wà.

Àwọn òǹkọ̀wé sọ pé àwọn ni àkọ́kọ́: ní ọ̀rọ̀ wọn, ìwọ̀nyí ni àwọn proof àkọ́kọ́ tí ó so àwọn ìdánilójú ààbò ní ìpele protocol pọ̀ mọ́ code tí a kò yí padà ti implementation cryptographic protocol kan tí ọ̀pọ̀ ń lò. Ẹ̀sùn tiwọn ni, kì í ṣe àbájáde òmìnira, bẹ́ẹ̀ ni mo sì ṣe ròyìn rẹ̀. Wọ́n ṣàpèjúwe àwọn èsì náà gẹ́gẹ́ bí ìgbésẹ̀ pàtàkì sí ìpèníjà ńlá kan tí a ṣí sílẹ̀ ní oṣù Kẹrin ọdún 2026.

## Ṣé àwọn specification ń mú àṣìṣe gidi?

Specification tí kò lè ya code tí ó tọ́ sọ́tọ̀ kúrò lára code tí ó bàjẹ́ kò wúlò, proof lòdì sí i sì kò níye lórí jù bẹ́ẹ̀ lọ. Àwọn òǹkọ̀wé dán èyí wò tààrà. Wọ́n tún fi bug méjì ti libsignal tí a ti tún ṣe tẹ́lẹ̀ sínú, wọ́n sì kọ́ àkójọ 17 synthetic mutants láti ṣàyẹ̀wò pé àwọn specification ń mú àṣìṣe gidi.

Àbájáde náà, gẹ́gẹ́ bí àwọn òǹkọ̀wé ṣe ròyìn rẹ̀: fún bug ìtàn méjèèjì àti, títí di báyìí, 16 nínú 17 synthetic mutants, Lean fi hàn pé trace tí a gbà sílẹ̀ (witness trace kan fún ọ̀kọ̀ọ̀kan) kò ṣeé ṣàlàyé nípasẹ̀ symbolic specification lábẹ́ ìtumọ̀ primitives kan pàtó tí ó bá run tí a gbà sílẹ̀ mu. Kernel ṣàyẹ̀wò àwọn binary refutation kíkún ti bug ìtàn méjèèjì kìkì lòdì sí untrusted placed variant (36-hook) ti gbólóhùn náà tí ó ṣáájú; gbígbé wọn lọ sí trusted statement ti theorem àkọ́kọ́ ṣì wà ní ṣíṣí.

Mo fẹ́ ṣe pàtó nípa ohun tí èyí sọ àti èyí tí kò sọ. Mẹ́rìndínlógún nínú mẹ́tàdínlógún kì í ṣe mẹ́tàdínlógún nínú mẹ́tàdínlógún, case study náà kò sì ṣàlàyé nǹkankan nípa mutant tí ó kù, nítorí náà n kò ní ṣe àmọ̀ràn nípa rẹ̀. Ẹ tún kíyèsí ìkìlọ̀ lórí àwọn bug ìtàn: a ṣàyẹ̀wò àwọn binary refutation kíkún lòdì sí untrusted placed variant ti gbólóhùn náà tí ó ṣáájú, tí ó ní 36 hooks, kì í ṣe dandan èyí ìkẹyìn. Kókó kékeré tí ó yẹ láti mọ̀ ni èyí kí ẹnikẹ́ni tó tọ́ka sí èsì náà gẹ́gẹ́ bí àṣeyọrí pípé.

Síbẹ̀, irú ìdánwò tí ó tọ́ ni èyí. Ó kọlu specification, ibi tí framework náà sọ pé ewu tí ó kù wà, dípò fífi ìwọ̀n proof yangàn. Mutation testing ti specification kò gbówó ní ìfiwéra pẹ̀lú verification campaign, ó sì ń dáhùn ìbéèrè tí kò sí iye proof tí kernel ṣàyẹ̀wò tí ó lè dáhùn: ṣé gbólóhùn yìí ì bá ti ṣàkíyèsí bug gidi kan?

## Ohun tí èyí túmọ̀ sí ní ìṣe

Àwọn ààlà yẹ fún àkíyèsí bí ìgbésẹ̀ pàtàkì náà ṣe yẹ. Fún àwọn system ńlá tí ó díjú, ìrànlọ́wọ́ AI lè dín iye owó kíkọ specification àti assurance kù ṣùgbọ́n kò lè rọ́pò ìdájọ́ àti àtúnyẹ̀wò ènìyàn pátápátá. Àwọn òǹkọ̀wé kò sọ ohun mìíràn. Ọrọ̀ ajé ń yí padà, ṣùgbọ́n kò wó lulẹ̀ sí òdo, apá tí ó kù fún ènìyàn sì ni apá tí ó ń pinnu bóyá ìdánilójú náà ní ìtumọ̀.

Mo rò pé pípín yẹn tọ́, ó sì dábàá ọ̀nà tí ó bọ́gbọ́n mu fún ẹgbẹ́ kan láti ka iṣẹ́ yìí. Má ṣe béèrè bóyá àwọn agents lè kọ proof; èsì libsignal, ní nǹkan bí ìlà mílíọ̀nù 6.3, ti dáhùn ìyẹn. Béèrè ta ni nínú ẹgbẹ́ rẹ tí ó lè kọ àti ṣàyẹ̀wò specification irú èyí tí a ṣàpèjúwe níbí: Lean theorem statements pẹ̀lú gbogbo definition tí wọ́n gbára lé, pẹ̀lú extern contracts tí ó ń sàmì sí ohun tí a gbà pé ó rí bẹ́ẹ̀. Ẹni yẹn, àti ìgbésẹ̀ àtúnyẹ̀wò tí ó yí iṣẹ́ rẹ̀ ká, ni ohun àmúṣọrọ̀ tí ó ṣọ̀wọ́n.

Ẹ̀kọ́ àpẹẹrẹ tún wà nínú bí system náà ṣe ń bá àwọn apá tí a kò lè gbẹ́kẹ̀lé lò. Kò gbìyànjú láti mú kí àwọn agents ṣeé gbẹ́kẹ̀lé. Ó mú kí ìgbẹ́kẹ̀lé wọn má ṣe pàtàkì sí àbájáde nípa gbígbé ohun gbogbo kọjá nínú checker kékeré kan tí kò yí padà. Àwọn ẹgbẹ́ tí ń kọ́ agentic systems ní àwọn pápá mìíràn lè béèrè ìbéèrè kan náà nípa pipelines tiwọn: kí ni ohun tí ó dọ́gba pẹ̀lú kernel ti Lean, ṣé gatekeeper sì ń ṣàyẹ̀wò gbólóhùn tí ó tọ́?

Fún àwọn òǹkàwé tí kò sí nínú cryptography, kókó tí a lè lò níbòmíràn ni ìrísí workflow náà, kì í ṣe protocol pàtó náà. Nínú àpẹẹrẹ àwọn òǹkọ̀wé, ènìyàn àti agents jọ ń kọ specification, reviewer agents ń ṣàyẹ̀wò bóyá ó jẹ́ olóòótọ́, ènìyàn ń fọwọ́ sí i, commit kan ń dì í mú gẹ́gẹ́ bí baseline, autonomous agents ń fi ẹ̀rí rẹ̀ hàn, gatekeeper kan sì ń ṣàyẹ̀wò pé proof kọ̀ọ̀kan wúlò àti pé ó ń fi gbólóhùn tí a fọwọ́ sí hàn gẹ́lẹ́. Ìpele kọ̀ọ̀kan ń dojú kọ irú ìkùnà tí ó yàtọ̀.

Kò yẹ kí a gbé èyíkéyìí nínú èyí ga jù. Àbá pé AI ń mú kí verification ṣeé ṣe fún àwọn system gidi ní ìkìlọ̀ nínú orísun náà, àpẹẹrẹ àsíá kan ṣoṣo, bó ti wù kí ó wúni lórí tó, jẹ́ àpẹẹrẹ kan ṣoṣo. Specification ṣì jẹ́ ohun tí a gbẹ́kẹ̀lé tí kò sí irinṣẹ́ kankan tí ó ń ṣàyẹ̀wò rẹ̀ fún ọ. Ìdánilójú lòdì sí quantum adversary sì jẹ́ èsì symbolic model fún handshake secrecy, kì í ṣe ti computational.

Ìbéèrè tí ó ṣí sílẹ̀ tí case study náà gbé dìde ni èyí tí àwọn òǹkọ̀wé fúnra wọn tọ́ka sí nígbà tí wọ́n pè é ní ìgbésẹ̀ pàtàkì sí ìpèníjà ńlá kan tí a ṣí sílẹ̀ ní oṣù Kẹrin ọdún 2026: bí kíkọ proof bá ti di olowó-pọ́ọ́kú báyìí ní kété tí specification bá wà, ṣé specification engineering ni yóò di ìdènà tí ó kàn láti kọlu? Àwọn èsì mutation fi hàn pé a lè dán specification wò, àbájáde "ọ̀pọ̀ ìyípo iteration" sì fi hàn pé ó ṣì lọ́ra. Èló nínú ìlọ́ra yẹn ni àwọn agents lè gbà, nígbà tí ènìyàn ń di àwọn ìpinnu ìkẹyìn mú? Iye yẹn ni ó yẹ láti máa wò nínú case study tí ó kàn.

## Àwọn Ìbéèrè Tí A Máa Ń Béèrè

**Kí ni AlphaProof Code?**
Framework láti ọ̀dọ̀ Google DeepMind àti Google fún ìfọwọ́sowọ́pọ̀ ènìyàn àti AI lórí formal specification àti verification ti software gidi. Olùlò ènìyàn kan àti àwọn AI agents jọ ń kọ Lean specifications; nígbà tí olùlò bá ti ṣàyẹ̀wò specification kan, ẹgbẹ́ autonomous agents kan ń fi hàn pé code náà mú un ṣẹ.

**Kí gan-an ni a ṣàyẹ̀wò nínú libsignal?**
Rust code ti libsignal tí a kò yí padà, tí a kó jọ pẹ̀lú rustc compiler àṣà sí AArch64 Linux machine code. Àwọn proof náà bo forward secrecy, authentication, post-compromise security àti handshake secrecy fún PQXDH handshake post-quantum àti Triple Ratchet ti Signal.

**Kí ló dé tí a kò fi nílò láti gbẹ́kẹ̀lé àwọn AI agents?**
Kernel ti Lean ń ṣàyẹ̀wò gbogbo proof, gatekeeper sì ń gba proof kan kìkì bí Lean comparator bá fìdí rẹ̀ múlẹ̀ pé ó ń fi ẹ̀dà specification tí a fọwọ́ sí tí a pa mọ́ sí ẹ̀gbẹ́ hàn gẹ́lẹ́. A ń kọ àṣìṣe ọgbọ́n, a sì ń kọ proof gbólóhùn tí ó rọrùn jù pẹ̀lú.

**Kí ló ṣì gbọ́dọ̀ jẹ́ ohun tí a gbẹ́kẹ̀lé?**
Nǹkan bí ìlà 27,000 ti specifications àti AArch64 semantics, pẹ̀lú extern contracts èyíkéyìí tí ó ń ṣàpèjúwe àwọn apá system tí ó wà lóde campaign náà. A kò lè ṣàyẹ̀wò specification láìfọwọ́ ènìyàn, àbùkù kan nínú rẹ̀ sì ń dín ìdánilójú tí theorem náà ń fúnni kù.

**Ṣé iṣẹ́ náà fi ààbò lòdì sí quantum attackers hàn?**
Ní apá kan. A fìdí handshake secrecy múlẹ̀ lòdì sí quantum attacker ọjọ́ iwájú nínú symbolic model. A fìdí forward secrecy, post-compromise security, àti àṣírí àti òtítọ́ ìfiránṣẹ́ múlẹ̀ tààrà fún compiled binary lòdì sí àwọn classical attacker.
