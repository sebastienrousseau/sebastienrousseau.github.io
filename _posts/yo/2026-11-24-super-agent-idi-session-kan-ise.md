## Model ti dára sí i; ọ̀nà iṣẹ́ kò dára sí i

Àpilẹ̀kọ yìí ka "Exploring Super-agent Design: Towards a More Autonomous Agent System", ìfiránṣẹ́ kan tí DeepSeek Harness (@DeepSeekHarness) tẹ̀ jáde lórí X ní 1 November 2026, tí Yujia Qiao kọ fún ẹgbẹ́ DeepSeek Harness, tí a sì gbé kalẹ̀ gẹ́gẹ́ bí ìtumọ̀ ẹ̀rọ láti inú ìwé Chinese àkọ́kọ́.

Coding agent àti àwọn agent iṣẹ́ kan mìíràn ti fi ohun kan hàn tí ó yẹ kí a sọ ní kedere. Model lè lo ohun èlò láti yanjú ìṣòro dídíjú, wọ́n sì nílò àbójútó títẹ̀síwájú àti ìdásí ìgbésẹ̀-sí-ìgbésẹ̀ láti ọ̀dọ̀ ènìyàn díẹ̀díẹ̀ sí i. Model tún ti dára sí i ní ìṣọ̀kan agent púpọ̀, èyí tí ó mú kí ó ṣeé ṣe láti ṣètò àti láti ṣe àkókò iṣẹ́ kárí àwọn session.

Kókó kejì yẹn ṣe pàtàkì ju bí ó ti kọ́kọ́ hàn lọ. Bí ìṣọ̀kan bá ṣeé ṣe, ìbéèrè tí ó dùn mọ́ni kì í ṣe bóyá agent lè parí iṣẹ́ líle kan mọ́. Ó jẹ́ ohun tí ó ṣẹlẹ̀ nígbà tí o bá fún un ní márùn-ún.

Àwọn agent ti ara ẹni tọ́ka sí ìdáhùn náà. Wọ́n so mọ́ ìfiránṣẹ́ ojoojúmọ́, kàlẹ́ńdà, email àti àwọn pẹpẹ iṣẹ́ tààrà, wọ́n ń wo àwọn feed, wọ́n sì ń ràn lọ́wọ́ pẹ̀lú iṣẹ́. Ìfiránṣẹ́ náà sọ pé ọ̀nà iṣẹ́ tí ó wà lórí ayélujára nígbà gbogbo tí ìṣẹ̀lẹ̀ ń darí yìí kò yàtọ̀ sí lílò ti ara ẹni nìkan, ó sì tún wúlò nínú iṣẹ́ ìṣòwò bí software development. Ó sọ èyí dípò kí ó wọ̀n ọ́n, ó sì yẹ kí a kà á bẹ́ẹ̀. Ṣùgbọ́n ìdarí náà ṣe kedere tó: agent tí ó jókòó sí àwọn ibi tí iṣẹ́ ti ń ṣẹlẹ̀ tẹ́lẹ̀, dípò kí ó dúró de prompt nínú terminal.

## Ibi tí àgbékalẹ̀ session kan ti ń fọ́

Àwọn agent ṣì ń lo session kan gẹ́gẹ́ bí ẹyọ iṣẹ́ ìpìlẹ̀, àwọn session sì dá wà láàrin ara wọn. Ìyẹn jẹ́ abstraction tí ó mọ́ fún iṣẹ́ kan. Ó di ìnira ní kété tí iṣẹ́ bá pọ̀.

Olùlò tí ń ṣe iṣẹ́ púpọ̀ ní ìbámu ní láti máa yí láàrin session pẹ̀lú ọwọ́, kí ó sì rántí ohun tí ọ̀kọ̀ọ̀kan ní nínú. Nínú ìrírí àwọn òǹkọ̀wé, ènìyàn kan sábà máa ń lè tẹ̀lé session tí ń ṣiṣẹ́ 3 sí 5 péré lẹ́ẹ̀kan náà. Nọ́mbà yẹn wá láti ìrírí dípò ìwádìí tí a ṣàkóso, nítorí náà kà á sí òfin àfojúrí. Síbẹ̀, ó tọ́ka sí ìṣòro ìgbékalẹ̀ náà. Pẹ̀lú àwọn àgbékalẹ̀ wọ̀nyí, agbára model ló ń ká iṣẹ́ kan lọ́wọ́ kò, ṣùgbọ́n àfiyèsí ènìyàn ló ń ká ṣíṣe iṣẹ́ púpọ̀ lọ́wọ́ kò.

Ka gbólóhùn yẹn lẹ́ẹ̀mejì. Ó sọ pé mímú model dára sí i kò ní, fúnra rẹ̀, gbé òrùlé iṣẹ́ ìbámu sókè. Òrùlé náà ni ènìyàn tí ó gbé àwọn session sí orí rẹ̀. Mo gbà pé èyí ni àgbékalẹ̀ tí ó wúlò jùlọ nínú gbogbo àríyànjiyàn náà, nítorí ó gbé ìṣòro náà láti model, níbi tí ọ̀pọ̀ akitiyan ń lọ, sí ètò tí ó yí i ká.

## Ìdí tí connector kò fi yanjú rẹ̀

Àtúnṣe tí ó hàn gbangba ni láti fa ohun tí ó wà gùn. Fi CLI, MCP tàbí connector òde kún agent session kan ti agbègbè, yóò sì lè gba ìfiránṣẹ́ òde. Kókó àwọn òǹkọ̀wé ni pé ààlà ìpìlẹ̀ rẹ̀ ṣì wà.

Wọ́n tò àwọn ààlà wọ̀nyẹn ní kedere. Irú ìṣètò bẹ́ẹ̀ ṣì ń ṣiṣẹ́ nínú session synchronous kan tí ó ń dènà lórí iṣẹ́ gígùn. Context láti àwọn iṣẹ́ ọ̀tọ̀ọ̀tọ̀ ń dàpọ̀. Ohun gbogbo ń dúró nígbàkígbà tí ẹ̀rọ agbègbè bá lọ offline. Pípa gbogbo ìṣètò náà mọ́ ní ṣíṣiṣẹ́ sì gba akitiyan ọwọ́ púpọ̀.

Ọ̀kọ̀ọ̀kan nínú wọn jẹ́ irú ìkùnà ọ̀tọ̀. Ìdènà jẹ́ ìṣòro throughput. Context tí ó dàpọ̀ jẹ́ ìṣòro ìpéye. Lílọ offline pẹ̀lú laptop jẹ́ ìṣòro availability. Ìtọ́jú ọwọ́ jẹ́ ìṣòro iṣẹ́. Connector kò yanjú ọ̀kankan nínú wọn, nítorí connector kan yí bí ìfiránṣẹ́ ṣe ń dé padà nìkan. Kò yí ohun tí session jẹ́ padà.

## Yíya agent kúrò lára session

Ìfiránṣẹ́ náà sọ pé kíkọjá àwọn ààlà wọ̀nyí túmọ̀ sí yíya agent kúrò lára session kan èyíkéyìí tí a ń darí pẹ̀lú ọwọ́. Ohun tí ó tẹ̀lé e ni a sọ gẹ́gẹ́ bí ohun tí agent gbọ́dọ̀ jẹ́ dípò àbájáde tí a wọ̀n, nítorí náà ó dára jù láti kà á sí àbá àgbékalẹ̀ àwọn òǹkọ̀wé.

Àbá náà lọ báyìí. Agent gbọ́dọ̀ jẹ́ ẹ̀dá kan tí ń bá a lọ láìdúró tí ó ń pa context rẹ̀ mọ́ kárí àwọn session, tí ó sì ń ṣiṣẹ́ lórí ọ̀pọ̀ iṣẹ́ dídíjú lẹ́ẹ̀kan náà, láìsí pé àwọn iṣẹ́ náà ń dí ara wọn lọ́wọ́. Àwọn òǹkọ̀wé pe irú agent yìí, àti architecture ètò rẹ̀, ní Super-agent.

Wọ́n ròyìn àpẹẹrẹ kan tí ń ṣiṣẹ́. Ẹ̀dà Super-agent inú ilé wọn, tí ó ń ṣiṣẹ́ lórí DeepSeek Harness, lè tẹ̀síwájú iṣẹ́ development kan náà kárí IM àti GitHub. Ó tún ń wo esì nínú àwọn group chat gbangba, kódà nígbà tí ẹnikẹ́ni kò @-mention rẹ̀, ó ń rí ohun tí ó fa ìṣòro fúnra rẹ̀, ó sì ń ṣí Pull Request láti tún wọn ṣe. Ìfiránṣẹ́ náà kò fúnni ní ìwọ̀n àṣeyọrí tàbí iye Pull Request fún ìhùwàsí méjèèjì wọ̀nyí, nítorí náà wọ́n jẹ́ ìfihàn agbára dípò benchmark. Síbẹ̀, ìhùwàsí kejì yani lẹ́nu. Kò sí ẹni tí ó béèrè, agent náà sì ṣe nǹkan.

## Ànímọ́ mẹ́rin

Ìfiránṣẹ́ náà sọ pé Super-agent ní ànímọ́ ìpìlẹ̀ mẹ́rin: ìtẹ̀síwájú, ìmésojáde, ìṣáájú àti ìwàpẹ́. Àwọn òǹkọ̀wé gbé èyí kalẹ̀ gẹ́gẹ́ bí ìgbàgbọ́ wọn, ọ̀rọ̀ kọ̀ọ̀kan sì ní ìtumọ̀ pàtó.

Agent tí ń tẹ̀síwájú ń jẹ́ kí olùlò bá a ṣiṣẹ́ tààrà níbi tí wọ́n ti ń ṣiṣẹ́ tẹ́lẹ̀, bí IM chat àti GitHub comment, ó sì máa ń dà bí agent kan nígbà gbogbo. Àpẹẹrẹ ìfiránṣẹ́ náà ni olùlò kan tí ó béèrè Plan A nínú IM tí ó sì yí padà sí Plan B nínú comment Pull Request GitHub lẹ́yìn náà. Agent náà lóye ìyípadà náà, ó sì ṣàtúnṣe ohun tí ó ń ṣe. Ikanni yí padà; ìbánisọ̀rọ̀ kò yí padà.

Agent tí ń méso jáde ń dáhùn kíákíá, ó sì ń parí ọ̀pọ̀ iṣẹ́ dídíjú ní ìbámu, ọ̀kọ̀ọ̀kan ní ìdíwọ̀n gíga. Ó tún lè gba ìtọ́ni tí ó tẹ̀lé e ṣáájú kí àṣẹ tàbí iṣẹ́ tí ó ṣáájú tó parí. Ìyẹn mú ìhùwàsí ìdènà tí a ṣàpèjúwe ṣáájú kúrò.

Agent tí ń ṣáájú ń wo àwọn ìṣẹ̀lẹ̀ nínú àyíká rẹ̀, ó ń ṣe nǹkan lórí ohunkóhun tí ó yẹ láti bójú tó, ó sì ń dákẹ́ bí bẹ́ẹ̀ kọ́. Gbólóhùn ìkẹyìn yẹ fún àfiyèsí. Agent tí ń ṣe nǹkan lórí ohun gbogbo jẹ́ ariwo. Dídákẹ́ jẹ́ apá kan specification náà.

Agent tí ó wà pẹ́ wà lórí ayélujára nígbà gbogbo, ó so mọ́ àyíká iṣẹ́ gidi olùlò tààrà, ó sì ń bọ̀ sípò fúnra rẹ̀ láti inú àìtọ́ nígbà iṣẹ́ gígùn.

Lẹ́yìn náà ni ìdènà tí ó ń darí ìyókù àgbékalẹ̀ náà dé: kò sí ReAct loop kan tí ó lè pèsè ànímọ́ mẹ́rẹ̀ẹ̀rin lẹ́ẹ̀kan náà, nítorí náà wọ́n gbọ́dọ̀ wá láti architecture ètò tí ó yí i ká. Ìfiránṣẹ́ náà sọ èyí láìṣọ́ra, òun sì ni ìdí tí èyí fi jẹ́ àpilẹ̀kọ architecture dípò ti prompting.

## Ìpàdé, àti àkójọ ìṣòro àtijọ́

Ìfiránṣẹ́ náà retí pé àwọn agent ti ara ẹni àti àwọn agent fún iṣẹ́ ìṣòwò bí software development yóò parí sí àgbékalẹ̀ tí ó jọra nígbà tí àfojúsùn bá jẹ́ ètò tí ó wà lórí ayélujára nígbà gbogbo tí ó ń dáhùn sí ìṣẹ̀lẹ̀ àyíká lẹ́ẹ̀kan náà. Ìrètí ni, tí a ṣọ́ra lé lórí bí ó ti yẹ. Bí ó bá dúró, àwọn tí ń kọ́ olùrànlọ́wọ́ ti ara ẹni àti àwọn tí ń kọ́ agent development ń yanjú ìṣòro kan náà, wọ́n sì lè pín ọ̀pọ̀ àgbékalẹ̀.

Àkíyèsí kejì wà tí mo rí pé ó fini lọ́kàn balẹ̀. Kíkọ́ irú ètò bẹ́ẹ̀ gbé ọ̀pọ̀ ìṣòro dìde tí ó jọ àwọn tí a ti ṣe ìwádìí wọn fún ìgbà pípẹ́ nínú computer systems, nítorí náà ọ̀pọ̀ èrò àgbékalẹ̀ àtijọ́ láti ẹ̀ka yẹn wúlò níbí pẹ̀lú. Àwọn òǹkọ̀wé kò sọ èrò wo, èmi kò sì ní dá a. Ṣùgbọ́n ìtumọ̀ rẹ̀ fún àwọn olùdásílẹ̀ jẹ́ ti ìṣe: ìwọ kò dojú kọ ìṣòro tí a kò tíì ya àwòrán rẹ̀ rárá. Scheduling, isolation àti recovery ti ní ìtàn gígùn.

Àwọn òǹkọ̀wé rò pé module márùn-ún ló jẹ́ ìlànà ìpìlẹ̀ tí ó ṣe àtìlẹ́yìn fún ànímọ́ mẹ́rin náà, nígbà tí ìmúṣẹ yóò yàtọ̀. Lẹ́ẹ̀kan sí i, ìdájọ́ wọn ni, kì í ṣe ìpínyà tí a fi hàn. A so mẹ́rin nínú àwọn module náà mọ́ àwọn ànímọ́ báyìí.

Architecture onípele méjì (Section 2) ń pèsè ìbáṣepọ̀ tí ń tẹ̀síwájú àti concurrency tí ń méso jáde. Àgbékalẹ̀ tí ìṣẹ̀lẹ̀ ń darí (Section 3) ń mú agent ṣáájú. Ìbáṣepọ̀ full-duplex oníkanni púpọ̀ (Section 4) ń pa ìbánisọ̀rọ̀ kọ̀ọ̀kan pẹ̀lú olùlò mọ́ ní títẹ̀síwájú àti ní mímésojáde. Yíya compute, state àti àyíká sọ́tọ̀ (Section 5), pẹ̀lú Watchdog (Section 6), ń pa agent mọ́ lórí ayélujára nígbà gbogbo kárí ẹ̀rọ, ó sì ń jẹ́ kí ó bọ̀ sípò láti inú àìtọ́ fúnra rẹ̀.

Ìyókù àpilẹ̀kọ yìí pọkàn pọ̀ sórí èkíní nínú wọn, architecture onípele méjì.

## Ìpààrọ̀ láàrin ìtẹ̀síwájú àti throughput

Ṣíṣe àtìlẹ́yìn fún ìbáṣepọ̀ tí ń tẹ̀síwájú kárí ikanni àti concurrency tí ń méso jáde kárí iṣẹ́ ń fipá mú ìpààrọ̀ ìpìlẹ̀ láàrin ìtẹ̀síwájú àti throughput nínú bí ètò ṣe ń ṣètò session rẹ̀. Ọ̀nà méjì tí ó hàn gbangba wà láti ṣètò wọn, ọ̀kọ̀ọ̀kan sì ń kùnà ní ọ̀nà tí a lè sọ tẹ́lẹ̀.

Èkíní ni láti darí gbogbo ìṣẹ̀lẹ̀ sí session kan. Ìyẹn ń fúnni ní context tí ó tẹ̀síwájú jùlọ, nítorí session yẹn rí ohun gbogbo. Iye owó rẹ̀ ni ìyára. ReAct loop ń ṣe ìgbésẹ̀ kan lẹ́ẹ̀kan, èyí tí ó ká bí session kan ṣe lè ṣiṣẹ́ yára tó lọ́wọ́ kò: iṣẹ́ ń gba àkókò gígùn, throughput sì ń wà ní ìsàlẹ̀. Àwọn àlàyé àárín ti iṣẹ́ ọ̀tọ̀ọ̀tọ̀ tún ń dàpọ̀ nínú context kan, èyí tí ó ń ba àbájáde jẹ́. Nítorí náà session tí ó mọ̀ jùlọ tún ni ó ń ronú burú jùlọ, nítorí ó ń ka ohun tí ó dàrú.

Èkejì ni láti fún ìṣẹ̀lẹ̀ kọ̀ọ̀kan ní session tuntun tirẹ̀. Ìyẹn ń mú throughput concurrent pọ̀ jùlọ, ṣùgbọ́n nígbà tí àwọn iṣẹ́ kò bá dá wà pátápátá, àìsí context gbogbogbò tí a pín ń fi àbájáde wọn sílẹ̀ láìsopọ̀. Àwọn session púpọ̀ tí ń dá olùlò lóhùn lọ́tọ̀ọ̀tọ̀ tún ń mú ìbáṣepọ̀ náà dàrú. Olùlò gba ohùn márùn-ún níbi tí ó fẹ́ ọ̀kan.

Kò sí òpin kankan tí ó ṣe ìtẹ́wọ́gbà, ìpààrọ̀ náà sì jẹ́ gidi dípò ọ̀ràn àtúnṣe. Ètò tí ó fẹ́ ìtẹ̀síwájú àti throughput méjèèjì ní láti ya iṣẹ́ méjì náà sọ́tọ̀.

## Session kan, iṣẹ́ méjì

Ìfiránṣẹ́ náà dá ìdí tí àwọn iṣẹ́ náà fi so pọ̀ láti ìbẹ̀rẹ̀ mọ̀. Nínú àwọn àgbékalẹ̀ tí ó wà, session kan ń ṣe iṣẹ́ méjì: ó ń ṣàkóso context model, òun sì ni ẹyọ ìṣàkóso iṣẹ́-àkànṣe olùlò. Ohun kan ló ru ojúṣe méjèèjì, nítorí náà mímú ọ̀kan dára ń ba èkejì jẹ́. Fún olùlò ní session kan láti tẹ̀lé, context á sì di ẹlẹ́gbin. Fún model ní context tí ó mọ́ tí ó dá wà, olùlò á sì ní láti máa jà pẹ̀lú wọn.

Ìdí nìyí tí nọ́mbà session 3 sí 5 fi ń jáni. Ẹyọ ìṣàkóso iṣẹ́-àkànṣe olùlò ni session, nítorí náà iye session tí wọ́n lè tọpa di iye iṣẹ́-àkànṣe tí wọ́n lè ṣe.

## Architecture onípele méjì

Àbá náà pín àwọn ojúṣe. Ìpele Router tí ó pẹ́ láàyè (Section 2.1) ń pa ìtẹ̀síwájú gbogbogbò mọ́ nípa bíbójú tó gbogbo ìbáṣepọ̀ ènìyàn àti ìṣọ̀kan gbogbogbò. Ìpele Worker tí context rẹ̀ dá wà (Section 2.2) ń ṣe iṣẹ́ pẹ̀lú concurrency gíga. Ní àpapọ̀: ìpele Router ń bójú tó gbogbo routing àti ìbáṣepọ̀ òde, nígbà tí ọ̀pọ̀ Worker Session tí ó dá wà ń ṣe iṣẹ́ lẹ́ẹ̀kan náà.

Ìpele Router jẹ́ ìpele routing gbogbogbò tí ó pẹ́ láàyè tí ó ń gba ìbáṣepọ̀ ènìyàn láti gbogbo ẹnu-ọ̀nà. Ìdí nìyí tí agent fi máa ń dà bí agent kan nígbà gbogbo. Ikanni èyíkéyìí tí ìfiránṣẹ́ bá gbà dé, ó ń balẹ̀ sí ibi kan náà. Àwọn Worker, ní báyìí, ń pa context wọn mọ́ lọ́tọ̀, nítorí náà ìṣòro ìdàpọ̀ láti àgbékalẹ̀ session kan kò wáyé nínú wọn.

Àwọn òǹkọ̀wé fi àlàyé kan kún un tí ó rọrùn láti fojú fò. Ìpele méjì náà jẹ́ ìpínyà ojúṣe onírònú, kò sì sí ìpele kankan tí ó ní láti jẹ́ session kan ṣoṣo nínú ìmúṣẹ. Router kì í ṣe process kan tí ó gbé context kan dandan, ìpele Worker kì í sì í ṣe pool kan dandan. Architecture náà ṣàpèjúwe ẹni tí ó ní ojúṣe fún kí ni, kì í ṣe iye session tí ó wà.

Àbájáde ìṣe ni a sọ tààrà: ètò náà gba ìṣàkóso context àti ìmúṣẹ concurrent, nítorí náà olùlò kì í sábà ní láti ronú nípa session. Èyí ni ohun tí ó dojú kọ òrùlé àfiyèsí. Bí ènìyàn kò bá nílò láti rántí ohun tí session kọ̀ọ̀kan ní nínú mọ́, ààlà 3 sí 5 kò jẹ́ ààlà iye iṣẹ́ tí ó lè ṣiṣẹ́ mọ́. Ìfiránṣẹ́ náà kò sọ iye iṣẹ́ tí ẹ̀dà inú ilé rẹ̀ ń ṣe lẹ́ẹ̀kan náà, nítorí náà èmi kò lè sọ ibi tí ààlà tuntun wà.

## Ohun tí ìfiránṣẹ́ náà ṣe àtìlẹ́yìn fún, àti ohun tí kò ṣe

Ó yẹ kí a sọ òótọ́ nípa ẹ̀rí níbí. Àwọn ẹ̀tọ́ tí ó lágbára jẹ́ ti ìgbékalẹ̀. Session dá wà, ReAct loop kan ń ṣe ìgbésẹ̀ kan lẹ́ẹ̀kan, session kan tí a pín ń da context pọ̀, session fún ìṣẹ̀lẹ̀ kọ̀ọ̀kan sì ń ya àbájáde sọ́tọ̀. Ìfiránṣẹ́ náà sọ àwọn wọ̀nyẹn láìṣọ́ra.

Àwọn ẹ̀tọ́ tí ó rọ̀ ni àwọn tí ó gbé ìfẹ́ ọkàn náà. Ìtumọ̀ Super-agent, ànímọ́ mẹ́rin, ìlànà module márùn-ún àti ìpàdé tí a retí láàrin àgbékalẹ̀ ti ara ẹni àti ti ìṣòwò ni a ṣọ́ra lé lórí nínú ìfiránṣẹ́ náà. Àwọn òǹkọ̀wé gbàgbọ́, wọ́n rò, wọ́n sì retí wọn. Kò sí ọ̀kan tí a gbé kalẹ̀ gẹ́gẹ́ bí àbájáde tí a wọ̀n.

A ṣàpèjúwe ẹ̀dà inú ilé lórí DeepSeek Harness nípasẹ̀ ìhùwàsí: títẹ̀síwájú iṣẹ́ development kan kárí IM àti GitHub, àti rírí ohun tí ó fa ìṣòro nínú group chat gbangba ṣáájú kí ẹnikẹ́ni tó béèrè. Ẹ̀rí pé ó wà ni, kì í ṣe ìwádìí iṣẹ́. Ìfiránṣẹ́ náà ròyìn àwọn ìdánwò àkọ́kọ́, ṣùgbọ́n àwọn òǹkọ̀wé sọ pé wọ́n lo workload àtọwọ́dá àti àyíká tí a mú rọrùn, àti pé àbájáde náà jẹ́ àmì nìkan. Nínú ablation yẹn, Super-agent parí iṣẹ́ ní ìṣẹ́jú 12.4 ní p50 àti ìṣẹ́jú 15.7 ní p95, yára ju session kan pẹ̀lú subagent tool, nígbà tí ó ń lo cache-read token púpọ̀ sí i fún ìṣiṣẹ́ kọ̀ọ̀kan. Fún òǹkàwé onímọ̀-ẹ̀rọ, ìyẹn ni ìpele ìgbẹ́kẹ̀lé tí ó tọ́ láti gbé lọ: àgbékalẹ̀ náà ṣe déédé, a sì ṣàpèjúwe àwọn ọ̀nà ìkùnà ti àwọn ọ̀nà mìíràn dáadáa, ṣùgbọ́n àwọn nọ́mbà wá láti iṣẹ́ àfarawé, kì í ṣe láti ẹ̀dà tí a ń lò lójoojúmọ́.

## Ohun tí olùdásílẹ̀ gbọ́dọ̀ mú láti inú èyí

Bí o bá ń kọ́ ọjà agent, ẹ̀kọ́ àkọ́kọ́ ni láti dẹ́kun kíka session sí ọjà náà. Session jẹ́ àlàyé ìmúṣẹ ti ìṣàkóso context tí a ti gbé ga sí user interface. Àríyànjiyàn àwọn òǹkọ̀wé ni pé ìgbéga yìí ni ohun tí ó ká iṣẹ́ ìbámu lọ́wọ́ kò, mo sì rò pé wọ́n tọ̀nà láti gbé ìṣòro náà síbẹ̀.

Ẹ̀kọ́ kejì jẹ mọ́ ibi tí o gbé akitiyan rẹ sí. Agbára model ló ń ká iṣẹ́ kan lọ́wọ́ kò, nítorí náà model tí ó dára jù ń ran iṣẹ́ kan lọ́wọ́. Àfiyèsí ènìyàn ló ń ká ṣíṣe iṣẹ́ púpọ̀ lọ́wọ́ kò, nítorí náà model tí ó dára jù kò ràn án lọ́wọ́ ní kedere. Architecture ló ń ràn án lọ́wọ́. Router tí ó gba gbogbo ẹnu-ọ̀nà àti Worker tí ń pa context mọ́ lọ́tọ̀ ni irú ìgbékalẹ̀ tí ó ń gbé òrùlé náà sókè.

Ẹ̀kẹta jẹ mọ́ ààlà. Àwọn agent ti ara ẹni tí ó jókòó nínú ìfiránṣẹ́, kàlẹ́ńdà, email àti àwọn pẹpẹ iṣẹ́ àti àwọn agent development ìṣòwò tí ń fi Pull Request dá group chat lóhùn dà bí ọjà ọ̀tọ̀ọ̀tọ̀. Àwọn òǹkọ̀wé retí pé wọn yóò pàdé sí àgbékalẹ̀ tí ó jọra, nítorí náà ẹgbẹ́ tí ń kọ́ ọ̀kan kò gbọ́dọ̀ fojú fo ìtẹ̀síwájú lórí èkejì.

Kò sí èyí tí ó mú kíkọ́ rọrùn. Ìwàpẹ́ nìkan béèrè pé kí a ya compute, state àti àyíká sọ́tọ̀, pẹ̀lú Watchdog kí agent lè bọ̀ sípò láti inú àìtọ́ fúnra rẹ̀. Ìṣáájú béèrè àgbékalẹ̀ tí ìṣẹ̀lẹ̀ ń darí. Ìbáṣepọ̀ full-duplex oníkanni púpọ̀ ní abala tirẹ̀. Architecture onípele méjì jẹ́ ọ̀kan nínú module márùn-ún, kì í ṣe gbogbo ìdáhùn.

## Ìbéèrè kan tí ó ṣí sílẹ̀

Ìfiránṣẹ́ náà fi ohun kan sílẹ̀ ní ṣíṣí, òun sì ni èyí tí mo fẹ́ kí a dáhùn jùlọ. Router ń bójú tó gbogbo ìbáṣepọ̀ ènìyàn àti ìṣọ̀kan gbogbogbò, àwọn Worker sì dá wà nípasẹ̀ àgbékalẹ̀. Ìfiránṣẹ́ náà sọ pé ìpààrọ̀ láàrin ìtẹ̀síwájú àti throughput jẹ́ ìpìlẹ̀, àti pé ìpínyà onípele méjì ń pèsè méjèèjì. Fún àwọn iṣẹ́ tí ó fọwọ́ kan àyíká kan náà, ó sọ pé àwọn Worker tí ó forúkọ sílẹ̀ sí Thread àyíká yẹn ń gba ìfitónilétí ìṣẹ̀lẹ̀ kan náà, Router sì ń gbé àwọn ọ̀ràn díẹ̀ tí ó nílò ìṣọ̀kan kárí iṣẹ́ kọjá. Ó tún sọ pé ní kété tí àwọn iṣẹ́ bá tóbi tí wọ́n sì so pọ̀ ju ohun tí Router Session kan lè gbé, ìgbékalẹ̀ tí ó tọ́ fún ìpele kọ̀ọ̀kan kò tíì yanjú. Ìkùnà session-fún-ìṣẹ̀lẹ̀ jẹ́ àbájáde tí kò sopọ̀ láti àwọn iṣẹ́ tí kò dá wà. Bí Router ṣe ń gbé context gbogbogbò tí ó tó sísàlẹ̀, láìmú ìdàpọ̀ tí ó yẹ kí ó dènà padà wá, ni ibi tí a ó ti dán àgbékalẹ̀ náà wò.

## Àwọn Ìbéèrè Tí A Máa Ń Béèrè

**Kí ni Super-agent?**
Òun ni orúkọ tí ìfiránṣẹ́ náà fún agent kan, àti architecture ètò rẹ̀, tí a ti yà kúrò lára session kan èyíkéyìí tí a ń darí pẹ̀lú ọwọ́. Agent náà jẹ́ ẹ̀dá kan tí ń bá a lọ láìdúró tí ó ń pa context rẹ̀ mọ́ kárí àwọn session, tí ó sì ń ṣiṣẹ́ lórí ọ̀pọ̀ iṣẹ́ dídíjú lẹ́ẹ̀kan náà láìsí pé àwọn iṣẹ́ náà ń dí ara wọn lọ́wọ́.

**Kí ló dé tí session kan fún iṣẹ́ kan kò fi lè gbòòrò mọ́?**
Session dá wà, nítorí náà olùlò tí ń ṣe iṣẹ́ púpọ̀ ní ìbámu ní láti máa yí láàrin wọn pẹ̀lú ọwọ́, kí ó sì rántí ohun tí ọ̀kọ̀ọ̀kan ní nínú. Nínú ìrírí àwọn òǹkọ̀wé, ènìyàn kan sábà máa ń lè tẹ̀lé session tí ń ṣiṣẹ́ 3 sí 5 péré lẹ́ẹ̀kan náà, nítorí náà àfiyèsí ènìyàn ló ń ká ṣíṣe iṣẹ́ púpọ̀ lọ́wọ́ kò dípò agbára model.

**Kí ló dé tí CLI, MCP tàbí connector kò fi yanjú ìṣòro náà?**
Wọ́n ń jẹ́ kí agent session kan ti agbègbè gba ìfiránṣẹ́ òde, ṣùgbọ́n ààlà ìpìlẹ̀ rẹ̀ ṣì wà. Ó ṣì ń dènà lórí iṣẹ́ gígùn nínú session synchronous kan, ó ń da context láti iṣẹ́ ọ̀tọ̀ọ̀tọ̀ pọ̀, ó ń dúró nígbà tí ẹ̀rọ agbègbè bá lọ offline, ó sì ń gba akitiyan ọwọ́ púpọ̀ láti máa ṣiṣẹ́.

**Báwo ni architecture onípele méjì ṣe ń ṣiṣẹ́?**
Ìpele Router tí ó pẹ́ láàyè ń bójú tó gbogbo ìbáṣepọ̀ ènìyàn àti ìṣọ̀kan gbogbogbò, nígbà tí ìpele Worker tí context rẹ̀ dá wà ń ṣe iṣẹ́ pẹ̀lú concurrency gíga. Ìpele méjì náà jẹ́ ìpínyà ojúṣe onírònú, kò sì sí ìpele kankan tí ó ní láti jẹ́ session kan ṣoṣo nínú ìmúṣẹ.

**Báwo ni ẹ̀rí fún àgbékalẹ̀ náà ṣe lágbára tó?**
Ìfiránṣẹ́ náà ṣàpèjúwe ẹ̀dà Super-agent inú ilé tí ó ń ṣiṣẹ́ lórí DeepSeek Harness, ó sì ròyìn àwọn ìdánwò àkọ́kọ́. Àwọn òǹkọ̀wé sọ pé àwọn ìdánwò wọ̀nyẹn lo workload àtọwọ́dá àti àyíká tí a mú rọrùn, nítorí náà àbájáde náà jẹ́ àmì nìkan.
