## Ìjìnlẹ̀ Òye

### Àìní fún interface token tí ó ní ìlànà kan náà

Kí wọ́n tó gbé ìlànà ERC-20 (Ethereum Request for Comments 20) kalẹ̀, blockchain Ethereum dà bíi Wild West ti àwọn ètò token. Token tuntun kọ̀ọ̀kan tí wọ́n dá ní àwọn òfin, iṣẹ́, àti interface tirẹ̀ tó yàtọ̀. Èyí kò mú kí kíkọ́ rẹ̀ ṣòro fún àwọn olùgbéjáde (developers) nìkan, ṣùgbọ́n ó tún dí ìṣọ̀kan (interoperability) àwọn token lọ́wọ́. Ní pàtàkì, token tuntun kọ̀ọ̀kan dà bí èdè tuntun kan tí wọ́n ní láti kọ́, lóye, kí wọ́n sì mú lò. Ìpínyà yìí dí bí wọ́n ṣe le mú kí ó tóbi sí i (scalability) àti ìtẹ́wọ́gbà gbogboògbò àwọn token lórí platform Ethereum.

Ìgbésẹ̀ akọ́kọ́ ti ìlànà ERC-20 ṣiṣẹ́ bí èdè tó so wọ́n pọ̀, tó gbé àwọn òfin àti iṣẹ́ kan náà kalẹ̀ tí gbogbo àwọn token Ethereum gbọ́dọ̀ tẹ̀lé. Báyìí, àwọn developer ní interface tí ó dánmọ́ràn láti ṣiṣẹ́ pẹ̀lú rẹ̀, láìwo irú token tí wọ́n ń lò. Ìṣọ̀kan yìí jẹ́ kí àwọn ìlànà ìbáṣepọ̀ token rọrùn sí i, tó sì jẹ́ kí ó rọrùn láti fi kún àwọn ohun èlò (applications) àti iṣẹ́ (services) ọ̀tọ̀ọ̀tọ̀. Nípa báyìí, àwọn developer le ṣiṣẹ́ lọ́nà tó nítumọ̀ sí i pẹ̀lú àwọn token, nípa ṣíṣẹ̀dá àyíká kan tó dára fún àtinúdá àti ìdàgbàsókè nínú ecosystem Ethereum.

#### Wild West ti àwọn ètò token

Ní ìbẹ̀rẹ̀, a ṣe blockchain Ethereum láti ṣe àtìlẹ́yìn fún irú token kan ṣoṣo: ETH. Ṣùgbọ́n, bí platform yìí ṣe ń di gbajúmọ̀, àwọn developer bẹ̀rẹ̀ sí ní dá àwọn token tiwọn láti ṣojú fún onírúurú ohun-ìní àti èrò. Èyí fa ìyọrísí ọ̀pọ̀lọpọ̀ ètò token ọ̀tọ̀ọ̀tọ̀, tí kọ̀ọ̀kan ní òfin àti iṣẹ́ ti rẹ̀.

Ìpínyà yìí mú kí ó ṣòro fún àwọn developer láti ṣẹ̀dá àwọn application tí ó le ṣiṣẹ́ pẹ̀lú ọ̀pọ̀lọpọ̀ token. Ó tún mú kí ó ṣòro fún àwọn olùmúlò láti ṣàkóso àwọn ohun-ìní token wọn kọjá àwọn platform ọ̀tọ̀ọ̀tọ̀.

#### Ìlànà ERC-20

A gbé ìlànà ERC-20 kalẹ̀ ní ọdún 2015 láti yanjú àwọn ìpèníjà tí Wild West ti àwọn ètò token mú wá. Ìlànà yìí sọ àwọn òfin àti iṣẹ́ tí gbogbo àwọn token Ethereum gbọ́dọ̀ tẹ̀lé. Ìṣọ̀kan yìí jẹ́ kí ó rọrùn fún àwọn developer láti ṣẹ̀dá àwọn application tí ó le ṣiṣẹ́ pẹ̀lú eyikeyii token ERC-20, ó sì tún jẹ́ kí ó rọrùn fún àwọn olùmúlò láti ṣàkóso àwọn ohun-ìní token wọn.

Àwọn ará àdúgbò Ethereum ti gba ìlànà ERC-20 tọwọ́tẹsẹ̀. Lónìí, ó ju ẹgbẹ̀rún lọ́nà igba (200,000) token ERC-20 tí ó wà nínú ayé, wọ́n sì ń lo ìlànà yìí fún onírúurú application, pẹ̀lú decentralised exchanges (ibi-ìpàṣípàrọ̀ tí kò ní olórí), àwọn platform ìyáwó, àti gaming dapps (àwọn application eré ìdárayá).

## Èrò

### Àwọn iṣẹ́ àti ohun-ìní kan náà fún gbogbo àwọn token

Ìlànà ERC-20 sọ àwọn iṣẹ́ pàtàkì mẹ́fà tí gbogbo àwọn token tí ó tẹ̀lé ìlànà ERC-20 gbọ́dọ̀ ní. Àwọn iṣẹ́ yìí ni:

- `transfer(address to, uint256 amount)`: Ó ń gbé iye token kúrò ní àdírẹ́sì ẹni tó ń pè é lọ sí àdírẹ́sì tí a tọ́ka sí.
- `approve(address spender, uint256 amount)`: Ó ń fọwọ́ sí àdírẹ́sì tí a tọ́ka sí láti lo iye token kan nípò ẹni tó ń pè é.
- `allowance(address owner, address spender)`: Ó ń dá iye token tí a fọwọ́ sí fún ẹni tí a tọ́ka sí láti ná nípò olówó rẹ̀ padà.
- `totalSupply()`: Ó ń dá àpapọ̀ iye token tí ó wà nínú ìyípo padà.
- `balanceOf(address owner)`: Ó ń dá iye token tí àdírẹ́sì tí a tọ́ka sí ní padà.
- `name()`: Ó ń dá orúkọ token náà padà.
- `symbol()`: Ó ń dá àmì (symbol) token náà padà.

Ìlànà ERC-20 tún sọ àwọn ìṣẹ̀lẹ̀ (events) méjì tí ó gbọ́dọ̀ jáde (emitted) lẹ́yìn tí a bá ṣiṣẹ́ lórí àwọn iṣẹ́ tí ó kàn ní àṣeyọrí. Àwọn ìṣẹ̀lẹ̀ yìí ni:

- `Transfer(address from, address to, uint256 amount)`: Ó ń jáde nígbà tí a bá gbé iye token kúrò láti àdírẹ́sì kan lọ sí òmíràn.
- `Approval(address owner, address spender, uint256 amount)`: Ó ń jáde nígbà tí a bá fọwọ́ sí àdírẹ́sì tí a tọ́ka sí láti ná iye token kan nípò olówó rẹ̀.

## Ìpa

### Ìdàgbàsókè DeFi àti ìtẹ́wọ́gbà Ethereum

Ìlànà ERC-20 ti ní ipa pàtàkì lórí àyíká Ethereum. Ó jẹ́ ohun pàtàkì tó mú kí ìṣẹ̀lẹ̀ DeFi (Decentralized Finance - Ètò Ìnáwó Láìní Olórí) ṣeé ṣe, ó sì tún ti ràn wá lọ́wọ́ láti sọ ìtẹ́wọ́gbà Ethereum di púpọ̀ sí i.

Àwọn platform DeFi, tí wọ́n ń pèsè onírúurú iṣẹ́ ìnáwó láti orí yíyáwó sí àkóso ohun-ìní, gbẹ́kẹ̀le àwọn token púpọ̀ láti mú kí ìṣòwò rọrùn. Pẹ̀lú bí ERC-20 ṣe ń ṣiṣẹ́ bí adapter gbogboògbò, ó ti rọrùn jù fún àwọn application DeFi láti lo onírúurú token láìní láti tún àwọn kòòdù wọn kọ fún kọ̀ọ̀kan wọn.

Ìlànà ERC-20 tún ti jẹ́ kí ó rọrùn fún àwọn olùmúlò láti ṣàkóso àwọn ohun-ìní token wọn. Pẹ̀lú bí àwọn token ṣe ń tẹ̀lé òfin pàtàkì kan náà, ó rọrùn fún àwọn olùmúlò láti gbé, ná, kí wọ́n sì ṣàkóso àwọn ohun-ìní token wọn kọjá ọ̀pọ̀lọpọ̀ platform. Ìrírí olùmúlò tó dára yìí ti jẹ́ kókó pàtàkì nínú ìyára ìtẹ́wọ́gbà Ethereum.

## Ìwúrí

### Ìdínkù nínú iye owó ìdàgbàsókè àti ààbò tó dára sí i

Ìṣọ̀kan tí a mú wá nípasẹ̀ ètò ERC-20 ti ní ipa lórí ètò ọrọ̀ ajé tààràtà pẹ̀lú. Nípa pípèsè àwòrán ìlànà (blueprint) tí a ti dánwò tí àwọn ará àdúgbò sì ti fọwọ́ sí fún dídá token, ó ti dín àwọn ìdíwọ́ àwọn developer kù láti bẹ̀rẹ̀. Wọ́n le dá token tuntun báyìí pẹ̀lú ìdínkù nínú iye owó ìdàgbàsókè àti yíyára lọ sí ọjà, nítorí wọn kò ní láti bẹ̀rẹ̀ ní tuntun mọ́. Ìlànà yìí tún ń ṣe ìwúrí ní ọ̀nà mìíràn fún dídá àwọn DApp (Decentralised Applications - Àwọn Application Láìní Olórí) àti iṣẹ́ tí ó le ṣiṣẹ́ pẹ̀lú eyikeyii token ERC-20, nípa báyìí ó ń ṣẹ̀dá ecosystem kan tó lẹ́sẹ̀ nílẹ̀ sí i.

Àǹfààní mìíràn tó ṣe sísọ ni pé ààbò rẹ̀ ti dára sí i. Ìlànà ERC-20 ti kọjá lórí ìdánwò tó le láti ọwọ́ àwọn ará àdúgbò Ethereum, èyí tó mú kí ó jẹ́ àwòṣe tó lágbára tó sì ní ààbò fún ìlò token. Títẹ̀lé ìlànà yìí fihàn pé àwọn apá pàtàkì nínú smart contract ti token náà tẹ̀lé àwọn ọ̀nà tó dára jù lọ tí àwọn ará àdúgbò ti fọwọ́ sí. Èyí ń dín ewu àwọn àlàfo ààbò (security vulnerabilities) kù tí ó le wáyé látàrí ètò token tí kò dára. Bí ó tilẹ̀ jẹ́ pé kò pèsè ààbò kúrò lọ́wọ́ gbogbo irú àlàfo, ó jẹ́ ìgbésẹ̀ pàtàkì láti rí i dájú pé ààbò àwọn token wà lójú àyè rẹ̀, àti pẹ̀lú rẹ̀, àwọn iṣẹ́ (projects) tí ó ń lò wọ́n.
