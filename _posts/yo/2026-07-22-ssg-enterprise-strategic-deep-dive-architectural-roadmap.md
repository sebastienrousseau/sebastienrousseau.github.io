# Ẹ̀rọ-agbéjáde Ojú-òpó Aláìdúró (SSG): Ìwádìí Jíjinlẹ̀ Ìlànà àti Àwòrán-ọ̀nà Iṣẹ́-ẹ̀rọ Ipò-Ilé-iṣẹ́

*Ọjọ́ ìwádìí: 2026-06-22. Dá lórí àyẹ̀wò kóòdù `static-site-generator` ní v0.0.41 àti ìwádìí wẹ́ẹ̀bù ti àyíká SSG ọdún 2026.*

**Fún atẹ̀wé tí ìlànà ń ṣàkóso, ẹ̀rọ-agbéjáde ojú-òpó aláìdúró kì í ṣe ohun-èlò àpẹẹrẹ mọ́; ó ti di apá kan agbègbè-ewu iṣẹ́.** Rust orísun-ṣíṣí [static-site-generator](https://github.com/sebastienrousseau/static-site-generator) ni a kọ́ lórí ìpìlẹ̀ yẹn, tí ó ń gbé ààbò, ìwọlé-fún-gbogbo, ìtumọ̀-orílẹ̀-èdè àti ọ̀nà-iṣẹ́ àkóónú AI lọ sí àkókò-àkópọ̀ kí àyẹ̀wò tí ó kùnà lè dá àkópọ̀ dúró dípò kí ó dé ipò-ìṣàgbéjáde. Ìtúpalẹ̀ yìí ya ohun tí v0.0.41 ń gbé jáde ní tòótọ́ kúrò lọ́wọ́ ohun tí àkọsílẹ̀ rẹ̀ ṣì ń ṣèlérí nìkan, ó ṣàkàwé agbára-iṣẹ́ ilé-iṣẹ́ márùn-ún tí kò tíì ní, ó sì dábàá ọ̀nà onípele sí ìtújáde 1.0 tó bá DORA, Òfin Ìwọlé-fún-Gbogbo ti Yúróòpù àti àwọn ìlànà ẹ̀wọ̀n-ìpèsè òde-òní mu.

## Àwọn Agbára Lọ́wọ́lọ́wọ́

Kóòdù `static-site-generator` fihàn ọ̀pọ̀ ìpinnu iṣẹ́-ẹ̀rọ tó yàtọ̀ tí ó ya á sọ́tọ̀ kúrò lọ́wọ́ àwọn ẹ̀rọ JavaScript àti Go àtijọ́:

- **Ìdúró ààbò àkókò-àkópọ̀:** `#![forbid(unsafe_code)]` káàkiri iṣẹ́-àyè ń pèsè ìdánilójú ààbò-ìrántí àkókò-àkópọ̀. Ọ̀nà-iṣẹ́ àkópọ̀ ń pèsè SHA-256/SHA-384 Subresource Integrity (SRI) hashes tòótọ́ (`src/plugins/assets.rs`) ó sì ń ṣe ìfàyọ Content Security Policy (CSP) aládàáṣe tí ó yọ àwọn script àti style unsafe-inline kúrò. A fọwọ́sí àwọn ìtújáde, wọ́n gbé ìjẹ́rìí Sigstore, wọ́n sì ń pèsè CycloneDX 1.5 SBOM lórí àkópọ̀ kọ̀ọ̀kan.  
- **Ẹnu-ọ̀nà ìwọlé-fún-gbogbo tí olùkọ́pọ̀ ń fipá múlò:** Àwọn àyẹ̀wò Web Content Accessibility Guidelines (WCAG) 2.2 Level AA ń ṣiṣẹ́ nínú ọ̀nà-iṣẹ́ àkópọ̀ nípasẹ̀ olùsọ àkókò-àkópọ̀ axe-core tí Playwright ń darí. Ìwọlé-fún-gbogbo di ẹnu-ọ̀nà àkópọ̀ tí ó le dípò àyẹ̀wò-lẹ́yìn-ìṣàgbéjáde: bí ojú-ìwé kan bá kùnà, àkópọ̀ dúró pẹ̀lú àṣìṣe nọ́mbà-ìlà pàtó.  
- **Ọ̀nà-iṣẹ́ AI aláṣẹ-lórí-dátà:** Ọ̀nà-iṣẹ́ ìtumọ̀ àti ìfàyọ-metadata LLM-àdúgbò (nípasẹ̀ Ollama àdúgbò tàbí àwọn endpoint llama.cpp) ń jẹ́ kí ilé-iṣẹ́ kan lè ṣe àkótán àkóónú, ìpèsè schema JSON-LD àti ìtumọ̀-orílẹ̀-èdè-púpọ̀ láìfi àwọn ìṣípayá ṣáájú-èrè tàbí ohun-ìní-ọgbọ́n aṣírí ránṣẹ́ sí àwọn API AI cloud ti àwùjọ.  
- **Àkópọ̀ tí a pín-síi-ọ̀nà-púpọ̀:** Ìdánilójú ààbò-ìrántí ti Rust ni ìpìlẹ̀ ọ̀nà-iṣẹ́ HTML àti ohun-ìní tí Rayon ń darí, tí a pín-síi-ọ̀nà-púpọ̀ (`src/core/pipeline.rs`). Ọ̀nà-iṣẹ́ plugin ń ṣe àwọn ìyípadà tí a dàpọ̀, pẹ̀lú `SearchPlugin`, `SeoPlugin`, `CanonicalPlugin` àti `JsonLdPlugin` tí ń ṣiṣẹ́ lórí `par_iter()`, kí a lè ka ojú-ìwé kọ̀ọ̀kan kí a sì kọ ọ́ sí disk lẹ́ẹ̀kan ṣoṣo.  
- **Ìmọ́tótó ẹ̀wọ̀n-ìpèsè àti ìgbẹ́kẹ̀lé:** Yíyí ẹ̀rọ template padà láti Tera sí MiniJinja (`v0.0.37`) dín ìwọ̀n binary kù, ó yọ àwọn ìgbẹ́kẹ̀lé ìdàpọ̀ bíi `rand` kúrò ní àkókò-àkópọ̀, ó sì pèsè ìtẹ̀-ẹsẹ̀ ìgbẹ́kẹ̀lé tí ó kéré tó ń dín ìṣàfihàn ẹ̀wọ̀n-ìpèsè sọ́fítíwérì kù.

## Àwọn Àlàfo àti Òtítọ́ Ayé-Gidi

Láìka àwọn agbára àràmàdà wọ̀nyí sí, àyẹ̀wò kóòdù tó jinlẹ̀ ti v0.0.41 fihàn ọ̀pọ̀ àlàfo iṣẹ́-ẹ̀rọ, iṣẹ́-ṣíṣe, àti ìrírí-olùdàgbàsókè láàrin àwọn àbá àkọsílẹ̀ rẹ̀ àti kóòdù rust gan-an:

### Àwọn Àlàfo Iṣẹ́-ẹ̀rọ

- **Ìṣubú Àyè-Òfìfo dípò Ìdínkù-ìwọ̀n Àbínibí:** Bí ó tilẹ̀ jẹ́ pé README ṣèlérí "ìdínkù-ìwọ̀n JS/CSS àbínibí," `MinifyPlugin` (`src/plugins/plugins.rs:96-116`) ń ṣe gẹ́gẹ́ bí olùkó-àyè-òfìfo àìlẹ́mọ̀ nìkan. Ó ń dúró lórí àwọn nkan `<pre>` ó sì ń kó àwọn àyè-òfìfo pọ̀ nínú HTML, ṣùgbọ́n kò ṣe ìdínkù-ìwọ̀n CSS tàbí JS àbínibí tó mọ̀ nípa ọ̀nà-gírámà. Síwájú síi, ó ń ṣàgbéyẹwo àwọn ojú-ìwé ìpele-òkè nìkan kò sì ń rìn àwọn ìsàlẹ̀-fọ́lder lọ́tọ̀ọ̀tọ̀ (bíi `/blog/` tàbí `/tags/`), tí ó ń fi àwọn ojú-ìwé jíjìn sílẹ̀ láìdín-ìwọ̀n.  
- **Ètò-ìpìlẹ̀ Àfikún-síi Òkú:** Àwòrán-ìdarí ìgbẹ́kẹ̀lé (`DepGraph` nínú `src/core/depgraph.rs`) ni a kójọ tí a sì gbé sínú `PluginContext.dep_graph` ṣùgbọ́n kì í kún ní tòótọ́ nínú kóòdù ìṣàgbéjáde. Ọ̀nà `add_dep()` ni a pè nínú àyẹ̀wò-ẹyọ nìkan, tí ń sọ àbá README ti "àkópọ̀ àfikún-síi nípasẹ̀ àwọn àwòrán-ìgbẹ́kẹ̀lé" di àfojúsùn lọ́wọ́lọ́wọ́.  
- **Àkópọ̀ Àkópọ̀-ẹgbẹ́ dípò Àkópọ̀ Ìṣàn-lọ:** Module `streaming::compile_batch` (`src/core/streaming.rs`) kò ṣàn-lọ ní tòótọ́. Dípò bẹ́ẹ̀, ó ń kó àwọn ojú-ìwé pọ̀ ní ẹgbẹ́-ẹgbẹ́ sí fọ́lder ìgbà-díẹ̀, ó ń ṣe `staticdatagen::compile` láti ìbẹ̀rẹ̀ fún ẹgbẹ́ kọ̀ọ̀kan, ó sì ń dàpọ̀ àwọn àbájáde. Èyí ń fa àpọ̀jù disk I/O tó pọ̀ àti ìtúpalẹ̀ àtúndáṣe, tó ń yapa kúrò lọ́wọ́ iṣẹ́-ẹ̀rọ ìṣàn-lọ tòótọ́.  
- **Ìrúfin Ìpele Ìyípo-Ayé Plugin:** Àwọn plugin tí ń pèsè àwọn ojú-ìwé HTML tuntun nígbà ìṣe àkópọ̀, bíi `TaxonomyPlugin`, `PaginationPlugin` àti `I18nPlugin`, ń kọ tààrà sí disk nínú `after_compile` dípò lílo ìyípo-ayé `transform_html`. Nítorí náà, àwọn ojú-ìwé tí àwọn plugin wọ̀nyí pèsè ń fo àwọn plugin ìṣàgbéyẹwo-lẹ́yìn pàtàkì (bíi `CanonicalPlugin`, `JsonLdPlugin`, `RobotsPlugin`, àti `AccessibilityPlugin`) bí a bá forúkọ àwọn plugin yẹn ṣáájú. Èyí ń fi àwọn ojú-ìwé tag, ẹ̀ka, àti àwọn ojú-ìwé onípẹpẹ sílẹ̀ láìní àwọn ọ̀nà-àṣopọ̀ canonical tó tọ́, schema JSON-LD, tàbí àwọn ìdánilójú ìwọlé-fún-gbogbo.  
- **Jíjáde sí `curl` nínú `LlmPlugin`:** Ọ̀nà-iṣẹ́ àkóónú LLM àdúgbò (`src/plugins/llm.rs`) ń jáde tààrà sí binary `curl` ti host láti béèrè àwọn endpoint àdúgbò. Èyí ń fa àwọn àṣìṣe agbélébùú-pẹpẹ tó le (bíi, lórí àwọn host Windows láìní curl nínú PATH), ó ń dá ewu ààbò sílẹ̀ (àwọn vector shell injection), ó sì ń kùnà nínú àwọn àyíká CI tí a há tàbí tí a ya sọ́tọ̀ kúrò lórí nẹ́tíwọ́kì.  
- **Ìdarí-ọ̀rọ̀ Àìlẹ́mọ̀ nínú Àtúnkọ HTML:** Àwọn olùfàyọ `image_plugin.rs` àti `search.rs` ń tún àwọn ọ̀rọ̀ HTML kọ nípa lílo àwọn iṣẹ́ `str::find` àti `str::rfind` aláìlera. Ọ̀nà yìí ṣí sílẹ̀ gidigidi sí àwọn tag HTML tí ó fọ́, àwọn tag `<img>` nínú àwọn àríwísí, àwọn nkan-ẹ̀dà nínú ọ̀rọ̀ alt, tàbí àwọn ohun-ìní `srcset` tí ó ti wà tẹ́lẹ̀, tó lè yọrí sí àbájáde tó bàjẹ́.  
- **Àtìlẹ́yìn AVIF Tí Kò Ṣe:** Bí ó tilẹ̀ jẹ́ pé a kọ AVIF image encoding sílẹ̀ gidigidi, ìṣe rẹ̀ nínú `image_plugin.rs` jẹ́ stub níbi tí `avif_variants` ti ń dá `Vec::new()` padà lásán, tó ń fi ẹ̀yà náà sílẹ̀ láìṣiṣẹ́.  
- **Olùṣọ́ Aládàáró-lórí-Ìwádìí:** Olùṣọ́ ti sáà idàgbàsókè àdúgbò (`src/server/watch.rs`) ń lo ìwádìí dípò àwọn API ìṣẹ̀lẹ̀ filesystem, tó ń yọrí sí lílo CPU aláìṣiṣẹ́ àpọ̀jù àti ìdádúró-àkókò ìyípadà tó kéré sí ìṣẹ́jú-àáyá.

### Àwọn Àlàfo Iṣẹ́-ṣíṣe àti DX

- **Kò Sí Ìdarí Ìgbẹ́kẹ̀lé Ìdàpọ̀:** Àwòrán-ìgbẹ́kẹ̀lé kò lè darí àwọn ìgbẹ́kẹ̀lé tí a fi sínú (bíi, àwọn ìyípadà sí ìsàlẹ̀-template tó ń nípa lórí layout tó ń nípa lórí ojú-ìwé), gẹ́gẹ́ bí àyẹ̀wò-ẹyọ `transitive_not_tracked` ti fọwọ́sí.  
- **Kò Sí Àsíá CLI Àkópọ̀ Àfikún-síi:** Kò sí àsíá CLI `--incremental` tí a so mọ́ olùkópọ̀ ìṣe, tó ń ṣèdíwọ́ fún àwọn olùdàgbàsókè láti lo àwọn àkópọ̀ tí a tọ́jú.  
- **HMR Ní Àdínkù sí CSS:** Hot Module Replacement (HMR) ń ṣàtìlẹ́yìn CSS nìkan; ìyípadà èyíkéyìí sí HTML, layout, tàbí àwọn fáìlì markdown ń fa àtúnkó ojú-ìwé pátápátá, tó ń dín eré olùdàgbàsókè kù.  
- **Àìtó Àṣẹ-abẹ́:** Àwọn olùdàgbàsókè gbọ́dọ̀ fi àwọn àsíá gígùn sílẹ̀ pẹ̀lú ọwọ́ (`ssg -s public -w`) nítorí àwọn àṣẹ-abẹ́ àpapọ̀ bíi `ssg dev`, `ssg build`, `ssg check`, àti `ssg lint` kò sí.

## Àwọn Àlàfo Iṣẹ́-ẹ̀rọ Tí À Ń Sọnù (Àwọn Ìwádìí Tuntun)

Ju àwọn àlàfo nínú v0.0.41 lọ, ṣíṣàyẹ̀wò iṣẹ́-ìṣe náà ní ìbámu pẹ̀lú àwòṣe-ewu ipò-ìnáwó fihàn ọ̀pọ̀ agbára-iṣẹ́ tí kò tíì pèsè ṣùgbọ́n tí olùrà ilé-iṣẹ́ yóò béèrè:

### 1. Sandbox Plugin WebAssembly (Àfikún Ìgbẹ́kẹ̀lé-Òdo)

Bí ó tilẹ̀ jẹ́ pé a kọ binary olùkọ́pọ̀ fúnrarẹ̀ ní Rust aláàbò, gbígba àwọn plugin ẹnìkẹta láìsí-àdíwọ̀n láàyè láti ṣiṣẹ́ ní àbínibí lórí àwọn ètò-host ń dá àìlera ẹ̀wọ̀n-ìpèsè tó le sílẹ̀. Plugin ẹnìkẹta tó bàjẹ́ lè ní ìráyèsí filesystem ti host ní ìrọ̀rùn, ka àwọn fáìlì Markdown aṣírí, tàbí kó àwọn ẹ̀rí-ìdánimọ̀ aṣírí jáde.

* **Agbára-iṣẹ́ Tí Ó Nsọnù:** Àyíká ìṣe sandbox. Láti dé àkópọ̀ ìgbẹ́kẹ̀lé-òdo, olùkọ́pọ̀ gbọ́dọ̀ ṣe àwọn plugin ẹnìkẹta nínú runtime WebAssembly tí a fi sínú (bíi `wasmtime`). Àwọn plugin gbọ́dọ̀ báṣepọ̀ pẹ̀lú host nìkan nípasẹ̀ WebAssembly System Interface (WASI) tí a há, tí ó ń dín ìráyèsí wọn kù pátápátá sí ojú-ìwé tí a ń yí padà.

### 2. Ìtúpalẹ̀ HTML Aláìní-àdà nípasẹ̀ AST Ìṣàn-lọ (`lol_html`)

Yíyí ìpele ìtúpalẹ̀ HTML padà sí ilé-ìkàwé DOM-nínú-ìrántí pátápátá (bíi Kuchiki tàbí html5ever) ń dá àpọ̀jù ìrántí tó pọ̀ àti àwọn ìdádúró ìṣàgbéyẹwo sílẹ̀ nígbà tí a bá ń darí àwọn ojú-òpó tó ní ju ojú-ìwé 100,000 lọ.

* **Agbára-iṣẹ́ Tí Ó Nsọnù:** Atúntò HTML ìṣàn-lọ, aláìní-àdà. Lílo `lol_html` ti Cloudflare (atúntò HTML Low-Output-Latency) ń jẹ́ kí olùkọ́pọ̀ lè ṣàyẹ̀wò, ṣàgbéyẹwo, kí ó sì yí àwọn nkan HTML padà nínú ìrìn ìṣàn-lọ ẹyọkan pẹ̀lú ìpín-ìrántí tó fẹ́rẹ̀ jẹ́ òdo, tó ń bá àfojúsùn olùkọ́pọ̀ ìṣàn-lọ ìṣọ̀kan ti àwọn àkópọ̀ tó kéré sí ìṣẹ́jú-àáyá mu.

### 3. Ìwádìí Vector Ìtumọ̀ Àdúgbò (RAG Àdúgbò)

Àtọ́ka ìwádìí lọ́wọ́lọ́wọ́ (`SearchPlugin`) ń pèsè àtọ́ka JSON pẹrẹsẹ, wíwúwo tí ń ṣe àfarawé ọ̀rọ̀-ọ̀kánkán ẹgbẹ́-alábara-lásán, tí kò ní àtìlẹ́yìn fún ìwádìí àìpé, stemming, tàbí àwọn ìbéèrè ìtumọ̀. Pagefind jẹ́ ìdàgbàsókè, ṣùgbọ́n ó ṣì gbára lé ìgbàsílẹ̀ àtọ́ka ńlá.

* **Agbára-iṣẹ́ Tí Ó Nsọnù:** Ìwádìí ìtumọ̀ tí a fi sínú. Olùkọ́pọ̀ gbọ́dọ̀ lo àwòṣe vector embedding àbínibí-Rust tó fúyẹ́, tí ó jẹ́ àdúgbò (bíi àwòṣe MiniLM-L6 tí a ṣe nípasẹ̀ `candle` tàbí `ort` / ONNX Runtime) ní àkókò-àkópọ̀. Ó gbọ́dọ̀ pèsè àwọn embedding vector tó nípọn fún ìpínrọ̀ ojú-ìwé kọ̀ọ̀kan kí ó sì pèsè àtọ́ka vector tó kéré. Widget ìwádìí ẹgbẹ́-alábara, tí a kójọ sí WASM, lè ṣe ìwádìí ìtumọ̀ àìsára-lóhùn tòótọ́ tààrà nínú aṣàwáríwẹ́ẹ̀bù.

### 4. Ìtọ́jú-àpò Ìtumọ̀ àti Inference Aláìyàrọ̀

Nítorí pé inference LLM àdúgbò (bíi, nípasẹ̀ Ollama tàbí Llama.cpp) ń lo CPU/GPU gidigidi, ìtumọ̀ tàbí ìpèsè metadata fún ẹgbẹẹgbẹ̀rún ojú-ìwé lórí àkópọ̀ kọ̀ọ̀kan jẹ́ èyí tí kò ṣeéṣe ní ti ìṣírò.

* **Agbára-iṣẹ́ Tí Ó Nsọnù:** Ìtọ́jú-àpò inference tó dá lórí hash-àkóónú. Olùkọ́pọ̀ gbọ́dọ̀ tọ́jú àpò aláìyàrọ̀ fún gbogbo iṣẹ́ LLM. Bí SHA-256 hash ti àkóónú fáìlì markdown àti àwọn àléébù ìtumọ̀ rẹ̀ bá bára mu pẹ̀lú ẹ̀yà àpò kan, olùkọ́pọ̀ gbọ́dọ̀ tún ìtumọ̀ àti metadata tí a tọ́jú lò, tí ó ń fo inference àdúgbò àtúndáṣe.

### 5. File I/O Aláìdúró fún Ìgbékalẹ̀ Ìṣọ̀kan

Bí ó tilẹ̀ jẹ́ pé a pín ọ̀nà-iṣẹ́ plugin síi-ọ̀nà-púpọ̀ nípasẹ̀ Rayon, àwọn kíkọ disk tó ń dúró-fúra ń dí àwọn OS thread Rayon lọ́wọ́, tó ń dá ìdíwọ́ I/O sílẹ̀ nígbà tí a bá ń kọ ẹgbẹẹgbẹ̀rún ojú-ìwé.

* **Agbára-iṣẹ́ Tí Ó Nsọnù:** Disk I/O aláìdúró, aláìdí-lọ́wọ́. Olùkọ́pọ̀ gbọ́dọ̀ ya àwọn iṣẹ́ tó ń lo CPU (ìtúpalẹ̀ Markdown, ìdínkù-ìwọ̀n) sọ́tọ̀ kúrò lọ́wọ́ àwọn kíkọ tó so mọ́ disk, tí ó ń lo àwọn àpò-thread I/O aláìdúró tàbí àwọn binding `io_uring` ti Linux (nípasẹ̀ `rio` tàbí `tokio`) láti kọ àwọn ojú-ìwé tí a kójọ ní ìṣọ̀kan láìdí àwọn olùṣe CPU ìṣọ̀kan lọ́wọ́.

## Àwòrán-ọ̀nà Ìlànà 1.0

Àwòrán-ọ̀nà tí ó tẹ̀lé yìí ń dàpọ̀ àwọn àlàfo tí a yanjú àti àwọn agbára-iṣẹ́ ipò-ilé-iṣẹ́ tí a ṣẹ̀ṣẹ̀ ṣàwárí sí àkópọ̀ ìtújáde onítòlẹ́sẹẹsẹ, aláṣẹ̀-ọjọ́.

### Ìpele 1: 0.0.42 (Àbọ̀ Ìdúróṣinṣin àti Ìtọ́, ọ̀sẹ̀ 1 sí 2)

1. **Tún `MinifyPlugin` kọ́:** Ìdàpọ̀ `minify-html`, `oxc_minifier`, àti `lightningcss` fún ìdínkù-ìwọ̀n HTML, JS, àti CSS àbínibí tó mọ̀ nípa ọ̀nà-gírámà. Rí i dájú pé plugin náà ń rìn gbogbo àwọn fọ́lder tí ó wà lábẹ́ `site_dir` lọ́tọ̀ọ̀tọ̀.  
2. **Fi Ààbò Bo Ọ̀nà-iṣẹ́ AI:** Yí `LlmPlugin` padà láti àwọn jíjáde-shell `curl` àbínibí sí `ureq` (alábára HTTP Rust aláàbò, aláìyàrọ̀, tó fúyẹ́) láti rí ìbámu agbélébùú-pẹpẹ dájú kí a sì mú àwọn àìlera shell injection kúrò.  
3. **Parí Ìṣe AVIF:** So `ravif` tààrà sí ọ̀nà-iṣẹ́ ohun-ìní image, tí ń jẹ́ kí AVIF encoding tó ga-lẹ́ṣẹ̀ ṣeéṣe lẹ́gbẹ̀ẹ́ WebP àti PNG.  
4. **Ṣe HrefLang àti Ìlà-àwòrán Locale-Púpọ̀ ní Aládàáṣe:** Ṣàwárí àwọn ojú-ìwé ìtumọ̀ ìṣọ̀kan ní aládàáṣe nínú àwọn àkópọ̀ orílẹ̀-èdè-púpọ̀ kí a sì fi àwọn tag `<link rel="alternate" hreflang="..." />` tó bá Google mu sí orí fáìlì HTML kọ̀ọ̀kan tí a kójọ.  
5. **Àtìlẹ́yìn JSON Feed 1.1:** Gbé olùpèsè JSON Feed 1.1 tó yàsọ́tọ̀ jáde lẹ́gbẹ̀ẹ́ àwọn ọ̀nà-àkànṣe RSS 2.0 àti Atom 1.0 àpapọ̀.

### Ìpele 2: 0.1.0 (Kékeré ti Ìgbẹ́kẹ̀lé àti Àfikún-síi, oṣù 2 sí 3)

1. **Kún `DepGraph` kí o sì Jẹ́ kí `--incremental` Ṣiṣẹ́:** So `DepGraph` pátápátá láti darí àwọn ìgbẹ́kẹ̀lé template-sí-ojú-ìwé àti markdown-sí-ojú-ìwé. Ṣe ìpele ìfagilé-àpò kí o sì so àsíá CLI `--incremental`, pẹ̀lú àfojúsùn àkópọ̀-àtúntò tó kéré sí 200ms fún àwọn àyíká àpò-gbígbóná.  
2. **Àtúnkọ AST Ìṣàn-lọ nípasẹ̀ `lol_html`:** Rọ́pò àtúnkọ ọ̀rọ̀ aláìlera nínú `image_plugin.rs`, `search.rs`, àti àwọn àbẹrẹ CSP pẹ̀lú atúntò HTML ìṣàn-lọ, aláìní-àdà tí `lol_html` ń darí.  
3. **Olùṣọ́ Aládàáró-lórí-Ìṣẹ̀lẹ̀ àti HMR Ẹ̀yà:** Yí module olùṣọ́ padà láti ìwádìí sí crate `notify` aládàáró-lórí-ìṣẹ̀lẹ̀, kí o sì ṣe àtúnkó gbígbóná CSS-nìkan àti HTML-apá-kan fún àwọn ìmúdójúìwọ̀n aṣàwáríwẹ́ẹ̀bù tó kéré sí 100ms.  
4. **CLI Àṣẹ Ìṣọ̀kan:** Tún ìlànà olùkọ́pọ̀ ṣètò láti ṣàtìlẹ́yìn àwọn àṣẹ-abẹ́ àpapọ̀: `ssg dev`, `ssg build`, `ssg check` (àyẹ̀wò ìwọlé-fún-gbogbo/SEO), àti `ssg deploy`.  
5. **Àpò Inference Aláìyàrọ̀:** Ṣe ìpele ìtọ́jú-àpò tó dá lórí hash-àkóónú fún gbogbo iṣẹ́ ìtumọ̀, àkótán, àti ìfàyọ-metadata LLM àdúgbò.

### Ìpele 3: 1.0.0 (Ńlá ti Ilé-iṣẹ́ àti Ìṣàgbéjáde, oṣù 6 sí 12)

1. **Sandbox Plugin WASM Ìgbẹ́kẹ̀lé-Òdo:** Fi runtime WebAssembly sínú (`wasmtime` tàbí `wasmer`) láti ṣe àwọn plugin ẹnìkẹta nínú àyíká sandbox pátápátá pẹ̀lú ìráyèsí filesystem àti nẹ́tíwọ́kì tó dá lórí agbára.  
2. **Ìwádìí Vector Ìtumọ̀ Àdúgbò (RAG Àdúgbò):** Fi àwòṣe embedding àbínibí-Rust àdúgbò sínú (nípasẹ̀ `candle` tàbí `ort`) láti kó àwọn embedding ìpínrọ̀ tó nípọn sí àtọ́ka tó kéré, tí ń jẹ́ kí ìwádìí ìtumọ̀ ẹgbẹ́-alábara aṣírí ṣeéṣe.  
3. **Àwọn Server Island àti Ìlépa Edge WASM:** Ṣe ìṣe ẹ̀yà `<ssg-island>` lórí àwọn runtime edge (bíi Cloudflare Workers, Vercel Edge, tàbí Netlify Edge) tí a kọ́ lórí ìpìlẹ̀ ìṣàkóso `ssg-wasm` tí a kójọ.  
4. **Ẹ̀rọ I/O Ìṣọ̀kan Aláìdúró:** Tún module kíkọ filesystem ṣètò láti lo àwọn àpò-thread I/O aláìdúró àti àwọn binding `io_uring`, tí ń mú àwọn ìdídúró olùṣe CPU kúrò nígbà àwọn kíkọ ìṣọ̀kan.  
5. **Ìjẹ́rìí Àkópọ̀ SLSA v1.1 àti Ìbámu SPDX 3.0:** Pèsè ìjẹ́rìí àkópọ̀ SLSA Level 3 tí a lè fọwọ́sí ní ti ìṣírò kí o sì pèsè àwọn SBOM tó bá SPDX 3.0 mu, tí ó ń tẹ́ àwọn ìlànà ààbò ẹ̀wọ̀n-ìpèsè sọ́fítíwérì òde-òní lọ́rùn pátápátá.

## Àwọn Ìbéèrè Tí A Sábà Ń Bèèrè

**Kí ni version 0.0.41 ń gbé jáde ní tòótọ́ lónìí, ní ìfiwéra pẹ̀lú ohun tí README ń sọ?**
Àwòṣe ààbò àti ìwọlé-fún-gbogbo jẹ́ tòótọ́ tí a sì fipá múlò nínú kóòdù: `forbid(unsafe_code)` káàkiri iṣẹ́-àyè, ìpèsè SHA-256/384 SRI, ìfàyọ CSP, àwọn ìtújáde tí a fọwọ́sí pẹ̀lú ìjẹ́rìí Sigstore àti CycloneDX SBOM, àti ẹnu-ọ̀nà WCAG 2.2 AA tó ń dá àkópọ̀ dúró. Ẹ̀yà mẹ́ta tí a kọsílẹ̀ kò ṣiṣẹ́ nínú v0.0.41. `MinifyPlugin` jẹ́ olùkó-àyè-òfìfo dípò olùdínkù-ìwọ̀n tó mọ̀ nípa ọ̀nà-gírámà; `DepGraph` tí yóò máa ṣàkóso àkópọ̀ àfikún-síi ni a kójọ ṣùgbọ́n kò kún ní kóòdù ìṣàgbéjáde; AVIF encoding sì jẹ́ stub tí `avif_variants` rẹ̀ ń dá vector òfìfo padà.

**Ṣé ẹnu-ọ̀nà ìwọlé-fún-gbogbo jẹ́ ẹnu-ọ̀nà olùkọ́pọ̀ tòótọ́ ni tàbí linter lẹ́yìn-àkópọ̀?**
Ó jẹ́ ẹnu-ọ̀nà àkópọ̀. Àwọn àyẹ̀wò WCAG 2.2 AA ń ṣiṣẹ́ nínú ọ̀nà-iṣẹ́ àkópọ̀ nípasẹ̀ olùsọ àkókò-àkópọ̀ axe-core tí Playwright ń darí, ojú-ìwé tó kùnà sì ń dá àkópọ̀ dúró pẹ̀lú àṣìṣe nọ́mbà-ìlà pàtó dípò gbígbé ìkìlọ̀ jáde lẹ́yìn ìṣẹ̀lẹ̀. Ìyẹn ni ohun-ìní tí ọ̀ranyàn Òfin Ìwọlé-fún-Gbogbo ti Yúróòpù ń béèrè: àbájáde tí kò bá ìlànà mu kò lè dé ipò-ìṣàgbéjáde.

**Kí ló dé tí jíjáde sí `curl` nínú plugin LLM fi ṣe pàtàkì?**
Ọ̀nà-iṣẹ́ LLM àdúgbò (`src/plugins/llm.rs`) ń pè binary `curl` ti host láti dé àwọn endpoint àdúgbò. Èyí ń so àkópọ̀ mọ́ ẹ̀rọ-ìṣe host, ó ń kùnà lórí àwọn ètò láìní `curl` nínú PATH, ó ń dá ojú shell-injection sílẹ̀, ó sì ń fọ́ nínú CI tí a ya sọ́tọ̀ kúrò lórí nẹ́tíwọ́kì. Yíyí ìpè náà padà sí alábára HTTP Rust bíi `ureq` ń mú ìgbẹ́kẹ̀lé ìta àti vector injection náà kúrò, ìdí nìyí tí ó fi jẹ́ nkan kejì nínú àbọ̀ 0.0.42.

**Kí ni nkan kan tó ṣe pàtàkì jùlọ lórí ọ̀nà sí 1.0?**
Kíkún `DepGraph` àti sísopọ̀ àsíá `--incremental`. Àwọn àkópọ̀ àfikún-síi ni àlàfo ìgbẹ́kẹ̀lé láàrin ẹ̀rọ tí a kọsílẹ̀ àti ẹ̀rọ gan-an, gbogbo àbá àbájáde nípa àwọn àkópọ̀ tó kéré sí ìṣẹ́jú-àáyá ní ojú-ìwé 100,000-ó-lé sì dá lórí àwòrán-ìgbẹ́kẹ̀lé tó ń darí àwọn ẹ̀gbẹ́ template-sí-ojú-ìwé àti markdown-sí-ojú-ìwé dípò kí ó jẹ́ ètò-ìpìlẹ̀ àyẹ̀wò-nìkan.
