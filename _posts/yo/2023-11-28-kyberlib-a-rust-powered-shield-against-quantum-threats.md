## Dídáàbò bò Data Rẹ ní Akoko Kuantum

Ìfarahàn kọ̀mpútà kuantum ti mú ìrọ́kẹ́kẹ́ ńlá wá sí àwọn ọ̀nà ààbò cryptography àtọwọ́dọ́wọ́. Láti yanjú ìpèníjà yìí, pápá Quantum-Safe Cryptography (QSC) ń tẹ̀síwájú ní kíákíá.

Níwájú nínú ìgbésẹ̀ ìyípadà yìí ni National Institute of Standards and Technology (NIST), tí ó ń ṣíwájú nínú ṣíṣe standardisation àwọn algorithm QSC.

Ní ọdún 2023, NIST yan àwọn algorithm tuntun mẹ́rin tí wọ́n dá lórí kókó yìí:

- [**[CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html)** ⧉][01] (key encapsulation mechanism)
- [**CRYSTALS-Dilithium** ⧉][02] (digital signatures)
- [**FALCON** ⧉][03] (lightweight digital signatures)
- [**SPHINCS+** ⧉][04] (hash-based digital signatures)

Àwọn algorithm tuntun wọ̀nyí dá lórí àwọn ìlànà ìṣirò oríṣiríṣi, títí kan lattice-based cryptography, hash-based cryptography, àti code-based cryptography pẹ̀lú ète láti pèsè ààbò tó lágbára lọ́wọ́ àwọn ìkọlù kuantum.

## Ṣíṣàyẹ̀wò Lattice-Based Cryptography

Lattice-Based Cryptography (LBC) ń yọrí síwájú nínú QSC, ní pípèsè ojútùú Post-Quantum Cryptographic (PQC) tí ó nílérí. LBC ní ìbáṣepọ̀ púpọ̀, pẹ̀lú àwọn ìlò tí ó bẹ̀rẹ̀ láti key-encapsulation mechanisms (KEMs), digital signatures, àti àwọn ètò public-key encryption tí ó jẹ́ yọ láti inú àwọn mathematical lattice.

Àwọn lattice jẹ́ kókó kókó pàtàkì nínú mathematics tí ó ti rí àwọn ìlò nínú àwọn pápá oríṣiríṣi, títí kan cryptography. Ní èdè tó rọrùn, lattice jẹ́ ètò tí ó ṣe déédé ti àwọn point ní ojú sánmà, tí ó ń dá ohun-èlò bíi grid. Àwọn point wọ̀nyí ní ìsopọ̀ pẹ̀lú àwọn line, tí wọ́n ń dá nẹ́tíwọ́ọ̀kì ti àwọn sẹ́ẹ̀lì tí wọ́n sopọ̀ pọ̀. Ètò pàtó ti àwọn point àti ààyè láàárín wọn ń tọ́ka sí àwọn àbùdá àrà ọ̀tọ̀ ti lattice kan.

### Ìfihàn 3D Lattice pẹ̀lú Àwọn Basis Vector

Graph yìí ń ṣàfihàn ohun-èlò 3D lattice tí a ṣẹ̀dá láti ara àwọn basis vector mẹ́ta:

- `b1 = [1, 0, 0]` ní àwọ̀ pupa,
- `b2 = [0, 1, 0]` ní àwọ̀ ewé, àti
- `b3 = [0, 0, 1]` ní àwọ̀ búlúù.

Point kọ̀ọ̀kan lórí lattice náà ni a ṣẹ̀dá nípa síṣàkópọ̀ àwọn basis vector wọ̀nyí ní àwọn ìpín integer oríṣiríṣi, ní ṣíṣẹ̀dá àwòrán bíi grid tí ó fẹ̀ sí gbogbo àwọn spatial dimension mẹ́tẹ̀ẹ̀ta. Ìfihàn náà ń fi kókó ti 3D lattice hàn, èrò tí a ń lò lọ́pọ̀lọpọ̀ nínú physics àti mathematics láti ṣàfihàn ètò tí ó ṣe déédé ti àwọn point tí ó ń tún ara rẹ̀ ṣe ní ojú sánmà.

![Ìfihàn 3D Lattice pẹ̀lú Àwọn Basis Vector][06].class=\"img-fluid mx-auto d-block\"

Nínú cryptography, a ń lo àwọn lattice gẹ́gẹ́ bí ìpìlẹ̀ fún àwọn algorithm cryptography kan. Lattice-Based Cryptography (LBC) ń lo àwọn ohun-ìní mathematics ti àwọn lattice láti ṣẹ̀dá àwọn ètò cryptography tó ní ààbò tí ó lè dènà àwọn ìkọlù láti ara àwọn kọ̀mpútà kuantum. Àwọn kọ̀mpútà kuantum ń mú ìrọ́kẹ́kẹ́ ńlá wá sí cryptography àtọwọ́dọ́wọ́, nítorí wọ́n lè fọ́ àwọn algorithm tí ó gbẹ́kẹ̀lé factoring large numbers tàbí yíyanjú àwọn ìṣòro discrete logarithm ní kíákíá.

[CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) ń ṣàfihàn àwọn agbára LBC, ní pípèsè ààbò tó lágbára lọ́wọ́ àwọn ìkọlù kuantum papọ̀ mọ́ iṣẹ́ tó múnádóko àti key size tó tayọ. Ìbáṣepọ̀ rẹ̀ pẹ̀lú àwọn platform oríṣiríṣi àti cryptography ń mú kí ó jẹ́ àyànfẹ́ tó ṣeé gbẹ́kẹ̀lé fún ààbò data ní akoko kuantum.

Àwọn ìlànà lọ́wọ́lọ́wọ́ ti [CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) nìwọ̀nyí:

- **Kyber512**: Ń pèsè ipele ààbò tó dọ́gba mọ́ 128-bit AES encryption, ní dídáàbò bò data tó ní kókó pẹ̀lú ààbò tó jẹ́ standard ilé-iṣẹ́.
- **Kyber768**: Ń pèsè ipele ààbò tó dọ́gba mọ́ 256-bit AES encryption, ní dídánilójú ìpamọ́ ti àwọn ìsọfúnni tó ní kókó gidi.
- **Kyber1024**: Ń pèsè ipele ààbò tí ó ju 256-bit AES encryption lọ, ní pípèsè ààbò tó lágbára lọ́wọ́ àwọn ìkọlù kuantum àti dídáàbò bò integrity data lọ sí ọjọ́ iwájú.

### Ìfiwéra ti Àwọn Ipele Ààbò láàárín Àwọn Classical Algorithm àti Àwọn Tí Ó Jẹ́ Quantum-Resistant

Chart bar yìí ń ṣàfihàn àwọn ipele ààbò ti àwọn classical cryptographic algorithm bíi RSA-2048 àti Elliptic Curve Digital Signature Algorithm (ECDSA) ní ìfiwéra sí àwọn ìlànà ti àwọn variant Algorithm [CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) tí ó jẹ́ quantum-resistant (Kyber512, Kyber768, àti Kyber1024).

Bí ó tilẹ̀ jẹ́ pé chart yìí ń pèsè ìfiwéra ojú, ó ṣe pàtàkì láti mọ̀ pé àwọn ipele ààbò wọ̀nyí kò ṣeé fiwé tààràtà nítorí pé wọ́n dá lórí àwọn ìlànà ìṣirò oríṣiríṣi.

Síbẹ̀síbẹ̀, chart náà ń pèsè kókó ìtọ́kasí tó wúlò fún níye ipele ààbò ti àwọn algorithm tí ó jẹ́ quantum-resistant.

## KyberLib: Library Rust kan fún Quantum-Resistant Cryptography

KyberLib ń lo agbára [CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) láti pèsè memory safety tó dára jù àti ààbò tó lágbára ní ipele ètò. Ó ń ṣàtìlẹ́yìn fún ọ̀pọ̀lọpọ̀ àwọn ìlànà [CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) (Kyber512, Kyber768, Kyber1024), ní pípèsè ọ̀pọ̀lọpọ̀ ipele ààbò láti bá àwọn ohun tí o nílò mu. Ìbámu `no_std` rẹ̀ ń mú kí ó jẹ́ àyànfẹ́ tó dára fún àwọn embedded system, nígbà tí ìbámu WebAssembly (WASM) rẹ̀ ń rọ̀rùn láti ṣàkópọ̀ rẹ̀ láìsí wàhálà sí àwọn web application.

![divider][divider].class=\"m-10 w-100\"

## Dídáàbò bò Àwọn Web Application Pẹ̀lú Quantum-Resistant Cryptography

Tí a ṣe fún lilo memory tó kéré jọjọ, KyberLib dára fún embedded system àti àwọn ètò tí kò ní ohun-èlò púpọ̀ láìsí pé ó ń dín ààbò kù. Imuse rẹ̀ tí ó dá lórí Rust ń lo àwọn ẹya ààbò ti èdè náà, ní mímú kí ààbò tí algorithm [CRYSTALS-Kyber](/2023-11-19-crystals-kyber-the-safeguarding-algorithm-in-a-quantum-age/index.html) ń pèsè túbọ̀ lágbára sí i.

Láfikún sí i, ìbámu WebAssembly ti KyberLib ń mú kí ìlò rẹ̀ gbòòrò sí i nínú àwọn web application, ní dídánilójú pé ó jẹ́ tool pàtàkì nínú ayé cryptography tí ń yí padà ní gbogbo ìgbà.
