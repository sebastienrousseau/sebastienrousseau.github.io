# 你的 DORA 退出計畫只是算了價，沒有做規劃。一月，這個價格就消失了。

**五個月後，那張讓雲端退出變得不可想像的帳單將被立法歸零，第三方風險管理中最耐用的藉口也隨之消失。** 自 DORA 適用之日起，它就要求為支撐關鍵或重要職能的 ICT 服務制定退出策略。多數銀行把它寫了出來。真正算過價的少得多，做過演練的更少——因為「要走需要付出什麼」這個問題的誠實答案，包含著一張誰也不願擺到成本委員會面前的資料傳出帳單。自 **2027年1月12日** 起，歐盟資料法徹底廢止轉換費用，資料傳出費包含在內。這並不會讓遷移變得容易。它只是移走了那個唯一可以被稱作「無法逾越」、卻從來沒人真正檢驗過是否如此的障礙——而商業壁壘一旦消失，剩下的就是一個工程問題，監理機關有權要求看到答案。

> **決策摘要**
>
> - **這是一個日期，不是一個趨勢。** 轉換費用在 2027年1月12日終止。更換服務商的法定權利，以及為此獲得技術協助的權利，自 2025年9月12日起已經生效。
> - **被撤走的是藉口，不是難度。** 傳出費定價從來不是退出計畫停留在紙上的唯一原因。它是那個不必讓任何人承認架構有問題的原因。
> - **DORA 早已要求的不止一份文件。** 第28條第8項要求退出策略完整、有文件記錄、經過充分測試並定期複核。
> - **監理問題換了形狀。** 不再是「你們有退出計畫嗎」，而是「你們說成本是限制——它沒了，請讓我們看演練」。

## 2027年1月12日真正改變的是什麼

歐盟資料法是規則 (EU) 2023/2854。其轉換條款分階段到位，而由於最終狀態異常直白，值得把這些階段準確說明。

自 **2025年9月12日** 起，納入範圍的資料處理服務客戶享有更換服務商的法定權利，服務商則負有技術配合義務，使資料移轉真正可行，而不只是在原則上予以允許。

自資料法生效以來，一套過渡機制限定了服務商可以收取的金額。在該窗口內，轉換與傳出費用不得超過服務商實際發生且與該次轉換過程直接相關的成本。沒有利潤，沒有策略性定價。

自 **2027年1月12日** 起，依第29條的逐步取消條款，轉換費用被徹底禁止。這包括資料傳出費——正是這項按 GB 計價的收費，在讓退出試算顯得高不可攀這件事上出力最多。

由此立刻產生三個後果，而其中只有一個關乎金錢。

留下不動的商業理由，少了一個往往承擔著大量修辭分量的科目。圍繞一個將不復存在的收費體系寫成的合約條款需要重新審視。而分析性的問題，也從*這要花多少錢*轉向*這需要做什麼*——後者在董事會材料裡要難迴避得多。

## 退出計畫為何停留在紙上

這一點上應當說句公道話。退出計畫被擱置，並不是因為有誰認為它不重要。它們停留在理論，是因為一次真正的測試貴得容易量化、又難以論證。

把一份有分量的工作負載搬出超大規模雲端業者，意味著為資料搬遷付費、搭建並行容量，並承擔切換期間同時運行兩套環境的成本。傳出費那一行是財務長看得見的一行，也總是終結對話的那一行。這讓它成為一個異常舒適的障礙：它推遲了整個計畫，卻不需要任何人說出「問題在架構」。

在它之下，三項更硬的限制在做真正的工作，而它們都不受資料法影響。

**託管服務在本性上並不可攜。** 建立在某家服務商的託管資料庫、其身分模型、其事件匯流排與其無伺服器執行環境之上的工作負載，不是一份會「搬走」的負載，而是一份會被「重寫」的負載。可攜性是被有意換掉的，通常出於速度與營運成本的正當理由，而這筆交換的帳單以工程季度計價，而非每 GB 多少歐元。

**資料引力比資料傳輸活得更久。** 分析體系、特徵庫、稽核封存，以及圍繞它們生長起來的一切，即便位元組可以免費流動，也無法乾淨地遷移。

**沒有人演練過。** 一份從未執行過的計畫是一個假設。DORA 的起草者顯然明白這一點，所以第28條第8項並未止步於要求一份計畫。

### 表 1：資料法移走了什麼，沒有移走什麼

| 退出的障礙 | 2027年1月12日移除？ |
|---|---|
| 傳出費與轉換費用 | **是**——徹底禁止 |
| 圍繞這些費用寫成的合約條款 | 否——需要重新談判 |
| 與託管服務的耦合 | 否——是重構，不是傳輸 |
| 分析體系中的資料引力 | 否 |
| 缺少一次演練過的切換 | 否——這才是工作本身 |

右側那一列才是重點。只有一行發生變化，而它恰恰是長期替所有其他行站台的那一行。

## DORA 實際要求什麼

這裡被揭開的義務並不新鮮，而且比通常被對待的方式更為嚴格。

第28條第8項要求金融主體為支撐關鍵或重要職能的 ICT 服務制定退出策略。這些策略必須考慮服務商失敗、服務品質下降、因提供不當造成的業務中斷，以及該服務持續部署所面臨的重大風險。計畫必須完整、有文件記錄，並且——這是要緊的措辭——**經過充分測試並定期複核**。

「經過充分測試」一直是那條硬條款。一份描述遷移的文件，並不能證明該遷移在可容忍的時間窗內可行。監理期待落在能力上，而非落在產出物上。

兩年來，成本一直是測試條款在實務中未被滿足的原因。它是監理機關可以聽進去而不必立刻升級的理由，因為它真實且可量化。從一月起它不再可用，剩下的是對一個從來沒有好答案的問題的回答：這實際要花多久，你們又憑什麼知道？

## 沒有人排進日程的合約工作

短期交付物既不體面又有明確時限——在這個領域是難得的組合。

過去幾年簽訂的雲端合約中，包含著屆時收取即屬違法的轉換與傳出費經濟條款。有些還帶著通知期、協助義務與資料返還條款，全都是按照「客戶理應為這份特權付費」的世界校準的。這些條款不會在 2027年1月12日自我修正；它們只是變成按字面無法執行的約定，嵌在仍然規範著其餘一切的合約裡。

由此產生一件邊界清晰、期限自然的工作：辨識受影響的合約，確定哪些條款被取代，並把修正折進下一次續約，而不是在事故當中才發現不一致。

### 表 2：續約週期之前需要確定的事

| 問題 | 它決定你曝險中的什麼 |
|---|---|
| 哪些合約對轉換或傳出計價？ | 那些條款將無法執行；合約的其餘部分不受影響 |
| 服務商實際負有何種協助義務？ | 該法定義務自 2025年9月起已生效 |
| 每項關鍵或重要職能的目標退出窗口是多久？ | 「經過充分測試」需要一個可供檢驗的數字 |
| 是否端到端演練過一次退出，哪怕是縮小規模？ | 從未執行過的計畫是一個假設 |
| 哪些必須重寫而不是搬遷？ | 把傳輸問題與架構問題區分開 |
| 兩次測試之間，退出能力歸誰所有？ | 隨著體系演進，退出就緒度會無聲退化 |

## 這暴露出來的那個問題

有一種令人不適的可能性值得點明，因為一月這個日期會把它逼到明處。

如果轉換免費，退出卻仍然不可信，那麼成本從來就不是那個具拘束力的限制。具拘束力的限制是集中度——一項關鍵職能落在一家實際上無法離開的服務商身上，而這正是 DORA 第三方制度存在的目的所在，也是關鍵 ICT 第三方服務商被指定並接受監督的原因。

這不是主張把工作負載搬回自建。對銀行運行的絕大多數東西而言，雲端依然是正確答案，而一次糟糕執行的退出，比一段管理良好的相依更糟。這是主張：要知道自己處在兩種情形中的哪一種，並且能夠拿出證明。能夠說出「我們測試過這項服務的部分退出，用了十一週，壞掉的是這些」的機構，與拿出一份四十頁文件加一個估算的機構，處在實質不同的監理對話裡。

法規移走了藉口。它沒有移走問題，也從來不打算。

## 操作手冊

五個動作，而第一個不是合約審查。

1. **挑一項關鍵或重要職能，誠實地把退出算出價來——現在，按舊價格。** 你想在傳出費還有價格的時候拿到這個數字，因為它會告訴你，你的遲疑當中究竟有多少曾經是財務上的。答案往往是：比所有人設想的都少。
2. **演練一次部分退出。** 不是整個體系。一項服務、一處相依、一次還原到第二家服務商或自有設施，計時進行。產出是一個時長和一份缺陷清單，而這正是「經過充分測試」所要的。
3. **盤點一月將要作廢的條款。** 轉換費用、傳出定價、按其校準的協助義務。把修正折進續約週期，而不是任由無法執行的約定因慣性繼續生效。
4. **按負載區分「傳輸」與「重寫」。** 兩列。傳出免費後能搬走的，和必須重建的。第二列才是你真實的退出地平線，也是董事會從未拿到過的數字。
5. **為兩次測試之間的能力指定負責人。** 退出就緒度是當前架構的屬性，不是一份帶複核日期的文件。沒有指定負責人，它會隨著每一個新增託管相依的迭代悄悄退化。

監理上的寬鬆通常以「移走某樣東西」的形式到來。這一次移走的，是一個長期替論點站台的數字。2027年最難堪的機構，不會是那些仍然只用一家服務商的——多數都會是。而是那些花了兩年告訴監理機關成本就是障礙，等到一月它不再是障礙時，卻無話可說的機構。

## 常見問題

**這是否意味著雲端退出會變容易？**  
不。它變成不再收取轉換費用，這是另一回事。資料法移走的是傳輸成本；它不會讓一份建立在託管服務之上的負載變得可攜。那依然是重構，以工程季度而非歐元計量。

**2027年1月12日起究竟禁止什麼？**  
轉換費用，包括資料傳出費。過渡期內服務商只能收回與轉換過程直接相關的成本，且不得加價；自該日起則完全不得收費。

**已經有什麼生效了嗎？**  
有。自 2025年9月12日起，客戶享有更換服務商的法定權利，以及在移轉資料時獲得技術配合的權利。一月這個日期專門了結的是收費問題。

**DORA 在其中處於什麼位置？**  
第28條第8項要求為支撐關鍵或重要職能的 ICT 服務制定退出策略，並要求其完整、有文件記錄、經過充分測試並定期複核。成本一直是測試這一支未被滿足的現實原因。這個原因即將失效。

**我們只用一家超大規模雲端業者，而且還會繼續。這與我們有關嗎？**  
有關，甚至更甚。義務是擁有一項經過測試的退出能力，而不是去行使它。留下是一個決定；離不開則是集中度風險，而一月之後，你無法再把後者歸因於傳出費的價格。

**這一季最有用的一件事是什麼？**  
演練一項關鍵或重要職能的部分退出，並記錄耗時與失敗之處。這份產出回答了監理問題，量出了真實問題的大小，比再多的規劃都更有價值。
